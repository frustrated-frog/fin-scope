# News Wire 评分与筛选改进

## 输入、规则和输出

作用于整个 News Wire 的后台生产、公共首页榜、个人研究雷达、事件排名历史和新闻河流回放。实时资讯继续按时间浏览，原始报道不因评价低而删除。沿用现有来源，不增加抓取、在线模型和额外部署服务。

复用 `RadarHotspotScoreService` 产出的独立来源分析和文本特征，新增 `RadarNewsworthinessService`，为每个当前事件持久化 `NewsworthinessAssessment`：

- 重要性：按政策动作、经营业绩、实际进展、程序性披露、疑问与传闻等上下文确定初始规则分；会议通知、法律意见、持股名单不因刚发布就获得高重要性。
- 新意：从主体、动作、方向、变量、数值生成事实特征摘要；特征不足时使用规范化内容摘要。与同一事件上次成功生产的记忆比较，记录新增特征及最新有效进展时间。
- 热度：保留 HOTSPOT_V3 的独立传播强度含义。
- 时效：按最新有效进展衰减，不按反复抓取时间刷新。完全相同的事实换渠道或改时间不会刷新时效；迟到的旧事实不算本轮进展。同源新增事实可以恢复优先级。
- 质量：标题、正文完整度、事实特征及来源质量；疑问和传闻不能获得已实施政策的重要性。

这是可回归的确定性初版，事实特征匹配不等于完整语义理解，重要性并非训练得到的人工判断概率。尚不评估金额占公司营收的比例，也不预测收益。没有足够时间信息的消息不获得时效加分；原始列表仍可查。

## 分数与场景

配置落在 `application.yml` 的 `finscope.newswire-ranking`，启动时校验权重非负且和为 1。

```text
维度基础分 = 重要性×0.45 + 新意×0.20 + 热度×0.20 + 时效×0.15
质量系数 = 0.5 + 质量/200
重要性系数 = 0.4 + 重要性×0.006
公共资讯价值 = 基础分 × 质量系数 × sqrt(进展时效比例) × 重要性系数
个人优先级 = min(100, 公共资讯价值 + 个人相关性比例×12)
```

重要性系数防止普通程序性公告仅靠新鲜度占据前列。重要性本身也随进展时间衰减。新意半衰期 2 小时，时效半衰期 6 小时，48 小时后归零。独立来源可信度不再作为个人排序的第二次加权项；仍保留原热度和可信度字段供现有展示使用。

公共榜按公共价值排序，个人雷达按个人优先级排序。共享 `NewswireRankingPolicy` 提供稳定次序；同主体每次重复最多降 12 分、累计最多降 36 分，对前 50 个位置逐项选择，剩余候选保留。复用本批次已知主体别名，避免公司前缀标题与机构描述标题完全独立处理。降权不是合并事件，也不删除报道。

用户处理状态先筛选，再计算候选之间的多样性和展示截断。首页预热与仓库回查、个人雷达预热与即时读取使用相同排序规则。历史回放仍读取实际保存批次，不用新规则重算旧榜单。

## 存储与升级

事件的 JSON 增加可选 `newsworthiness` 字段，无 SQLite 表迁移。旧缓存无此字段时，公共分回退到原热度；下一次完整后台生产后切换到新评价。失败批次不发布新的页面版本。

每个当前事件最多保存 64 个截断 SHA-256 摘要（每个 16 个十六进制字符），不保存第二套正文，不把摘要集合复制到每次热度快照。API 卡片只增加公共价值、重要性、新意和版本字段，不暴露内部特征记忆。版本为 `NEWS_VALUE_V1`，热度版本仍为 `HOTSPOT_V3`。

## 验收方式

自动回归覆盖：重大单源政策与普通自选披露、20 次转载改时间、同源数值进展、迟到报道、重复生产、未来/未知时间、传闻、真实程序性公告标题、配置校验、旧缓存兼容、状态先筛选、多样性与候选完整性、公共/个人排序差异。

新增可选离线回放测试 `NewswireCorpusEvaluationTest`，输入固定 `capturedAt` 和 `events[{event,signals}]`，不连接 Redis、数据库、模型或外部来源。对同一批事件、同一时点重算 V3 热度，与新公共价值榜比较，并检查重复评价一致性和候选完整性：

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home \
mvn -o -f backend/pom.xml -pl finscope-service -am test \
  -Dtest=NewswireCorpusEvaluationTest -Dsurefire.failIfNoSpecifiedTests=false \
  -Dnewswire.corpus=/绝对路径/corpus.json \
  -Dnewswire.report=/绝对路径/report.md
```

真实语料及逐条结果只保存在被 Git 忽略的 `data/exports/`。没有输入语料时，此项可选测试明确跳过，不以空数据宣称真实验收成功。排名变化不是准确率，当前回归样本也不能证明全量新闻已经分准；后续可基于漏选、误选案例继续扩充同一套评测。
