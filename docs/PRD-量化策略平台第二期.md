# PRD：量化策略平台第二期

## 1. 背景

FinScope 第一期已经具备持仓角色、策略模板、股票研究卡和复盘能力，但它仍然是投资纪律工作台，不是可验证策略假设的量化研究平台。用户当前持仓较少，第二期不围绕持仓规模扩展，而是建立股票日频多因子研究的完整闭环，为后续基金策略、通用资产回测和模拟组合奠定基础。

本期面向个人投资学习场景。系统的价值不是给出“买什么”，而是把自然语言投资想法转成可审计的规则，在严格的时间语义和交易假设下复现结果，并保留每次实验的证据。

## 2. 产品目标

交付一个可实际操作的量化实验室：

1. 用户能够查看数据集覆盖范围、质量和来源，不在未知数据上运行策略。
2. 用户能够理解并选择量价、价值、质量、成长、规模等首批因子。
3. 用户用自然语言描述策略，Agent 生成结构化策略草案和理由。
4. 草案必须经过确定性规则校验，并由用户确认后才能回测。
5. 回测结果提供收益、风险、回撤、换手、基准和因子诊断，不只展示单一收益率。
6. 每次实验保存策略快照、数据指纹、成本参数、引擎版本和结果，保证可复现。
7. Agent 可以解读已有结果并提出下一轮实验建议，但不能自动发起实验或修改已确认策略。

## 3. 非目标

- 不提供 Python、SQL 或 Notebook 在线编辑器。
- 不做分钟级、高频、期货、期权、加密资产或海外市场。
- 不连接券商，不自动下单，不提供实盘交易指令。
- 不进行无人确认的参数搜索或连续实验。
- 不把当前指数成分股伪装为历史成分股；缺少历史成分数据时必须暴露幸存者偏差风险。
- 不把合成学习数据、当前截面财务数据或未来修订数据包装成真实历史业绩。

## 4. 核心用户流程

```text
进入量化实验室
  → 选择或建立数据集
  → 查看覆盖率和质量门禁
  → 浏览因子目录与诊断
  → 用自然语言描述策略
  → Agent 生成结构化草案
  → 系统校验股票池、因子、日期、时间对齐和成本参数
  → 用户确认并启动回测
  → 查看净值、回撤、年度表现、交易和因子贡献
  → Agent 解读结果并给出下一轮实验建议
  → 保存为新的策略版本
```

## 5. 信息架构

现有“策略”一级入口升级为量化策略平台，内部包含：

- `实验室`：自然语言入口、策略草案、校验结果与运行操作。
- `数据中心`：数据集、时间范围、股票数量、字段覆盖率、来源、更新时间和风险标记。
- `因子库`：因子定义、方向、经济含义、依赖字段、缺失率、IC/Rank IC 与分层表现。
- `实验记录`：不可变实验快照、运行状态、指标、曲线、年度表现、调仓和 Agent 解读。
- `长期投资`：保留一期组合、策略模板、股票孵化和复盘，不作为默认页。

默认进入 `实验室`。没有真实数据时可以建立明确标记为“学习数据”的数据集，所有结果持续显示学习数据水印。

## 6. 功能需求

### 6.1 数据中心

- 支持建立日频股票研究数据集，记录名称、市场、股票池类型、起止日期、来源类型和说明。
- 支持导入统一结构的日行情、基本面时点快照和股票池成员数据。
- 日行情至少包含交易日、代码、开高低收、前复权收盘价、成交量、成交额、是否停牌、是否 ST、涨跌停可交易状态。
- 基本面快照至少包含代码、报告期、公告/披露日期、PE、PB、总市值、ROE、营收同比、净利润同比和资产负债率。
- 股票池成员必须带生效日期；只有当前成员时标记 `CURRENT_SNAPSHOT` 并提示幸存者偏差。
- 导入后生成数据指纹、覆盖率、重复记录数、无效价格数、缺失交易日和字段缺失率。
- 学习数据与真实数据严格区分；真实实验不得引用学习数据并隐藏标识。

### 6.2 因子库

首批因子控制在 12 个：

- 动量：20 日、60 日收益率。
- 反转：5 日反转。
- 波动：20 日实现波动率。
- 流动性：20 日平均成交额、20 日平均换手代理。
- 规模：对数总市值。
- 价值：EP、BP。
- 质量：ROE、低资产负债率。
- 成长：营收同比、净利润同比。

每个因子具有唯一代码、类别、名称、方向、经济含义、依赖字段、最短回看窗口和是否需要财务时点数据。因子值只由确定性计算器生成。

因子诊断包括缺失率、截面去极值、Z-Score、分位数组、Rank IC、IC 均值、IC 标准差、ICIR、正 IC 占比和分层收益。诊断收益使用下一可交易日之后的持有期收益，禁止同日收盘信号同日成交。

### 6.3 Agent 策略草案

- 用户输入自然语言目标、偏好或风险约束。
- Agent 只能从当前数据集可用的股票池、因子和枚举参数中选择。
- 输出固定 Schema：名称、投资假设、股票池、过滤规则、因子及权重、持股数量、调仓频率、基准、成本、回测区间、风险边界和解释。
- Agent 输出先进入 `DRAFT`，通过 Schema、因子可用性、权重、日期和未来函数规则校验后进入 `VALIDATED`。
- 用户确认后生成不可变策略版本；修改已确认策略必须产生新版本。
- LLM 未配置或返回非法 JSON 时，系统返回可理解的错误，不伪造 Agent 结果。

### 6.4 回测

- 首期策略类型为多因子横截面排序、Top-N、等权持有、固定交易日周期调仓。
- 信号在 T 日收盘后形成，订单最早在 T+1 日开盘或可配置的下一可交易价格执行。
- 默认过滤 ST、停牌、上市不足 252 个交易日、成交额不足阈值以及当日不可买入股票。
- 交易成本包含买入佣金、卖出佣金、印花税、最低佣金和滑点；所有参数进入实验快照。
- 基本面数据仅在 `disclosed_at <= signal_date` 时可见。
- 输出组合净值、基准净值、超额净值、日收益、回撤、调仓和成交明细。
- 输出累计收益、年化收益、年化波动、最大回撤、夏普、卡玛、胜率、换手率、交易次数和相对基准指标。
- 数据不足、无可交易标的、因子全缺失或现金不足时明确记录告警，不静默补值。

### 6.5 实验与解读

- 实验状态为 `QUEUED/RUNNING/SUCCEEDED/FAILED`，运行记录不可覆盖。
- 实验详情显示策略版本、数据指纹、引擎版本、全部参数、指标、曲线、年度表现、持仓/交易和告警。
- Agent 解读只能读取已保存指标和摘要，事实数字由服务端注入；输出区分观察、可能原因、风险和下一步实验。
- 每条建议必须说明“只改变一个主要变量”，减少多变量同时变化造成的归因困难。

## 7. 交互与视觉要求

延续一期“沉静的投资作战室”，但从资产轨道转为“实验画布”。页面视觉中心是策略流水线：数据、因子、组合、执行、分析五个节点，每个节点展示状态和质量门禁。

主界面采用三栏结构：左侧为实验步骤，中间为草案与结果画布，右侧为 Agent 研究员。窄屏按步骤折叠为单列。曲线使用 SVG 或现有前端能力绘制，必须提供文本指标和表格替代，颜色不是唯一信息载体。

所有收益类区域显示数据来源与实验性质；学习数据使用持续可见的琥珀色水印。失败状态保留输入和日志摘要，允许修正后创建新实验，不提供“覆盖旧结果”。

## 8. 验收标准

1. 可建立数据集并导入日行情、财务时点和股票池成员；质量报告与指纹可查询。
2. 12 个因子均有定义，量价因子可计算，基本面因子严格遵守披露日期。
3. Agent 能生成合法策略草案；非法因子、权重、日期和未来函数假设被后端拒绝。
4. 用户确认后可运行至少一种 Top-N 等权日频策略并保存实验。
5. 相同数据指纹、策略版本和引擎版本重复运行得到相同结果。
6. 回测指标、净值/回撤曲线、年度表现、交易明细和告警可在页面查看。
7. Agent 解读引用的数字全部来自已保存实验结果，不能自行生成指标。
8. 后端 Repository、Service、Controller 和回测核心测试通过；前端关键流程测试与生产构建通过。

## 9. 后续路线

- 第三期：场外基金定投、轮动、再平衡与多资产通用回测。
- 第四期：Python 策略运行沙箱、Notebook、批量参数实验和更完整因子研究。
- 第五期：模拟组合、纸面交易和策略运行监控。
- 自动下单只有在单独的安全设计、权限体系和实盘验证完成后才可能进入路线。
