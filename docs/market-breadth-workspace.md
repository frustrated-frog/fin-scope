# 市场宽度独立分析页

## 定位与页签分工

市场宽度用于分析市场内部参与结构：指数表现是否与多数股票一致，上涨是否有成交配合，不同周期的趋势参与是否同步，强弱两端如何变化。

- 市场全景继续负责指数走势、行业地图和行业轮动。
- 今日雷达继续负责当日发现、研究线索和关注方向。
- 市场宽度负责横截面结构及两日结构对照。
- 历史演变保留连续时间轨迹；原市场宽度下的五日市场节奏轨移到历史演变。
- 转折与情景的判断逻辑不变。

## 页面功能

采用紧凑日期工具栏替换宽度页原有的市场状态大横幅，保持原有页签导航。

1. **指数与个股温差**：选择指数，与个股涨跌幅中位数比较，展示两者差值及上涨、平盘、下跌家数。
2. **参与与成交配合**：比较上涨家数占比与上涨成交额占比；对照日位置以竖线标出。
3. **涨跌幅分布**：当前日与对照日的七档并列柱，支持家数／占比切换、点击分档、查看两端超过3%的占比及涨跌停数量。
4. **趋势宽度**：MA20/60/120/250参与度、各自样本量、50%参考线、对照位置及百分点变化。
5. **新高／新低**：20/60/250日新高与新低家数、占比及净占比对照，三个周期柱长共用比例尺。
6. **结构变化排序**：上涨参与、上涨成交参与、四条均线、新高和新低共12项比例变化，按绝对幅度排序，支持筛选比例上升／下降。
7. **宽度动量**：保留McClellan、10日参与率EMA、TRIN、A-D Line、样本净上涨家数和净上涨成交额，并标明指标含义。

支持历史截面选择、补刷新、对照日期选择、上一观测日、前5个观测日和不对照。快捷日期按可用观测截面计数，不承诺连续交易日。默认对照最近的更早截面。

## 数据口径

- 沿用现有 `GET /api/market-pulse/{date}`。主日和对照日各用完整宽度截面，不用历史序列中缺少分档和有效样本数的简化点代替。
- 对照日期来自已有日期列表与宽度历史日期的并集，排除当前及未来日期，最多保留60个。仅接受工作区日期、宽度日期均与请求日期一致的对照响应。
- 指数 `return1d` 与 `medianChangePct` 本身已经是百分数，不再次乘100；二者差值展示为百分点。
- 价格卡的上涨比例包含平盘。成交卡的两个比例统一排除平盘：上涨家数／（上涨+下跌家数），上涨成交额／（上涨+下跌成交额）。成交参与差为后者减前者，绝对差小于0.5个百分点时描述为“接近”。
- 涨跌分档比例优先由当日分档家数／当日有效行情数计算；零有效样本不转换为0%。涨幅≥3%合并 `UP_3_7` 与 `UP_7`，跌幅≥3%合并 `DOWN_3_7` 与 `DOWN_7`，缺少任一分档时不推算。
- 各周期新高、新低比例按该周期 `valid{window}Count` 计算，不使用全市场行情数。MA参与度使用服务端比例及对应有效样本量。
- 结构变化比较两日各自样本的比例，不表达同一股票群体从某种状态迁移到了另一状态。新低占比上升属于弱势端扩大，筛选名称使用中性的“比例上升／下降”。
- 当前后端的McClellan、参与率EMA、A-D Line和净上涨家数来自本地日K样本，与上方全市场即时行情家数可能不同。A-D Line为近60个观测日的样本净上涨累计，McClellan为样本净上涨家数EMA19减EMA39。
- 净上涨成交额为上涨股票成交额减下跌股票成交额，不是资金净流入。

## 实现与交互

新增组件与纯计算函数放在 `frontend/src/features/market-pulse/`，CSS限定 `mbw-*` 和 `.is-breadth`，没有修改Java、Python、量化策略或共享行情接口。

日期切换取消旧对照请求并立即清空旧对照展示；请求失败保留主日分析，提供独立重试。切换主日重置对照和局部选择；刷新同日后通过 `generatedAt` 更新对照。无有效数据展示“—”或空态。

日期选择、分档切换和筛选均使用原生表单或按钮，具备可见键盘焦点。布局支持深浅主题、窄屏单列和减少动画偏好。图表不运行持续动画。

- 使用真实截面完成1600/1280/1180/900/760/390像素六种宽度检查，无横向溢出；检查了深浅主题、快捷对照、家数／占比切换、分档选择、升降筛选、关闭对照、键盘焦点和减少动画设置。
