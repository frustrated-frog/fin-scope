# 市场全景与演变工作台

本次在当前分支开发。目标是把指数趋势、市场参与度、完整行业分布和行业演变放在同一观察过程。

## UI 决策

- 布局：趋势主图 → 全行业地图与行业详情 → 行业时间矩阵与轮动；顶部统一日期和观察周期，底部可键盘操作的时间轴。
- 主视觉：贯穿交易日的行业颜色矩阵，行表示行业、列表示日期，点击单元格同时切换日期与行业。
- 色彩：浅色底 #f7fafc、深色底沿用项目 #0d192a、文字 #182b43、主线蓝 #347fa1、上涨红 #c85852、下跌绿 #288578。深色主题使用现有可读性更高的对应色。
- 字体：标题 SF Pro Display/PingFang SC；正文系统无衬线；行情数字 SFMono-Regular/Menlo，等宽数字。
- 不用新的大数字仪表盘替代图表；地图面积只表示已说明的权重。行业默认等面积，个股允许按本地样本成交额调整面积。
- 浅深主题、390px 窄屏、键盘焦点、缺数据、快速切换日期均验证。

## 数据与复用

复用 MarketPulseRepository 冻结快照、市场宽度、轮动尾迹、DailyResearch 本地日线缓存及同花顺成分目录；不增加第三方依赖。
新增只读 GET /api/market-pulse/panorama?businessDate=YYYY-MM-DD&limit=60：最近最多60份、截止指定日期的轻量快照，按日期升序。只读取已有快照，无抓取或模型调用。保留真实缺口。
刷新时保留指数最近60根收盘价供归一化走势图使用；旧快照仍可由每日指数收盘价拼接。
日频研究股票补充当前目录的行业代码、名称；历史收益保持指定日期，当前行业归属在 UI 明示，不伪装历史成分。

## 验证

后端测试：截止日期、数量边界、序列顺序和响应日期；指数序列不得包含未来数据。
前端测试：完整行业覆盖、共同基日起点、缺值断线、矩阵/地图/时间轴联动、请求乱序与失败恢复。
浏览器：真实页面的桌面浅/深色和移动端；必要时以明确标注的测试数据验证完整图表。

## 实现与验收（2026-10-04）

- 默认入口切换为“市场全景”，原有今日雷达、转折、宽度、轮动和历史演变保留。
- 20/40/60日观察区间；主要指数共同基日起点比较，以及相对所选指数的收益差；同期成交额、上涨占比、MA20参与度对齐。
- 全行业等面积地图采用固定行业顺序，避免换日期时位置跳动。颜色切换1/5/20日涨跌或上涨占比；点击行业联动详情、矩阵与轮动轨迹。
- 行业下钻到本地成员样本；个股可等面积或按真实成交额比例展示，小面积/缺成交额成员仍可从完整列表进入研究，自选带星标。
- 行业×日期矩阵固定行业列和日期行、支持横向/纵向滚动；方向键选择相邻单元格。时间轴支持前后移动、日期拖动和回到末日。
- 新接口仅读库；旧快照无指数内嵌历史时使用已存逐日收盘价。数据缺口断线/留空，个股响应按日期隔离并忽略过期返回。
- 前端全套114文件572测试通过；生产构建通过（原有大包提示仍在）。Java相关14项测试及Python日频研究19项测试通过。
- 浏览器使用既有30份真实历史快照、90个行业验证桌面浅/深色；390px页面宽度与scrollWidth均为390，无整页水平溢出。实际当日566只本地样本中的半导体成员用于验证下钻与成交额面积图。
- 浏览器测试拦截新历史接口，使用现有接口逐日读取的真实快照；成员字段由本地既有目录补充以匹配新接口。没有改写行情库或生成演示涨跌数据。
- 当前本机Java由IDEA启动，仍运行旧版本；需要重新运行Java与Python进程加载新接口及成员字段。指数60根序列会随下一次行情刷新保存，已有快照可立即作为历史查询来源。
