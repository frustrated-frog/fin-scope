# Market Pulse 日频研究使用说明

入口：Market Pulse → 今日雷达。保留原有复盘、宽度、轮动和历史功能，新增三项日频研究能力。

## 行业机会筛选

选择全部、初步转强、中期强势回落或弱势修复；组合行业名称、最低上涨比例和最高5日涨幅。界面展示规则与实际指标，缺少所需指标的行业自动排除。勾选最多三个行业横向比较；“研究行业/研究已选行业”携带观察日期与行业到已有股票发现页面。

该入口只提供研究上下文，不触发新预测，也不宣称既有报告已按本次行业重新计算。目的页明确展示这个边界。

## 主线与题材地图

默认提供算力建设、机器人、半导体三个空白模板，可以修改名称。点击“维护成员”，每行填写：

```text
600519.SH,贵州茅台,白酒,你的研究笔记或来源
```

这是输入格式示例，不是默认成员或投资推荐。每主题最多50只A股，公司名称、产业环节、归属依据均必填；同一主题不允许重复股票。关系保存在当前浏览器 localStorage 的 `finscope.market-pulse.themes.v1`，不会同步到服务器或其他浏览器，清理浏览器存储会删除配置。

每次保存以北京时间当天作为关系生效日期。早于该日期的历史截面不计算；这是当前篮子的区间表现，不是历史成分回测。切换今日/5日/20日后按有效成员等权计算；至少3只且覆盖率达到80%才展示整体及环节统计。成交额为今日有效成员的金额，不是资金净流入；字段不足时留空。

成员可以直接加入“市场研究”自选分组，或打开现有产业链研究。打开页面或保存成员后，自动检查已保存成员的行情；本地满足连续22个交易日前复权日线时直接复用，否则逐股补齐。成员跨主题去重，最多2只并发、最多250只；切换日期停止旧队列并丢弃旧结果。完成后自动刷新日频研究。展开产业环节可查看每只股票的完整度及缺失原因；失败可点击“重新检查主题行情”，供应商失败后冷却60秒。

单股60秒期限包括排队；服务不会用较短的供应商结果覆盖已有长历史，也不会混合不同复权批次拼接。若供应商无法提供足够历史、股票停牌或上市不足22个交易日，仍会显示缺口，不承诺每只股票都能补齐。

## 赚钱效应与信号跟踪

以所选日期的前一交易日数据确定成员，观察所选日期的表现：

- 强势股：前一交易日涨幅至少3%。
- 趋势股：前一交易日收盘高于MA20且5日收益为正。
- 突破股：前一交易日收盘高于此前20个交易日最高收盘。

在原“基础赚钱效应”位置增量升级，不调整其他区域的布局和功能：

- 群体对比：每组展示入组/有效数量、今日收益中位数、收涨比例和跌幅至少3%的比例。三组中位数使用同一条以零为中心的比例尺，点击切换下方观察组。
- 昨日信号的今日表现：上涨（>1%）、横盘（-1%至1%，含端点）、回落（<-1%）的分布及成员。缺行情单独列出，不计入比例；点击分类展开原有成员研究、加入自选入口。
- 今日机会结构：展示新转强、持续强势、弱势修复、强势转弱的数量及较前一交易日增减。仅比较两日走势状态均可判断的同一批股票；其他走势与待补齐数量单列。点击查看对应成员及当前行业分布。
- “仅看自选”按需读取当前自选股票，重新计算整个面板。自选加载失败可局部重试；基金及行业关注不混入股票分组。

趋势条件沿用现有规则：收盘高于MA20且5日收益为正。昨日不满足、今日满足为“新转强”；两日均满足为“持续强势”；昨日满足、今日不满足为“强势转弱”；两日均不满足但今日收涨为“弱势修复”，其余为其他走势。这里“新”只表示相对昨日发生变化。

当日缺失仍保留昨日分组成员；有效数量少于5只时不输出组统计。组间允许重叠。机会结构互斥，行业归属采用当前目录，多重归属可重复计数。成员默认折叠、按需展示30只；窄屏堆叠展示，不新增页面级横向滚动。

Python日频计算缓存算法升级至 `daily-research-v1.2`，沿用原查询接口并兼容旧字段。Java与Python服务需要重启以加载新增走势字段；旧服务结果仍可显示群体对比与延续分布，机会结构显示待补齐。

所有数据来自Python行情服务已有日K快照；不代表完整全A。连续交易日与复权条件不满足时不计算多日指标。未知年份交易日历、非交易日、未来日期和当日15:30之前失效关闭，不用其他日期冒充。当前沿用项目已维护的2026年交易日历；更新年份前需要维护日历。

快照可能被后续抓取和前复权重算覆盖，结果是基于当前本地库的回看，不是不可变的时点数据库。损坏日K逐条跳过并给出汇总说明。收益单位为百分点，上涨比例等比例字段为0..1。

## 运行与验证

需要重启更新后的Java后端和Python行情服务；前端按原方式启动或重新构建。接口为：

- Java：`GET /api/market-pulse/research/{businessDate}`
- Python：`GET /v1/markets/CN-A/daily-research?business_date=YYYY-MM-DD`
- Java成员补齐：`POST /api/market-pulse/research/{businessDate}/members/{instrumentCode}`
- Python成员补齐：`POST /v1/markets/CN-A/daily-research/members/{instrumentCode}?business_date=YYYY-MM-DD`

Java复用 FinanceHttpClient，版本/日期/字段/成员关系校验后经 Service 和独立 Web Response 返回。样本读取独立加载，失败可重试，不阻塞行业筛选和原有工作台。

2026-09-12验收：Python相关回归80项通过；Java相关市场测试45项通过，另用真实Python输出完成Java契约冒烟验证。真实本地库查询2026-09-11：检查2948只，返回365条可展示记录，读取约13.7秒（单次测量）；各组均保留缺失当日的成员。前端全量91个文件、473项测试及生产构建通过（保留既有大分包提示）。前端覆盖条件筛选、比较、导航来源、主题字段/去重/覆盖/生效时间、保存、自选、失败重试与请求竞争；浏览器1440px/390px验收均无整体横向溢出。

页面视觉验收使用独立临时入口，行业为标明的演示数据，股票组为真实本地输出；未覆盖或重启原有正在运行的服务。没有改动本地运行密钥与用户锁文件。


## 2026-09-13 增量验收

日频结果按观察日期、算法版本和日K修订号持久缓存，保留最近20个日期。日K插入、修改和删除均使缓存失效；同秒更新、其他进程更新也能识别，报价更新不触发重算。计算期间数据变化不会写入错误版本。页面展示结果生成时间和缓存命中状态；缓存不改变样本与历史回看口径。

真实本地库2026-09-11截面、2948只股票：首次计算11.750秒，再次命中0.004秒（单次测量，非性能保证）。重启后Python和Java接口均返回cache_hit/cacheHit=true并保留同一生成时间。实际成员600519.SH返回READY、22/22、FUYAO_TONGHUASHUN_API来源。运行中的Java/Python均已重启更新；浏览器使用独立测试会话验证保存成员自动补齐及结果刷新。

前端全量494项通过、生产构建通过；Java相关40项通过；Python全量398项通过，最终边界修复后相关65项通过。覆盖并发上限、去重、日期切换、失败重试、损坏数据修复、非有限OHLCV、短历史保护、排队超时和缓存失效。构建仍有既有分包大小提示。没有改动已有本地配置与用户锁文件。

## 个人关注与机会首页（2026-10-04）

“今日雷达”在原有市场概览下增加双栏：左侧“与你有关的今日变化”，右侧“关注方向的新机会”。原有行业筛选、题材地图、赚钱效应与导航保留；窄屏按顺序单列展示。

- 在自选股票或基金卡片点击“关注理由”，填写为什么关注、接下来观察什么、关注方向。内容写入本地 SQLite，留空保存可清除；不依赖浏览器 localStorage。卡片展示两行以内摘要。
- 左侧可筛选公司动态、行业变化和跟踪进展。公司事件、归因报告与观察变化来自既有模块保存的数据，展示观察日期及之前七个自然日的记录；行业变化与个股相对行业的明显偏离使用所选交易日行情。
- 行业关联来自已登记的行业代码、与行业名称一致的关注方向、同日股票发现已有的行业成员关系。关注理由和后续观察以“我的关注点”展示，不自动判定某条新闻已经验证你的判断。
- 右侧最多展示两个关联方向及两个其他市场方向，从当日上涨行业中按轮动得分、涨幅排序。同日股票发现已纳入候选的相关公司可加入自选；已自选公司不重复展示添加按钮。最新报告日期不一致时保留行业入口，不混入其他日期的候选。
- “查看事件”进入投资观察原有详情，“查看归因”打开原有报告，“查看公司”打开自选详情，“查看方向与候选”携带行业和日期进入股票发现。
- 尚无自选时显示“添加自选股”入口，市场机会继续展示。当前入口沿用已有手动添加自选能力，不新增批量导入器。

重启 Java 后端后自动添加兼容字段；前端开发服务热更新，生产部署需重新构建。没有改动配置、密钥或真实运行数据库。独立浏览器验收使用明确标注的演示公司和内容，不代表真实行情。

本批验证：后端相关16项通过；前端112个测试文件、565项通过；TypeScript与Vite构建通过，保留既有包大小提示。桌面浅色、桌面深色及390px手机界面已检查，手机页面与抽屉宽度均390px，无横向溢出。临时验收入口已移除。
