# Market Pulse 日频研究使用说明

入口：Market Pulse → 今日雷达。保留原有复盘、宽度、轮动和历史功能，新增三项日频研究能力。

## 行业机会筛选

选择全部、初步转强、中期强势回落或弱势修复；组合行业名称、最低上涨比例和最高5日涨幅。界面展示规则与实际指标，缺少所需指标的行业自动排除。勾选最多三个行业横向比较；“研究行业/研究已选行业”携带观察日期与行业到已有股票发现页面。

该入口只提供研究上下文，不触发新预测，也不宣称既有报告已按本次行业重新计算。目的页明确展示这个边界。

## 主线与题材地图

默认提供算力建设、机器人、半导体三个空白模板，可以修改名称。点击“维护成员”，每行填写：

```text
600519.SH,贵州茅台,白酒,你的研究笔记或来源
```

这是输入格式示例，不是默认成员或投资推荐。每主题最多50只A股，公司名称、产业环节、归属依据均必填；同一主题不允许重复股票。关系保存在当前浏览器 localStorage 的 `finscope.market-pulse.themes.v1`，不会同步到服务器或其他浏览器，清理浏览器存储会删除配置。

每次保存以北京时间当天作为关系生效日期。早于该日期的历史截面不计算；这是当前篮子的区间表现，不是历史成分回测。切换今日/5日/20日后按有效成员等权计算；至少3只且覆盖率达到80%才展示整体及环节统计。成交额为今日有效成员的金额，不是资金净流入；字段不足时留空。

成员可以直接加入“市场研究”自选分组，或打开现有产业链研究。打开页面或保存成员后，自动检查已保存成员的行情；本地满足连续22个交易日前复权日线时直接复用，否则逐股补齐。成员跨主题去重，最多2只并发、最多250只；切换日期停止旧队列并丢弃旧结果。完成后自动刷新日频研究。展开产业环节可查看每只股票的完整度及缺失原因；失败可点击“重新检查主题行情”，供应商失败后冷却60秒。

单股60秒期限包括排队；服务不会用较短的供应商结果覆盖已有长历史，也不会混合不同复权批次拼接。若供应商无法提供足够历史、股票停牌或上市不足22个交易日，仍会显示缺口，不承诺每只股票都能补齐。

## 基础赚钱效应

以所选日期的前一交易日数据确定成员，观察所选日期的表现：

- 强势股：前一交易日涨幅至少3%。
- 趋势股：前一交易日收盘高于MA20且5日收益为正。
- 突破股：前一交易日收盘高于此前20个交易日最高收盘。

每组展示可判断数量、入组数量、今日有效数量和覆盖率，以及收益中位数、上涨比例、收益分布和成员名单。当日缺失仍保留成员；有效数量少于5只时不输出组统计。组间允许重叠。

所有数据来自Python行情服务已有日K快照；不代表完整全A。连续交易日与复权条件不满足时不计算多日指标。未知年份交易日历、非交易日、未来日期和当日15:30之前失效关闭，不用其他日期冒充。当前沿用项目已维护的2026年交易日历；更新年份前需要维护日历。

快照可能被后续抓取和前复权重算覆盖，结果是基于当前本地库的回看，不是不可变的时点数据库。损坏日K逐条跳过并给出汇总说明。收益单位为百分点，上涨比例等比例字段为0..1。

## 运行与验证

需要重启更新后的Java后端和Python行情服务；前端按原方式启动或重新构建。接口为：

- Java：`GET /api/market-pulse/research/{businessDate}`
- Python：`GET /v1/markets/CN-A/daily-research?business_date=YYYY-MM-DD`
- Java成员补齐：`POST /api/market-pulse/research/{businessDate}/members/{instrumentCode}`
- Python成员补齐：`POST /v1/markets/CN-A/daily-research/members/{instrumentCode}?business_date=YYYY-MM-DD`

Java复用 FinanceHttpClient，版本/日期/字段/成员关系校验后经 Service 和独立 Web Response 返回。样本读取独立加载，失败可重试，不阻塞行业筛选和原有工作台。

2026-09-12验收：Python相关回归80项通过；Java相关市场测试45项通过，另用真实Python输出完成Java契约冒烟验证。真实本地库查询2026-09-11：检查2948只，返回365条可展示记录，读取约13.7秒（单次测量）；各组均保留缺失当日的成员。前端全量91个文件、473项测试及生产构建通过（保留既有大分包提示）。前端覆盖条件筛选、比较、导航来源、主题字段/去重/覆盖/生效时间、保存、自选、失败重试与请求竞争；浏览器1440px/390px验收均无整体横向溢出。

页面视觉验收使用独立临时入口，行业为标明的演示数据，股票组为真实本地输出；未覆盖或重启原有正在运行的服务。没有改动本地运行密钥与用户锁文件。
