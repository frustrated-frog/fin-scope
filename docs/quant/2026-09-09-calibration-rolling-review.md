# 次日方向 E0：校准与滚动训练真实对照

日期：2026-09-09。实现分支：`codex/next-session-joint-ranking`。

## 结论

第一阶段 E0 已实现真实时序样本外概率、加权单调校准、日期等权概率诊断和可重放的交叉实验。**未证明方向准确率提高，测试前选中的新方法没有超过固定基础树加旧校准。新方法保持离线研究，不替换线上预测。**

构造反例与真实股票结果不同：新校准保住了原本校准准确的 47%/51% 概率，但当前真实基础树从旧校准中获益。不能把构造反例当作线上退化的已证实原因。

## 固定口径

缓存 SHA256 顺序固定 240 股，54 特征；测试信号从 2026-06-15 开始，最后成熟目标日 2026-09-08；60 个信号日期、13290 个股票日，其中 279 个零涨跌归非上涨。日期等权、日期内股票等权，分类阈值 0.5。

这是已参与研发的回溯数据，存在缓存股票池的存活及选择偏差，不是全 A 股前瞻准确率。本文所有百分数均来自相同 240 股实验，不与完整 1198 股报告混算。

候选族 BASE_TREE / FULL_TREE / POOLED_LOGISTIC；新校准 RAW / INTERCEPT / PLATT（恒等收缩 0.001、0.01、0.1），旧 Platt 单独保留。每五个交易日重训，最多 505 个训练日期，校准使用过去 60 日期同族成熟 OOF；标签退出日期严格早于批次首日。48 次实际拟合，测试区包含 12 次拟合。不是将一个固定模型的成绩切成多段冒充滚动。

选择区 2025-12-11 至 2026-03-13 的成熟标签选出 `BASE_TREE:PLATT_0.1`；选择结束边界为之后 calibration 区的首日。该候选预先门槛合格，选择区准确率 50.996%，BA 50.963%。之后规则固定，允许成熟标签进入后续重训，但不使用最终测试成绩重新选方法。

## 同池同日结果

|训练与校准|准确率|平衡准确率|Brier ↓|预测上涨占比|总体 AUC|同日 AUC|

固定与滚动使用同一个测试前选定的基础树族。固定模型保留旧 train 区与独立 calibration 区，滚动模型用历史 OOF 校准；因此校准数据分布也不同，不能将整个差值仅归因于重训频率。

相对固定基础树＋旧校准：滚动＋新校准准确率差 -4.385 个百分点，日期分块区间 [-10.311, +1.619] 个百分点；Brier 差 +0.007216，区间 [-0.001492, +0.017392]。区间使用 2000 次、5 日期循环移动分块，并对两个基准作 Bonferroni 校正，每项 97.5% 区间。没有可信增益。

**54.04% 是本次基础树对照成绩，不是线上原选模器的成绩，也不是这轮研发实现的提升。** 原 v3 在相同 240 股实验中预先选中了逻辑回归，成绩另见上一轮报告。

## 对下一步建模的意义

1. 同日 AUC：固定原始基础树 0.5309，滚动原始基础树 0.5340。滚动更新仍有同日区分线索，但绝对概率尚不准确。
2. 滚动新校准保持同日 AUC 0.5340，却把总体 AUC 从 0.5242 降到 0.5012。单调映射在每个批次内保序，不保证不同批次之间的概率可比。这是跨日期概率水平需要研究的线索，不是单独因果证明。
3. 旧 Platt 在固定模型下提高命中，在滚动下只预测 4.37% 样本上涨；旧斜率没有单调约束，在 2026-06-30、2026-07-21 两轮测试批次确实为负，会反转同日排序。不能将旧校准一刀切移除，也不能不检验地沿用。
4. 下一项应在强日线基线与真实 OOF 上增加小型市场条件/相对强弱残差修正，分别检验市场分量、相对排序和交互项。历史行业、分钟数据作为独立新增信息实验，不把“重新校准”当作新增信息。
5. 本次测试已看过，任何下一步选择都属于进一步回溯研发。最终需要新的前瞻冻结记录，不承诺固定胜率或 +2 个百分点。

## 代码和复现

- `forecast/direction_calibration.py`：新方向校准独立模块，斜率非负，正则中心 (1,0)，权重统一，无 0.005 损失退化容忍；旧共享校准器不变。
- `forecast/rolling_direction.py`：同族、同更新规则 OOF，成熟标签清除，五日更新，测试前选择，记录每批训练截止、校准截止、参数及模型年龄。
- `forecast/direction_evaluation.py`：总体与有效日期内 AUC、上涨预测占比、日期等权分位数、Log Loss，保留原有配对分块比较。
- `scripts/evaluate_rolling_direction.py`：只读行情加载，保存全部训练特征及逐条 OOF 概率，支持冻结输入重放，运行期间源码变化时拒绝产出汇总。
- 两个现有入口共享 `NextSessionForecast`，新报告可展开校准前后命中、BA、上涨占比、Brier、参数、训练截止。历史报告缺少字段时仍正常展示；不改写旧报告。

在 `market-data-service` 目录：

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/evaluate_rolling_direction.py --as-of 2026-09-08 --max-symbols 240 --output data/quant/rolling-e0-2026-09-08.json
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/evaluate_rolling_direction.py --as-of 2026-09-08 --frozen-inputs data/quant/rolling-e0-2026-09-08.inputs.npz --output data/quant/rolling-e0-replay-2026-09-08.json
```

两次执行选模、所有比较指标和全部批次校准参数完全一致。正式复现证据使用第二次 replay 产物；第一次执行期间另有页面审计代码开发，第二次执行对源码起止指纹进行了严格一致性核验。

本地实验产物在被 Git 忽略的 `market-data-service/data/quant/`：汇总 `.json`、冻结特征 `.inputs.npz`、全部 OOF `.predictions.jsonl.gz`、同日测试概率 `.test.npz`。不提交市场数据到仓库。

源码指纹：`2f1cb4cbec0d2cfa5820b2dcc0c700ab773ec5e5220c3ea1959994b868ce8ebb`。

当前数据接入核验：行情快照库只有 DAILY_BARS、CAPITAL_FLOW、CORPORATE_ACTIONS、VALUATION_SNAPSHOT，没有分钟行情能力；源码未发现 Tushare / stk_mins / minute_bars 接入。后续分钟实验需要真实数据接入，不能用日线插值伪造。
