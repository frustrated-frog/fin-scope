# 量化强化与历史对照验收（2026-09-09）

本批在 `codex/next-session-joint-ranking` 实施，沿用股票发现、单股预测，不新增 Tab。核心结论：收益估计相对旧版本有所改善，方向准确率尚未得到提升证据；因此近期概率模型保留为候选对照，未替换正式概率。

## 已实施的量化变化

1. **近期模型与历史验收分离**：1/5/20 日模型增加最多 504 条成熟训练样本、最多 60 个非重叠校准锚点。训练标签不得跨入校准区；历史 qualification 保持独立。报告记录训练与校准截止日、候选概率及独立比较结果。
2. **概率候选先比较**：独立近期窗口至少 20、最多 30 个锚点，候选在窗口前完成训练和校准。比较 Brier 与方向命中。此次整体历史 Brier 未改善，正式上线模式保持 `SHADOW`；即便个别股票通过局部门槛，也不将其包装成整体升级。
3. **收益幅度与区间分别验证**：按信号日历史波动率归一化收益目标，近期重训分位数模型，用独立校准残差调整区间。替换必须同时改善相对原模型的 MAE、胜过零收益 MAE，并改善惩罚漏覆盖与过宽区间的 interval score。未通过保留旧输出。
4. **行业同行信息**：两处入口使用已归档、当日可用的行业成员，计算至少两个同行的 20 日等权动量与个股相对动量。排除自身、要求价格窗口完整、不向过去回填今天的成员。它是同行动量特征，不冒充行情供应商的行业指数。既有归档短，多数历史日期仍然缺失。
5. **评价与时点纠错**：没有最终候选成熟收益时不再报 HEALTHY；昨天收盘数据可用至目标交易日 09:30 前，跨午夜不再错误阻断次日预测。
6. **实跑阻塞修复**：热门板块调用增加等待上限，超时后走现有有效快照降级，保留快照来源与质量说明。

## 历史对照方法

原概率和原收益预测取自数据库中保存的报告。按入口、股票、信号日、周期去重，采用最早记录。排除收盘前生成、入场开盘后补做、缺行情或标签未成熟的记录。5 日收益口径为 T+1 开盘到 T+6 开盘，扣原策略成本；这与“次日收盘涨跌”是两个不同任务。

新候选只读取信号日及之前的行情，训练与校准仅使用当时成熟的标签。行情使用当前前复权缓存重建，不是当时完整行情快照；数据库只读事务固定一次比较中的输入，结果不能称为前瞻测试。缺少足够历史或旧报告缺少模型标识时，保留原输出并记录原因，不能删掉这些案例以提高成绩。

复核共 110 条成熟记录，其中 5 日 106 条，覆盖 74 只股票、10 个信号日（2026-08-11 至 2026-08-27）；1 日仅 3 条、20 日仅 1 条，不能据此评价短长周期效果。

| 5 日指标 | 原报告 | 最终上线方案的历史对照 |
|---|---:|---:|
| 方向正确 | 64 / 106（60.4%） | 64 / 106（60.4%） |
| 方向错误 | 42 | 42 |
| Brier，越低越好 | 0.24170 | 0.24170 |
| 收益幅度 MAE | 6.063 个百分点 | 5.858 个百分点 |
| 区间覆盖率 | 53.8% | 64.2% |
| 平均区间宽度 | 8.98 个百分点 | 13.81 个百分点 |
| 区间评分，越低越好 | 0.3411 | 0.3089 |

不能只看平均数：原来方向正确的 64 条，幅度 MAE 5.982 → 5.563 个百分点；原来方向错误的 42 条，MAE 6.187 → 6.308 个百分点，反而略差。零收益预测在这批记录的 MAE 为 5.760 个百分点，最终方案整体仍未胜过它。名义 80% 区间的实际覆盖也只有 64.2%。因此只能认定相对原收益模型有局部改善，不能认定已有稳定的收益预测优势。

直接替换近期概率曾在 58 条可拟合记录上从 34 条命中降到 26 条；增加逐股比较后命中恢复为 34 条，但 Brier 仍恶化。这两次尝试均已披露，未作为正式概率发布。

## 仍值得强化的量化不足

- 大幅上涨和下跌的尾部事件仍难覆盖。例如保存的 2026-08-20 / 603618.SH 记录，实际 5 日净收益约 +40.5%，旧幅度预测不足 +1%；近期模型仍远低估。这不是提高概率置信度就能解决的问题。
- 误判股票组没有被近期重训稳定修复。下一批研究应优先验证带可用时点的行业相对强弱、市场状态与事件信息，而不是继续调当前窗口参数。
- 行业档案尚短，只能逐步积累；禁止用今天的归属名单制造过去的行业覆盖。
- 正式概率保留基准，近期候选随新报告存储。之后必须使用方案冻结后的新日期检验候选，不能再把本次参与研发的历史当独立成果。

## 可复现入口

从 `market-data-service` 目录运行：

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 PYTHONPATH=src .venv/bin/python scripts/compare_recent_forecasts.py \
  --database /absolute/path/finance.db \
  --snapshots /absolute/path/market-data-snapshots.db \
  --output /absolute/path/comparison.json
```

输出包含逐条原值/新值、成熟收益、回退原因、周期分组、原正确/错误组、零收益基准和输入指纹。缓存更新可能使之后重放的结果变化；原报告不被改写。

## 研究依据与实现边界

- [DoubleAdapt](https://arxiv.org/html/2306.09862v3)：参考非平稳市场中近期适应的研究方向。本次不是 DoubleAdapt 元学习算法复现。
- [HIST](https://arxiv.org/html/2110.13716v2)：参考同行关联信息的建模价值。本次仅增加可用时点约束下的同行动量，没有复现概念图网络。
- [MASTER](https://arxiv.org/html/2312.15235v1)：参考市场信息与股票关联共同建模的方向；论文的截面排名任务与本项目原始涨跌概率不同，论文成绩不能直接迁移到本项目。
