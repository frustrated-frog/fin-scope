# 历史行业信息直接分类：真实实验结果

本轮完成用户授权的四步工作：核实并采集行业历史、完整截面预测、日线与日线加行业的受控对照、多个历史窗口评价。结果是**尚未形成可信的次日方向增益**，因此不替换线上模型。已有股票发现和单股预测页增加同一份历史研究摘要，没有新增 tab。

## 实际数据

申万官网 `StockClassifyUse_stock.xls` 实测返回 HTTP 508。改用巨潮 `p_stock2110` 行业归属变更接口，参考现有 AKShare 适配代码，通过项目 providers 层的 HTTP 客户端采集。旧研发池的 240 只股票全部成功，共 266 条分类编码 008003 的申万行业变更记录，包含 28 个历史一级行业名称；有效日期跨度 1991-01-29 至 2026-07-01。历史名称可能经历分类修订，不能直接宣称是统一的 SW2021 全历史。

原始响应、请求截止、采集时间与 SHA256 保存于 `market-data-service/data/quant/cninfo-industry-e2-2026-09-10-raw/`，规范记录在同名前缀 JSON 中；没有购买数据权限或新增依赖。

**可用时间限制：** 接口没有返回当时的公告发布时间，`available_at` 保持空。研究明确采用 `VENDOR_RECONSTRUCTION`，变更日期后一个自然日可用是实验假设，不是证明。这轮不能作为严格 PIT 或真实前瞻证据。另有 OBSERVED 模式，保守地从实际可用/采集日期的次日才纳入，避免晚上观察进入当天收盘特征。

参考来源：[AKShare 行业变更适配实现](https://github.com/akfamily/akshare/blob/main/akshare/stock/stock_industry_cninfo.py)、[巨潮接口文档入口](https://webapi.cninfo.com.cn/#/apiDoc)。供应商变更记录只解决历史归属线索，不能证明公告时点、历史数据修订和商业使用授权。

## 如何保证比较的是行业增量

旧冻结输入缺少可观测未成熟股票，已从日线缓存重新构建同一 240 股票池并保存 v2 面板。重建输入与旧 E0 概率并非同一份数据，不把旧 54.04% 当作本次可直接比较的基准。

- **D**：现有市场、价量和日线截面特征，排除旧行业相关六列。
- **D+S**：D 加行业同行 1/5/20 日强弱、上涨广度、成交活跃度、离散度、个股相对同行表现、行业相对全池表现及同行数量/覆盖/缺失，共 12 列。
- 同行计算剔除自身。少于两个同行时经济特征缺失，NaN 与显式覆盖指标保留；没有用零冒充中性。
- 行业特征在完整 observable panel 上计算。两臂都先为全部可观测股票推断，再挂接标签；标签只用于已经成熟的训练、过去 OOF 校准和事后评分。
- 参数沿用固定 LightGBM PARAMETERS，种子 42，每 5 个交易日更新，最多 505 个成熟训练日期，过去 60 日 OOF 截距校准。阈值固定 0.5，日期等权、日期内股票等权。
- 主对照固定为 INTERCEPT，RAW 仅诊断；没有看到结果后切换主方法、校准或种子。协议文件先于训练落盘。

测试前预热从 2025-09-10 开始。三个测试窗口共 180 个信号日期：2025-12-11 至 2026-09-07。窗口内共生成 42,282 个股票日预测，其中 42,077 个有成熟标签，覆盖 99.515%；205 个缺标签股票日没有被偷偷移出预测截面，原因未获证实，不擅自都称为停牌。准确率仅针对可评分标签，不能视为未评分股票同样准确。行业同行特征在含预热的预测行中可用比例约 97.98%。

## 结果

### 预先指定的主对照（统一截距校准）

| 信号日期 | 日线 D | 日线＋行业 D+S | 差值 |
|---|---:|---:|---:|
| 2025-12-11～2026-03-16 | 48.048% | 47.711% | -0.337 个百分点 |
| 2026-03-17～2026-06-12 | 51.972% | 51.909% | -0.063 个百分点 |
| 2026-06-15～2026-09-07 | 46.732% | 47.125% | +0.394 个百分点 |
| 合计 180 日 | **48.917%** | **48.915%** | **-0.002 个百分点** |

整体差值的 95% 五日移动分块区间约为 **[-1.033, +1.086] 个百分点**。平衡准确率为 48.493% → 48.455%；Brier 为 0.255235 → 0.254941，差值区间 [-0.000918, +0.000334]，也跨过零。

相对日线模型，行业模型救对 821 个股票日、改错 811 个。原始计数略好，但日期等权救对率 1.9266%、改错率 1.9288%，净变化仍略负。不能用未加权计数替代预设日期等权指标。

### 未校准概率诊断

整体方向准确率 **51.197% → 51.232%**，增加 **0.036 个百分点**；95% 差值区间 **[-0.414, +0.482] 个百分点**。三个窗口分别略降、近乎持平、略升。平衡准确率 50.940% → 50.982%，Brier 0.253591 → 0.253329。

RAW 高于 INTERCEPT 提示该校准设置在这些历史窗口损害方向命中，但这不是允许事后把 RAW 改成主实验的理由。行业增量在两种预先列出的输出里都很小，尚无稳定优势。结果只否定本轮“固定研发池、这些同行特征、该模型与更新方式”的充分性，不能断言任何行业信息都无效。

## 实现与重放

新增主要代码：

- `industry_models.py`、`providers/cninfo_industry.py`：领域记录与外部协议分离，校验证券代码、标准、完整响应、同日冲突。
- `forecast/historical_industry.py`：独立可用时间口径及同行剔除自身的完整截面特征。
- `forecast/observable_direction.py`：完整截面直接分类滚动推断，标签成熟后才用于学习。
- `scripts/fetch_industry_history.py`、`scripts/evaluate_industry_increment.py`：真实采集、双臂固定协议、窗口评价、纠错归因及不可覆盖的研究输出。
- `DirectionResearchComparison.tsx`：现有两处量化页面显示行业实验主结果、三个窗口、区间、未校准诊断及数据局限。数据为明确标注的静态研究快照，不是实时单股上涨概率。

在 `market-data-service` 目录执行（输出名必须未占用）：

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/fetch_industry_history.py --inputs data/quant/rolling-e0-replay-2026-09-08.inputs.npz --output data/quant/cninfo-industry-e2-2026-09-10.json --end-date 2026-09-10
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/evaluate_industry_increment.py --inputs data/quant/industry-e2-2026-09-08.panel.npz --industry data/quant/cninfo-industry-e2-2026-09-10.json --output data/quant/industry-e2-new-replay-2026-09-08.json --as-of 2026-09-08
```

首次结果 `industry-e2-2026-09-08.json`，最终源码重放 `industry-e2-replay-2026-09-08.json`。两次全部概率数组、98 个训练批次、所有窗口及整体评价逐项完全一致。两次之间只修复未用于本实验的 OBSERVED 晚间可用时间边界、加强输入不变校验；VENDOR_RECONSTRUCTION 实际特征和模型参数不变。协议源代码指纹因此不同，数据和结果相同。

验证：357 项 Python 测试通过；覆盖删除未来标签、改动未来标签、追加未来数据不影响早期推断，以及同行剔除自身和晚间观察边界。前端研究摘要/股票发现测试 4 项、单股预测测试 9 项通过，生产构建通过；只有既有 Starlette 与大 chunk 提示。浏览器已在股票发现与已有单股报告中实际展开核验 48.917% / 48.915%、180 日范围和“不可信提升”的结论。Python 和前端已重启，健康/股票发现状态/前端均 HTTP 200。

提交前自检：无新增依赖、无 Spring/Java 改动，外部调用位于 providers，领域记录不放进 HTTP 实现，按相邻 Python 风格实现并通过 diff 检查。原有 application.yml 与 pnpm-lock.yaml 用户改动保留。
