# 可执行量化最小闭环

## 边界与契约

输入为版本化协议、显式交易日历、每五个交易日的完整候选截面和原始成交日线。协议示例见 executable-protocol-v1.json；其中资金和费用仅为模拟研究参数，不声明适用于任何真实账户或全部历史日期。固定信号时间为上海时间 15:30，参考成交为下一交易日 09:30，标签退出为买入后第五个交易日开盘。

复用 QuantBacktestEngine、PortfolioLedger、PerformanceMetrics；不创建新的回测引擎。Python 标签复用现有特征，仅输出 price_return，不输出账户净收益。Java 在订单层计算最低佣金、滑点和现金占用。新类型位于 domain/quant/execution，跨层稳定枚举位于 common/enums/quant。

首版回放无数据库和券商副作用。相同输入返回相同结果和指纹。未知协议、日期不一致、未成熟训练标签、重复股票日、缺失执行状态、前复权成交价格均拒绝。没有冻结信号不能自动回退模型或使用今天的候选池。空候选批次明确表示目标为空，与丢失批次不同。

公司行为暂不自动处理：首版仅接受有证据确认区间内无分红送转的执行数据；存在公司行为或证据缺失时阻断。不得通过删除发生公司行为的股票宣称全市场无偏结果。后续接入既有真实持仓流水的公司行为语义后才能扩展区间。

成交状态是明确记录的开盘模拟假设，不接受收盘涨跌停状态倒推成交。数据来源证据是可审计声明，不是自动验证供应商真实性。交易日历必须由调用方提供已经核验的版本与完整序列。

## 分批验收

1. 共享协议与五个交易日开盘标签：缺行情不顺延、未来信息不影响特征、未成熟标签不输出。
2. 冻结信号接入既有账本：固定槽位留现金、现金及集中度约束、失败订单留痕、重复回放一致、每日估值。
3. 提供 HTTP 回放入口、完整示例与报告：先证明执行闭环，模型重训、A/B/C 对照与持续模拟留待后续批次。

## 已实现入口与使用

后端提供 `POST /api/quant/executable-replays`，请求体为冻结 JSON，返回项目统一响应信封。此入口无数据库、模型调用或自动下单副作用；响应中的 `data.frozenInput` 可作为下一次请求体，`inputFingerprint` 标识完整输入，`engineVersion` 标识计算语义。字段格式见 `examples/executable-replay-synthetic.json`。该例全部为合成数据，不是历史市场实验。

从仓库根目录、在后端运行后执行：

```bash
python3 market-data-service/scripts/replay_executable_quant.py \
  --input docs/quant/examples/executable-replay-synthetic.json \
  --output /tmp/finscope-executable-synthetic
```

输出 JSON 包含协议、原始冻结输入、候选与拒绝理由、每期目标权重、逐笔成交价与费用、失败订单、每日现金与持仓估值；同名 Markdown 展示账户摘要、订单和每日净值。工具拒绝覆盖已有结果。也可使用 `--result 已保存的结果.json` 离线渲染报告。

### 数据生产方必须保证的条件

- `signals` 每五个日历交易日一批，包括明确的空候选批次。最后一天不生成无法执行的新信号。起始日锚定调仓节奏；不按自然周一调仓。
- `protocolVersion` 必须为 `OPEN_5D_V1`，不能将 `NEXT_CLOSE_RETURN` 改名导入；训练标签成熟截止时间严格早于信号截止。`rankingScore`、可选 `predictedPriceReturn` 和账户净收益互不替代。
- 原始价格与研究前复权价格分开提供。现有 `PythonQuantDailyBarSource` 的 QFQ 输出不能直接提交到该入口。
- 冻结全候选截面，`eligible=false` 必须附拒绝原因；历史主板、ST、上市历史和可交易资格的证据由数据生产方负责，服务不根据今天的股票名称推断历史资格。
- 行情必须覆盖全部候选与全部日历日期。停牌也提供 `SUSPENDED` 状态和有依据的估值，不能删行或拿复牌日填补目标日。首版拒绝区间内行业分类变化。
- 开盘状态包括 `TRADABLE`、`BUY_BLOCKED`、`SELL_BLOCKED`、`SUSPENDED`；它是开盘模拟约束，不是日终涨跌停布尔值。
- `hasCorporateActions` 必须显式为 false，且附无公司行为的区间证据。这一条件目前限制真实数据回放范围；不是宣称已经实现分红送转核算。
- 费率在整个回放区间固定。跨费率生效区间应先补版本化费用规则；不得用示例费率宣称精确历史成本。

### 账户规则与局限

最多五槽位，单槽不超过总仓位预算除以五和单股上限。行业预算不足时跳过该候选；候选不足不重新分配现金。调仓按持仓差额，卖出后再买入；现金竞争沿用现有账本的证券代码顺序，不声称按排名优先成交。买入失败不临时补选，也不在次日自动追单；下一调仓批次重新计算。

新增买入同时受可用现金、总仓位、单股和行业剩余预算限制；无法卖出的股票继续占用这些预算。实际价格跳变或被动持仓可能越过上限，限制新增风险不能保证任何时点的实际权重都不超限。当前固定五日调仓且单日单次撮合，无当日买入再卖出路径；尚未提供通用可卖股份批次账本。

剩余持仓在区间末按收盘价估值，不强制平仓，不能将期末净值等同于清算后现金。公司行为尚不支持。历史研究基准沿用引擎输入行情的等权收益，不是同资金可执行基准，也不能用于宣布 A/B/C 胜负。

该版本交付交易协议与账户回放入口。真实历史输入自动组装、新目标模型训练、A/B/C 批量比较、持续模拟持久化、真实成交通道对照均未接入，后续开发应继续沿这条链路推进。
