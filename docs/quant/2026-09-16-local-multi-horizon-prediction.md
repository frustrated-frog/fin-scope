# 本地多周期预测与次日模型加强

本版不依赖大模型 API。次日单股预测接入 `local-prediction-v3`，并新增一日/五日收盘收益的本地滚动对照工具。历史多股票联合预测仍遵循原有独立门禁，未通过资格检查时不会覆盖单股预测。

## 次日模型

- 本地候选为逻辑回归、原有直方图提升树和 LightGBM。使用既有量价/上下文特征；没有虚构新增信息源或扩展超参数搜索。
- 历史依次划分训练、30 样本模型选择、60 样本校准区，校准区再分为拟合和独立检查。跨分段到期的标签剔除，训练最多 504 个样本。
- 逻辑回归保留为简单候选；复杂候选须在整体选择期同时改善准确率、不恶化 Brier 和平衡准确率，并在三个子段中至少两个满足同样条件。
- 校准器只在前半校准区拟合。后半区验证其概率误差是否降低、方向及平衡准确率是否不下降；不通过则使用原始概率。不会用检查期重新拟合校准器。
- 每 20 个预测样本重训。最近 60 个滚动测试样本同时与历史频率、动量和冻结的旧版算法比较，资格门禁要求方向和概率的日期分块区间都显示优势。未通过时保持 WATCH/ABSTAIN，不宣称准确率必然提高。
- 次日页面新增“本地模型选择与独立校准检查”，展示当前模型的选择期、校准拟合期、检查期及候选得分；历史预测保留原版本，不回填新概率。

## 多周期研究

`evaluate_local_prediction.py` 读取现有 SQLite 行情缓存和参考指数交易日期，构建一日、五日收盘到收盘收益标签。缺少目标日期行情时不顺延。两个周期使用共同的 60 个历史信号日，分别训练、滚动比较及输出当期预测。

输出包括原始冻结输入、版本与输入指纹、每次重训边界、每笔历史预测、各阶段表现、旧版对照、收益平均绝对误差及区间覆盖率。五日目标不是前一版的五日开盘交易收益，不接入交易账本。旧算法在五日标签上作为本次研究对照，不称为既有线上五日模型。

```bash
cd market-data-service
PYTHONPATH=src OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python \
  scripts/evaluate_local_prediction.py \
  --code 000001.SZ --as-of 2026-09-15 \
  --output data/quant/local-prediction-new-run
```

输出目录必须不存在。`input.json` 保存行情及参考日历，`report.json` 保存逐笔结果，`report.md` 提供摘要。当前周期输出是指定数据截止时点的研究预测，不因历史参数 `--as-of` 而冒充实时信号。未来目标日期使用项目已核验交易日历；不支持年份不猜测日期。

## 真实缓存验证

固定参数在数据截至 2026-09-15 的缓存运行，共同测试信号日为 2026-06-16 至 2026-09-08，共 60 日：

| 标的 | 周期 | 新规则准确率 | 旧算法准确率 | 新 Brier | 旧 Brier |
|---|---|---:|---:|---:|---:|
| 000001.SZ | 次日 | 53.33% | 46.67% | 0.2475 | 0.2569 |
| 600036.SH | 次日 | 51.67% | 46.67% | 0.2478 | 0.2681 |
| 000001.SZ | 五日 | 36.67% | 60.00% | 0.2698 | 0.2636 |
| 600036.SH | 五日 | 65.00% | 68.33% | 0.2222 | 0.2018 |

两只股票的次日点估计改善，五日未改善，所有周期均未通过完整可信优势门禁。该小样本不足以证明普遍提升，不据此提高仓位或推广为稳定盈利模型。两个银行股不代表全市场，已有历史窗口也不是全新前瞻数据。

另尝试了 600519.SH 与 000063.SZ：前者缓存仅截至 9 月 11 日，不满足统一截止日；后者成熟历史不足。工具明确拒绝，未改变截止日期、减少验证长度或隐藏为有效实验。

新旧模型在相同股票、日期和标签上比较；没有按测试结果选择新参数。后续应继续积累冻结后的真实预测结算记录，五日改进单独研究，不能把次日结果外推到五日。

## 到期结算

研究运行目录中的当前预测保持不变。后续使用新行情结算，输出独立文件，不调用模型：

```bash
cd market-data-service
PYTHONPATH=src .venv/bin/python scripts/settle_local_prediction.py \
  --run data/quant/local-prediction-new-run \
  --as-of 2026-09-22 \
  --output data/quant/local-prediction-new-run/outcomes-2026-09-22.json
```

结算校验冻结输入指纹，保留源预测文件指纹、原概率、模型版本及结算行情。未到目标日为 PENDING，目标日缺行情为 MISSING_OUTCOME_PRICE，不拿之后的复牌日替代。到期记录实际收益、方向命中、Brier、绝对误差和区间覆盖。

QFQ 行情可能随公司行为更新，结算分母和分子使用同一份新快照中的信号日/目标日价格，不将旧复权基准与新复权基准混算。结算工具根据指定截止日和已缓存完整日线工作；使用当天未收盘数据之前必须等待行情完成。当前未增加五日专用页面或自动定时任务；次日继续由原有单股预测及历史记录流程承接。
