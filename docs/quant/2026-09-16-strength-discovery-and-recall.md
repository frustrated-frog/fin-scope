# 强势股发现、次日事件研究与漏选评测

## 问题与目标

本地批次 6386（2026-09-14）中，澳弘电子通过准入但初筛第 32，前 15 名均为银行，未进入深度预测。此轮修复候选入口与分析名额，保持严格交易门禁独立，不以事后涨幅倒推买入信号。

## 已实现的流程

1. **独立事件入口**：东方财富涨停池、炸板池、A 股现货异动，通过 `MarketEventProvider` 适配。现货筛选涨幅至少 5%，或量比至少 2 且绝对涨跌幅至少 3%；涨停、炸板优先。默认最多补充 160 只，截断数、各源条数、失败源均在审计中展示。
2. **与热门行业并集去重**：热门行业仍以同花顺为唯一行业榜来源。行业源失败时，有事件证据仍可生成明确标记为 `EASTMONEY_EVENTS / PARTIAL_FRESH` 的研究报告。账户范围继续排除科创板、北交所等；范围内但预算、完整历史不足的事件仍出现在观察池。
3. **分配深度名额**：默认 15 席，40% 预留短期强势，剩余按稳健因子顺序补充；每行业最多 3 席，多行业关联同时计数，行业未知合并限额。不会为了凑满 15 席突破上限。删除初筛中成交金额百分位的重复加分，保留一次流动性信息。
4. **强势识别**：至少 21 条日线；疑似涨停、20 日突破且当日涨幅至少 3%、成交额相对前 20 日至少两倍且绝对涨跌至少 3%。强势排序使用连续疑似涨停天数、5 日动量、异常成交额、突破；外部涨停/炸板/异动记录可独立触发观察。
5. **独立观察与深度门禁**：短期强势列表覆盖所有检出的事件；稳健趋势列表仅来自其深度名额。最终合格结果依旧要求原概率、回测、稳定性门禁。观察池不是买入名单。

请求新增有界参数：`sectorSeatCap=3`、`strongSeatShare=0.4`、`eventScanLimit=160`。现有 Java 请求可使用 Python 默认值；未改动本地密钥和运行配置。

## 次日评估口径

`event-frequency-v1` 使用同一股票、截至信号日已成熟的历史同类事件。疑似涨停与普通突破/放量分组，不把它包装成已验证的机器学习优势。

- 次日收盘高于信号日收盘的频率及 Wilson 95% 区间。
- 次日涨幅至少 3% 的强势延续频率、疑似再次涨停频率。
- 冲高回落：次日最高价比信号日收盘高至少 3%，但次日收盘低于次日开盘。
- 不涨/亏损率、平均收盘收益、平均次日开盘至收盘价格收益。
- 历史疑似一字涨停频率；缺少真实竞价和封单，未来可成交性始终为 `UNVERIFIED`。
- 先积累 20 个成熟事件，再按扩展时间窗口验证后续事件的 Brier；与同股全部成熟交易日的上涨先验比较。验证事件不进入自身概率估计。少于 30 个同类事件显示样本不足，达到 30 例也只标 `WATCH`。
- 标签必须匹配指数交易日历中的紧邻下一交易日，不以停牌后的下一根 K 线替代。指数日历缺失时不计算标签。

所有历史统计仅能说明样本中的情况。调整后日线只能识别“疑似涨停”，不能认证交易所涨停价；不同上市阶段、特殊限制及真实成交队列仍需要独立数据。旧普通次日预测及最终交易资格不被这些统计覆盖。

## 冻结与漏选评测

生产装配自动启用 `data/discovery-research/`：

- 每个信号日期只冻结第一份完成的研究结果，重试不覆盖；完整文件通过原子发布，避免并发读到半份 JSON。
- 下一次发现任务结算最近 5 个较早信号日期；保存原报告、行情输入及各自 SHA-256 指纹。
- 同时覆盖信号日和紧邻次日的缓存股票进入评测，不只评测入选股。它是**缓存覆盖范围，不是完整历史全市场**。
- 统一以次日收盘涨幅至少 5% 定义强势上涨，统计观察池召回、深度分析召回、漏选原因；同时记录强势事件的亏损率、冲高回落率与冻结概率的 Brier。
- 信号日收盘后生成的报告与历史补跑区分为 `FORWARD` / `RETROSPECTIVE`。旧报告缺少事件列表时，事件召回率为不可用，不伪装成零。
- 未到次日标 `PENDING`；价格缺失不填零，也不跳到后续交易日结算。
- 来源失败保留警告，部分事件快照允许重试；完整事件快照按日期冻结。历史补跑没有当日现货快照时只查历史涨停/炸板池，禁止用今天现货回填。

也可以独立核查已有冻结 JSON：

```bash
cd market-data-service
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/evaluate_discovery_recall.py \
  --report /absolute/path/signal-report.json \
  --as-of 2026-09-15 \
  --output /absolute/path/new-evaluation-directory
```

输出 `signal-report.json`、`outcome-input.json`、`evaluation.json`；输出目录必须是新目录，数据库只读。
