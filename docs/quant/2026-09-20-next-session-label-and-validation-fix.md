# 次日预测标签与真实效果验收修复

## 本次范围

修复收盘方向模型的“下一条日线等于下一交易日”问题，并在现有次日真实验证区域增加分版本的近期效果汇总。保留强势事件统计、尾盘与盘后独立策略；不改变交易执行规则。

## 标签连续性

- 日历覆盖的年份严格核对下一交易日，同时拒绝周末、已知休市日作为标签端点。
- 内置日历目前只有 2026 年。更早历史仅接受中间没有工作日的相邻观测（例如周五到周一），不把缺失行情推测为节假日；未确认的长假间隔会保守剔除。
- 报告说明剔除数量，样本不足时显示有效数量，不填造概率。
- 联合模型的特征截面必须独立于未来标签可用性；缺失次日行情仅排除训练标签，不移除该股票当天的可观察特征。
- 单股预测版本改为 `local-prediction-v3-consecutive-session-v2`，联合模型改为 `next-session-general-adaptive-v4-session2`。行情指纹包含标签协议，旧联合快照不能覆盖新标签协议的预测。
- 既有冻结记录保留，不事后改写历史概率。历史长假样本保守丢弃会改变样本构成，后续仍需要扩展经验证的历史日历。

## 页面入口与计算

Strategy → Quant → 股票发现的“次日预测真实验证”；单股预测已有的验证区域同步显示。

加载最近最多 100 条记录，明确限定为当前窗口，并非全量历史验收。按模型版本分别计算；同版本、同股、同目标日保留本窗口内最早生成的一条，避免重复试算增加权重。若全局首次记录在窗口之外，本页不会声称使用了全局首次记录。

方向命中率、Brier 概率误差先按同日股票平均，再按目标交易日等权。概率分段同样在各段内按日等权，展示预测概率和实际上涨比例。待到期、无法验证、非有限结果不计入成绩；无有效样本显示空缺。

不把 60 天视作优势保证，不把方向命中当作扣费后盈利。现有冻结账本没有逐条同期基线概率，本次不会用训练期基线冒充前瞻基线，也不输出“优于基线”的结论。

## 验证与启动

- Python 全量：461 项通过；其中次日与联合模型专项 38 项通过。
- 前端针对次日展示、统计和股票发现的 11 项测试通过；生产构建通过，仍有原有包体积提示。
- 浏览器用真实最近 100 条记录验证分版本展示与空样本状态，检查桌面截图。
- 重启 Python 服务后新生成的预测使用修复协议；前端刷新可看到验收区。无需改写旧预测或重启 Java。

## 后续边界

完整前瞻基线需要在预测生成时同步冻结基线概率，再追加结算；全量验收应由后端按日期范围分页/聚合，不应通过继续提高前端读取上限实现。尾盘定时采集、自动结算及模型增强属于后续独立批次。
