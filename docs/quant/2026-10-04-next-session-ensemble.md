# 次日收盘模型 v4：近期价量学习与原版对照

## 解决的问题

v3 把最近约 90 个交易日留给模型选择和概率校准。隔离本身合理，但用于当前方向预测的基础分类器因此长期未看到最新成熟标签。v4 保留这个长期分支，新增一个使用最近成熟标签的短期分支，固定各占 50%。无需模型 API。

短期分支用 15 个收盘时可见的特征：按波动率调整的 1/2/5/20 日收益、当日收盘位置、上下影线、跳空、实体、成交额相对过去 20 日的变化、振幅、市场单日收益、个股单日超额收益，以及大幅涨跌且收在日内高低位的标志。最后两个标志不是交易所涨跌停认定。

训练最多使用 504 个成熟样本，样本权重每 126 个交易样本减半；使用强正则逻辑回归（C=0.03）。标准化参数只从训练段计算，标准化值裁剪到 ±5，限制异常值影响。全部模型只接受 `exit_date < cutoff` 的标签。

方向概率才做组合，收益幅度与残差区间仍由 v3 计算。没有把收盘数据充当 14:30 的信息，也没有改变尾盘买入策略、5 日模型或交易收益口径。

## 真实缓存对照

股票按 `sha256('next-session-v4' + symbol_key)` 排序选取，不按收益、涨幅或行业挑选。输入来自当前本地前复权日线缓存；只有通过质量校验且至少 900 根日线的股票进入本次研究。

开发段为 2026-01-01 至 2026-03-31，32 只股票共 1,792 条记录。开发段单独使用短期模型未提高方向命中率，因此选用固定等权组合。后续没有用测试结果修改权重或参数。

以下比较信号日为 **2026-04-01 至 2026-09-11**，逐股每 20 个可验证样本重新训练，目标标签都是相邻且核验连续的交易日收盘收益。指标先按股票、再按交易日等权。

| 股票组 | 记录 / 日期 | v3 准确率 | v4 准确率 | v3 Brier | v4 Brier | 始终不涨准确率 |
|---|---:|---:|---:|---:|---:|---:|
| 开发股票后续日期，32 只 | 3,602 / 113 | 51.52% | 52.14% | 0.25887 | 0.25212 | 52.95% |
| 另取 96 只股票，与前组无交集 | 10,808 / 113 | 50.95% | 51.91% | 0.25977 | 0.25262 | 53.16% |

96 只股票组平衡准确率为 51.52%。相对 v3，日期分块重采样并校正 3 个基线比较后的准确率差区间为 **−0.38 至 +2.23 个百分点**，Brier 差区间为 **−0.00971 至 −0.00518**。

结论：概率误差改善较明确，观察到的方向命中率提高约 0.96 个百分点，但准确率差区间仍跨 0，且没有战胜“始终不涨”基线。不能将其宣传为稳定高准确率或盈利能力提升。短期分支单用的后续结果也随报告保留，未据此事后改权重。

## 接入与展示

- 新版本为 `next-session-ensemble-v4-consecutive-session-v2`，生成指纹同时包含两个分支特征。
- 每次正式报告仍重放最近 60 个样本；增加真正的上一版 `LOCAL_V3` 和“始终不涨”基准。只有同时通过各项方向与概率检验才进入 READY，否则保持 WATCH / ABSTAIN。
- 长期分支的选模和校准记录照常保留；额外记录短期分支训练日期、样本数、特征、权重和两个分支当前概率。
- 页面展示原版与组合的同日期准确率、Brier。详细数据默认折叠，避免继续挤占股票发现页面。
- 收益区间并非组合概率的校准区间；页面与响应说明其来源。

## 重放方式

在 `market-data-service` 下执行：

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 PYTHONPATH=src .venv/bin/python \
  scripts/evaluate_next_session_ensemble.py \
  --start 2026-04-01 --end 2026-09-11 --through 2026-09-30 \
  --symbols 96 --skip 32 \
  --output data/quant/next-session-v4-independent-96-2026-10-04
```

目录已存在时必须换新输出目录；不会覆盖原始实验。产物包含执行前写入的 protocol、冻结行情、每条预测、训练边界和完整比较报告。`--input 原目录/input.json.gz` 可复用冻结输入，不再读取可能更新的数据库。

本次 96 只股票输入 SHA-256：`57025d5e3a886d52c78a28a2e0f820ee579caf6d5dc4773ae5ea6a9b83961afd`。原始数据及完整报告位于 Git 忽略的上述本地实验目录，不提交原始行情。协议并不冻结解释器及依赖二进制；跨环境重放允许浮点误差。

## 证据边界

这是 RETROSPECTIVE 历史重放。当前股票缓存有幸存者偏差，前复权历史可能被后来事件修订，且日期曾参与项目其他研发。32 只股票的开发段与后续日期隔离、另 96 只股票分组隔离，只说明本次比较过程，没有把数据变成真正未见过的未来。

本地分钟库只有 13 个标的、2026-08-06 至 2026-09-18 的约一个多月记录，尚不足以证明尾盘买入模型准确率提高。该策略继续单独积累冻结快照与真实次日结算记录。
