# 隔夜模型独立校准与可靠性诊断

## 使用场景

入口：量化策略 → 尾盘与盘后。尾盘入场继续只使用截止时刻前的完整分钟线，盘后持仓继续使用独立的持仓收盘参考价。次日开盘、10:00、14:30、收盘分别建模，不根据测试成绩挑选最佳退出时点。

本次模型版本为 `overnight-local-v3-calibrated`。无需 LLM API，不新增依赖。Java RPC 接受新版本并保留旧版本兼容；冻结键包含模型版本，旧预测不覆盖、不重新计算概率。v2 与 v3 的到期结算继续剔除无法验证的一字价格区间。

## 学习与验证协议

- 输入仍为既有 8 个盘中价格、成交额和波动特征；复用 LogisticRegression、Ridge 和项目已有 PlattCalibrator。
- 每次拟合仅使用退出时刻严格早于决策截止的已成熟标签；训练标签退出时间还必须严格早于校准区首个信号截止，防止训练与校准边界重叠。
- 训练最少 40 例、最多最近 240 例；最后 20 例作为独立校准区。缩放器和基础模型只在训练区拟合。
- 盈利概率使用独立校准区拟合 Platt 映射。校准区正负类别不足时明确保留原始概率，不伪装成校准成功。
- 预期收益仍为 Ridge 输出；80% 误差范围使用独立校准区的绝对残差和有限样本分位数。该范围不保证未来覆盖率。
- 最多最近 60 个样本逐日重建训练、校准、基线和误差范围；至少 20 个有效顺序验证才输出研究概率。测试结果不参与当前模型或退出时点选择。
- 新版至少需要 82 个有效收益样本，包含两个时间隔离边界的余量；不足时返回所缺样本数，不把缺失分钟线替换成日线。
- 每次验证的基线为当时已成熟的最近最多 260 个样本的盈利比例，正式预测同步冻结这一基线。模型和基线比较使用同一批扣费标签。

## 页面如何解读

概率误差改善为 `1 - 模型 Brier / 基线 Brier`。正值表示该历史窗口的概率误差更小，负值表示更差。基线误差为零时不计算比值。近期对照使用最后 10 个有效验证样本，不称为完整连续 10 个交易日。

可靠性诊断按固定顺序给出：验证不足、未超过基线、近期退化、校准不足、区间覆盖不足（低于 60%）、历史对照改善。最后一项仍只代表历史窗口内的对照，所有预测维持 WATCH，不自动升级为买卖指令。各诊断阈值不是收益保证。

页面默认展示盈利概率、预期净收益、误差范围及一句可靠性结论。展开可看校准前后误差、近期退化、区间覆盖、训练和校准截止。真实前瞻成绩仍由已有冻结档案验收区单独统计。

## 启动与限制

重启 IDEA 中的 Java 和 Python 服务，再刷新前端。旧版本档案没有新增校准证据，页面不追补；新版本从下一次生成或自动留档开始积累。

分钟历史不足时，提高模型复杂度不能补足数据。本次测试验证时间隔离、协议兼容、计算和展示正确性；尚无新版本真实前瞻成绩，不能据此声称命中率提高。原始价格的公司行为、真实成交和涨跌停队列验证仍是既有局限。
