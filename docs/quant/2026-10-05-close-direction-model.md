# 尾盘与盘后：独立次日涨跌预测

## 目标与边界

原有隔夜模型的 `upProbability` 实际表示扣费后盈利概率，不能作为“次日涨跌准确率”。新增独立 `closeDirection`，目标固定为：**次一交易日未复权收盘价是否高于信号日收盘价**。持平属于未上涨，不把未上涨概率称为下跌概率。

- 14:30、14:45、15:00 分别建模。尾盘只能使用截止时刻的特征；信号日收盘仅用于未来标签，不作为尾盘输入。
- 费用、持仓成本、成交代理不参与涨跌标签。一字行情有有效收盘成交额时保留价格结果，仍不代表可以成交。
- 原有四条扣费收益路径保持独立。涨跌结果有独立冻结字段、核验结果及前瞻验收协议 `overnight-close-direction-v1`。
- 复用现有分钟缓存、公共样本池、后台任务、模型存储、日期加权评估和方向校准门槛，不增加模型 API 或依赖。

## 学习与防泄漏

使用原有 14 个个股时段特征，再增加最后 5/30/60 分钟走势、午后表现、日内区间位置、回撤/反弹、下行波动、最后半小时相对成交额、前五日收益及波动、创业板标识，共 26 个特征。

固定候选为历史比例、原有时段特征逻辑回归、扩展特征逻辑回归、扩展特征树模型、等权组合。至少 80 个训练日，20 日选择窗口，20 日校准窗口；跨窗口未到期标签清除。选择窗口按日期等权 Brier 决定候选，不用检验结果挑模型。训练权重均值归一为 1，保持同日总权重一致，明确正则化使用的样本尺度；这不意味着同日股票相互独立。

概率校准复用 `fit_direction_calibration(INTERCEPT)`，只平移整体概率而不反转或压缩股票排序。校准拟合完成不等于可采用：复用成熟预测校准门槛，至少 60 个已到期预测日期，方向准确率、概率误差、多个子窗口同时支持才采用校准值；否则保留原始模型概率。历史回放和实时报告均严格使用当时已经到期的证据。

最近 20 日逐日重新训练和预测，最终模型使用截至任务启动时间的到期标签。JSON 保存模型、特征清单、数据指纹和训练面板，网页摘要不传递模型系数。

## 自动运行与验收

后台在原有非交易关键窗口训练，两类目标独立满足条件即可发布。自动发现候选与真实持仓报告自动附带涨跌结果，无需手动选代码。行情或样本不足时显示具体状态。涨跌核验不会因入场不可成交而被丢弃，也不会因交易收益已结算就漏掉待补的收盘标签。

只统计自动生成、当时冻结的前瞻记录；同股票同日同截止时点的费用或持仓修订去重。按尾盘 14:30、14:45 和盘后 15:00 三组分别验收，首 60 个完整结果交易日固定一次检查，失败不反复滚动试到通过；采用日期分块不确定性及三组比较校正，后续监控覆盖和退化。该验收独立于扣费收益和候选排序，不输出交易指令。

## 开发对照（不能当成独立验收）

沿用在获取行情前固定的 24 股名单，23 股获取成功，失败成员未替换。每个时点有 173 个有效信号日期、3,969 个样本；检验区为最后 20 个日期、460 个样本。以下旧配方对照使用**相同新涨跌标签、相同 26 个特征与检验日期**，不是把旧净收益准确率直接拿来比较。

| 决策时点 | 新配方准确率 | 旧配方准确率 | 历史比例基准 | 新配方两类平均识别率 | 新配方预测上涨比例 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 14:30 | 52.17% | 50.87% | 56.52% | 47.65% | 15.65% |
| 14:45 | 54.57% | 47.61% | 56.52% | 52.13% | 31.09% |
| 15:00 | 51.52% | 48.48% | 56.52% | 49.04% | 31.09% |

新配方 Brier 为 0.24955 / 0.25075 / 0.25183，基准均约 0.24744。**虽然对旧配方有改善，三个时点均未超过简单基准，不可声称形成预测优势。** 14:45 两类平均识别略超过 50% 也不能单独作为有效证据。

开发中先评估了直接采用截距校准的版本，准确率仅 46.96% / 45.22% / 44.57%，随后增加已有成熟预测门槛。该修改参考过此开发区间，因此最终成绩也不是未接触的样本外验收。保留第一次与最终审计，不删除失败实验。

复现命令（输入为预先冻结的公开分钟数据目录，不访问实盘账户）：

```bash
cd market-data-service
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 PYTHONPATH=src .venv/bin/python \
  scripts/evaluate_overnight_direction.py --input-dir /tmp/finscope-overnight-joint-20261005 \
  --output-dir /tmp/finscope-overnight-joint-20261005/direction-gated-audit --compare-legacy
```

审计文件保存在本机临时目录，不提交原始行情。当前数据仍有缓存股票池覆盖/幸存偏差，普通公司行为没有完整核验；缺少决策当时的指数、板块和全市场广度输入。增加特征、生成两类预测或相对旧配方改善，都不能替代独立前瞻优势。
