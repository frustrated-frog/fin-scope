# 尾盘与盘后：论文复核、分钟历史底座与概率参考选择

## 本轮结论

本轮最有价值的改进是补齐真实分钟历史，以及让缺乏历史优势的模型退回明确标注的历史基线。隔夜／日内分离特征没有在本地对照中形成稳定增益，保留为离线研究候选。生产版本为 `overnight-local-v4-evidence-gated`，无需模型 API。

同一份数据的 8 组比较中，新参考选择规则的方向命中与 Brier 均好于原 v3；但 Brier 仍没有超过简单历史基线。这个结果支持减少无效模型输出，**不支持宣称发现了可稳定获利的新因子**。

## 已上线的改动

### 自动历史采集

- 自动发现候选、真实持仓及已有分钟缓存都进入补数队列，不需要另填观察名单。
- 历史源独立存储；读取时整日优先采用实时采集源，禁止用另一个来源填满同一天的缺失分钟。
- 按重叠日的开盘、收盘、全天成交额核验跨源口径；单根分钟聚合差异单独留痕。11 只实测股票各有 31 个完整重叠日，开收盘一致，全天成交额最大偏差约 0.26%。
- 采集目标 140 个完整交易日，回溯最多一年。覆盖天数不等于有效收益样本，日历、完整分钟、成交代理、成熟标签和独立验证仍需分别满足。
- 独立后台循环串行下载，单进程最多 45 秒；14:24—15:05 不发起补数，按日最多三次失败重试。SDK 的全局 socket 隔离在子进程中。
- 只补昨日及更早数据，不重写已经冻结的预测，也不把历史补数算成前瞻成绩。
- UI 新增折叠的“历史样本自动补齐”，显示覆盖天数、处理状态和失败原因，沿用透明背景。

原本地库只有 13 只股票、32 个日期。真实来源探测中，澳弘电子 2026 年 1—9 月取回 8,688 根分钟线，覆盖 181 日；另 11 只研究股票各取回约 242 个日期的近一年历史。实际模型仍只使用已核验日历范围，不能把完整行情天数直接当作训练资格。

### 模型与基线自动选择

沿用此前已有的滚动诊断规则，不根据这次对照成绩重新调整阈值：

1. 仅使用决策截止前已经成熟的标签，原模型逐日重新训练和独立校准。
2. 对最近最多 60 个历史预测，检查整体与近期是否优于当时的历史基线，以及校准状态和误差区间覆盖。
3. 只有诊断为 `HISTORICAL_EDGE` 才采用模型参考；其他状态采用当时的历史盈利比例和平均净收益。
4. 基线参考不附上被拒绝模型的误差区间。原模型概率、收益估计、验证记录仍保存，可在“独立验证依据”查看。
5. 次日结算使用当时实际展示并冻结的参考概率。新旧版本分组统计，旧记录及其结算规则保持兼容。

`HISTORICAL_EDGE` 是历史诊断，不是实盘盈利资格；当前仍为研究观察，不生成交易指令。页面会区分“历史基线参考”和“校准后盈利概率”，不会将基线频率包装成个股上涨优势。

- 信号区间：2026-08-03—2026-09-29，目标行情截至 2026-09-30 15:00。
- 合计 3,511 个“股票 × 信号日 × 场景 × 退出时点”观测，**不是 3,511 个独立交易日**。每组 40—41 个信号日；各退出时点不完整／一字价格区间分别排除，收盘末日尚未严格越过成熟时点也排除。

### 新特征为什么暂未启用

研究候选为原 8 个分钟特征，加今日开盘缺口、前日隔夜与日内收益、近 5 日隔夜与日内平均收益、相同截止时刻的相对成交额；候选与原版概率固定各占一半，未遍历权重择优。候选所有输入都在决策时刻可知，历史不完整时拒绝构造特征。

结果并不稳定：尾盘到次日 10:00 的 Brier 从 0.2473 变为 0.2500，尾盘到次日收盘从 0.2741 变为 0.2746；盘后到次日开盘略降至 0.2283，但对应配对区间仍跨零。没有因个别命中率上升就替换生产模型。`session_features.py` 仅供离线评测调用。

### 证据边界

这些都是事后历史重放。股票来自当前缓存，有选择与幸存者偏差；有效日期少于既有方向资格所需的 60 日。v4 在检查新特征失败后提出，并在同一批数据诊断，**这批数据不再是 v4 的独立最终保留集**。后续应以新交易日冻结的前瞻记录确认，不能把这次表格作为未来准确率承诺。

研究使用同一 BaoStock 历史输入对照算法；在线系统使用按日期隔离的实时／历史来源，分钟聚合差异仍可能影响泛化。未复权价格中的分红送转、停牌和涨跌停排队未全面验证，不能将价格代理净收益当成真实交易收益。

## 复现与运行

```bash
cd market-data-service
uv sync --locked --extra dev --extra ecosystem
PYTHONPATH=src OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python \
  scripts/evaluate_overnight_sessions.py \
  --input-dir /tmp/finscope-overnight-research-20261004 \
  --start 2026-08-03 --end 2026-09-29 \
  --output /tmp/finscope-overnight-replay-new
```

输入为按股票代码命名的 `.json.gz` 分钟数据列表。脚本只读冻结输入，输出独立 `protocol.json`、`report.json` 和逐笔审计文件；目标目录已存在时拒绝覆盖。研究数据与账户信息不提交 Git。临时输入目录清理后需重新获取并核对摘要，不能把新下载文件冒称为同一冻结输入。

已验证：Python 全套回归 540 项通过，随后新增的全天成交额冲突与中断恢复用例及该模块 8 项通过；前端相关 12 项和生产构建通过；Java 隔夜 RPC 测试通过。所有研究观测的训练／校准／选择依据均早于决策截止。核心输出另与离线重放做同日逐目标核对。
