# 尾盘上涨排序配对实验

## 运行前固定的协议

目标只使用 NEXT_SESSION_CLOSE_VS_DECISION_PRICE：次日收盘严格高于判断参考价。持平仍计未上涨。14:30 与 14:45 独立，不研究费用，不改主预测。

复用分钟面板、68 维环境与多周期特征、覆盖门槛、时间分区、日期等权和已有浅树参数。不新增依赖，不对既有测试窗口调参数。

- 同一训练输入分别拟合 LGBMClassifier 与二元标签 LambdaRank；排序仅使用上涨/未上涨，不使用收益幅度或市场残差五档。
- 排序关注前 3 位；分数无概率含义，不允许 sigmoid 后伪装为上涨概率。
- 两臂使用相同训练行、训练期截尾与树参数；预留原校准区但不使用其标签拟合或校准。没有候选选优。
- 逐日重训，每折仅使用决策前到期标签；保留训练指纹。缺少 20 个含两类标签的训练日期不产生模型。
- 固定最后 20 个覆盖合格日期，所有方案同股同日强制取前 3，比较分类、排序、当日涨幅动量、同池均匀选择期望；并列按比例计分，日期等权。
- 整体方向准确率、收益排序相关性不能代替前 3 名上涨比例。公共池成绩标为 RETROSPECTIVE，不冒充真实自动候选成绩。
- 旧日线 LambdaRank 负结果保留。本实验检验不同目标及分钟输入，并不假定排序损失必然优于分类。

依据：[Learning to Rank](https://arxiv.org/abs/2012.07149)、[ListFold](https://arxiv.org/abs/2104.12484)。借鉴排序目标，不复用其收益成绩；这些研究不能证明本项目尾盘次日方向有效。

## 自动运行边界

新增独立 SHADOW 工件，随已有夜间训练生成；实际尾盘预测冻结排序分数、同输入分类概率和动量分数。真实候选结果齐全且所有成员都有同版本配对预测的日期，才计算前瞻对照。缺失日单列，不拼接旧模型，不事后补造。此版本不自动替换主模型。

## 离线入口

`market-data-service/scripts/evaluate_tail_ranking.py` 读取既有冻结 artifact/panel gzip，拒绝目标与特征不一致，输出独立实验结果、逐条预测、逐折截止与运行环境；拒绝覆盖已有输出。不读取在线行情或发布模型。

## 真实冻结面板实验结果

使用上一轮原模型工件的 contextRows：每个时点 2094 个股票日、同一批 20 个检验日期，信号从 2026-09-30 起，标签截至 2026-11-04。训练面板来自固定公共研究池，不是实际自动发现名单。每折训练与评测名单一致性、未来标签隔离均受协议限制。

| 时点 | 同输入浅树分类 | 二元上涨排序 | 简单动量 | 同池均匀期望 |
| --- | ---: | ---: | ---: | ---: |
| 14:30 | 49.51% | 61.67% | 50.00% | 50.40% |
| 14:45 | 57.36% | 56.67% | 51.67% | 49.73% |

指标均为每天前 3 名的实际上涨比例，日期等权，公平处理并列。分类器是本实验固定的同输入浅树参照，不是线上择优后的通用方向模型。排序输出不是概率。

14:30 相对同输入分类提高约 12.15 个百分点；14:45 略低约 0.69 个百分点。未据此挑选时点、改超参数或上线替换。排序相对同池平均的描述性五日分块 95% 区间分别约为 [0.97, 24.29]、[-3.07, 18.38] 个百分点，未作多重比较校正，也未补偿这些历史曾参与开发的选择影响，不能作为正式优势认证。

在本机 Python 3.13.13 和原镜像 Python 3.12.13 / Linux aarch64 各运行一次；两者 NumPy 2.5.1、LightGBM 4.7.0、scikit-learn 1.9.0。两时点全部逐条分类概率、排序分数、动量、标签完全一致；均匀期望汇总仅有浮点舍入差异。
