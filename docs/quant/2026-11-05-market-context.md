# 尾盘广泛市场数据留存与分组对照

本轮补充信息来源，不宣称准确率已经提高。沿用当前分支与自动任务，未增加模型 API 依赖。

## 数据契约

- 自动环境采集继续在 14:30、14:45、15:00 判断之前执行；复用腾讯批量行情适配器，异步等待最多 45 秒，不阻断原有股票与指数采集。
- 保留证券目录总数、有效报价数、来源、逐条行情时间和接收时间。仅接受环境窗口开始之后、接收时刻之前的报价；截止后返回的结果不入库。
- 最低目录规模 1000，有效覆盖率至少 80%。覆盖率分母由行情适配器明确提供，不用已成功返回数量代替。旧缓存没有分母时视为不足。
- 使用原环境快照的不可变主键和指纹，重启后保留；盘后不补填盘中缺口。状态接口不输出数千条明细。
- 行业关系沿用已有可用日期历史；行业特征至少 5 个同行、75% 成员覆盖，排除股票自身。行业成员缺失时不伪造。

## 独立研究

夜间自动训练后分别生成 MARKET、SENTIMENT、INDUSTRY 三组配对实验。每组基准与新增特征模型使用同一批股票、日期及成熟标签，采用已有按时间划分的训练、选择、校准与逐日测试流程。需要至少 143 个覆盖合格日期。缺失真实环境快照的历史不参与，样本不足仅报告积累情况。

- MARKET：市场平均涨幅、上涨比例、涨幅离散度。
- SENTIMENT：涨幅达到 3% 的比例、跌幅达到 3% 的比例，以及涨幅仍达到 3% 但已从高点回落至少 2% 的比例。这是价格强弱代理，不冒充涨跌停或连板统计。
- INDUSTRY：同行平均涨幅、上涨比例、个股相对同行涨幅。

结果保存至自动化状态 `marketAblation`，仅含研究指标。它不会自动改变线上主预测。现有指数、研究池及 68 维模型协议保持兼容。下一阶段必须依据新积累的独立结果，决定哪些信息值得进入线上挑战模型。

界面在现有“次日涨跌独立验证”折叠区补充一行广泛市场数据状态，不增加交易主界面指标。

## 验证

- 全量 Python：671 项通过；随后补充到 6 项市场上下文专项测试并全部通过。
- 前端涨跌面板相关 9 项测试通过，生产构建通过（保留既有大包提示）。
- 时间戳、覆盖率分母、缺失数据、不可变快照、重启恢复、行业可用日期、配对样本一致性和样本不足不训练均有覆盖。
