# 广泛市场增强模型的自动前瞻闭环

## 解决的问题

上一轮 `marketAblation` 只保留历史实验指标，训练出的系数未发布，无法对后续真实候选进行预测。本轮将其接入已有模型发布、自动研判归档、次日结果回填和后台评估链路。无需手动触发或模型 API。

## 实现边界

1. 每个 MARKET / SENTIMENT / INDUSTRY 实验保存相同样本基准与新增特征模型，包含特征顺序、数据指纹及独立协议 `overnight-market-direction-v1`。继续要求 143 个合格日期，不降低样本门槛。
2. 模型与主模型一起原子发布，包含系数的完整内容参与版本指纹。发布时检查训练、校准及测试标签时点；状态 API 排除系数。只有发布成功后才更新训练进度。
3. 自动尾盘、盘后预测执行时，按原始截止时间获取已冻结环境数据。使用同一参考价格，同时冻结增强概率、同样本基准概率、当时主预测概率、行情指纹及模型版本。缺少真实环境或模型时明确标记，不生成替代值。
4. 后台每五分钟核验真实自动候选与计划持仓。使用最早自动前瞻记录，拒绝未来模型、未来行情、未到期结果、旧协议、无效概率和参考价格不一致的结果。
5. 失败或遗漏预测保留在分母。一个候选日有缺口时，该日不计入方向与 Top-3 评分；报告已配对数量、完整日期数及缺失原因。
6. 按日期等权评价，与相同训练样本基准和线上主预测分别比较，使用现有日期分块区间与 9 组比较校正。结果仅供研究，`eligible=false`，不会因为历史成绩自动接管主预测。
7. 配对样本构建按日期处理，仅保留一天的广泛市场明细，避免多月数千只股票快照同时常驻内存。

## 页面

沿用透明背景与现有折叠区，不增加主预测卡片的概率数量。入口为“尾盘与盘后 → 模型研究 → 次日涨跌独立验证”。分别显示各时点各信息组的训练有效日期、完整真实对照日期和配对覆盖；没有结果时不显示 0% 命中率。

143 个训练日期与 60 个前瞻日期是两个不同阶段，不代表明天就能形成新模型的有效性结论。当前广泛市场历史仍需从真实采集开始积累。
