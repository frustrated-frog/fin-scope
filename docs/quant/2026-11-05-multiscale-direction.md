# 尾盘与盘后：多周期方向模型和候选诊断

## 问题与实现

目标仍为“次一交易日收盘价是否高于本次 14:30 / 14:45 / 15:00 的参考价”，与交易费用无关。原方向模型只包含很短的历史量价特征，上一版环境候选有 44 维特征；本次增加 24 维，形成 68 维候选方案。

- 每个 5 / 10 / 20 日窗口计算历史收益、均线偏离、收益波动、上涨比例、价格区间位置、同时间窗成交额比、收益与成交额变化相关性、趋势强度。需要此前 21 个完整交易日，缺失不填零。
- 当前日只使用判断时点及之前的分钟数据；过去的完整日价格与当前同时间窗成交额分别计算。不会使用当天尚未发生的收盘价或完整日成交额。
- 保留原先的历史比例、时段逻辑回归、形态逻辑回归、浅树和组合模型。新增完整特征组合模型、近期加权组合模型；近期权重以 40 个有效训练交易日为半衰期，先平衡同日股票，再按日期衰减并保持均值为一。
- 同一特征转换仅在训练区拟合。选择区、校准区和逐日测试区维持时间隔离，跨区未到期标签清除。新方案只在选择区竞争，不用测试成绩调参。
- 增加固定“预测上涨候选前 3 只”的实际上涨比例、覆盖日数、同日股票池上涨比例和差值区间。相同概率在边界按比例分配，避免股票代码顺序制造选股优势；该指标仅供诊断，不单独批准升级。

当前模型仍保留。增强候选的协议升级为 `overnight-context-reference-v4`，后台训练任务随版本重新建模；旧协议的前瞻成绩不能继承到新版。所有窗口自动训练、冻结预测和回填次日结果。只有新的 60 个真实前瞻日期同时在方向及概率质量上胜过原模型和简单基准，才允许自动采用；近期退化恢复原方案。

新模型推断检查协议与完整特征名单；数据不足或旧工件不兼容时保留原预测，不让增强失败阻断主流程。后台默认在 13:00–18:00 之外训练，新代码上线并不改写当天已冻结预测。

## 论文依据与适用边界

[Qlib（Yang 等，2020）](https://arxiv.org/abs/2009.11189)提供可复用特征、模型和研究流程的基础设施；[官方 Alpha158 实现](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py)包含多窗口价量统计。本次取其多周期、无量纲特征的思路，改成适配尾盘时点的数据口径，不是完整复现 Alpha158。

[DoubleAdapt（Zhao 等）](https://arxiv.org/abs/2306.09862)研究通过数据及模型适配应对股票分布变化。论文采用元学习及增量更新；本次的时间衰减是一个低复杂度、可对照的工程候选，不是 DoubleAdapt 的复现，不能借用论文的实验收益或准确率。

## 第一轮冻结对照（开发诊断，不是验收）

冻结输入截止 2026-11-04，40 只股票；增强历史要求后约 6,624 条训练/验证样本，167 个有样本的日期。三方案在相同股票、日期和价格标签上逐日滚动测试最后 20 个覆盖合格日期。此前该区间已被开发使用，存在研究池和幸存偏差，未复权公司行为未完整核验；不能把它解释为真实交易胜率。

| 时点 | 原模型方向命中 | 上一版环境方案 | 本次增强方案 | 本次相对上一版 |
|---|---:|---:|---:|---:|
| 14:30 | 58.15% | 57.72% | 57.72% | 0 |
| 14:45 | 55.63% | 58.01% | 58.01% | 0 |
| 15:00 | 54.99% | 57.41% | 57.41% | 0 |

**新增候选未在选择区形成优势，最终测试输出与上一版一致，不能声称本次已经提高准确率。** 多个窗口主要退回历史上涨比例，两类平均识别率约 50%；不能只看整体命中率。14:45 相对原模型的命中差异约 +2.38 个百分点，但日期分块区间包含零，优势未成立。原模型在此表中的成绩与完整研究池的后台诊断不同，因为这里严格取了三个方案共同可用的历史范围。

“前 3 只”诊断有时没有预测上涨的日期，输出空值及零覆盖而非编造胜率；14:45 增强方案仅在极少日期给出上涨候选，66.67% 的局部比例不能用于宣称选股有效。完整 JSON 留在本地临时审计目录，不提交原始行情。

复现：在 `market-data-service` 下设置 `OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 PYTHONPATH=src`，执行 `.venv/bin/python scripts/evaluate_overnight_multiscale.py --input-dir <冻结行情目录> --output-dir <审计输出目录>`。该命令不发布模型、不改变线上采用状态。

## 验证

Python 隔夜模块首轮 127 项测试通过，覆盖未来分钟/标签隔离、特征顺序一致、平稳行情、缺失历史、日期权重、模型序列化、原候选预测兼容、候选概率并列和自动采用门槛。数据源、页面与自动候选扩容的检查另随对应提交记录。
