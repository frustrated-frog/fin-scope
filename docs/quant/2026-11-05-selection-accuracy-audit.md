# 尾盘选股准确性审计

## 结论

当前证据不支持把整体方向命中率的提高解释为选股能力已经提高。

- 14:30：原模型与环境增强方案的前排选股均未体现优势。取消 50% 概率门槛仍然如此，不能只靠调整门槛修复。
- 14:45：环境增强的历史排序表现较好，值得继续观察，但样本只有 20 个测试日期，优势区间仍包含零，不能据此上线替换或认定未来有效。
- 本轮没有调整参数、重新挑选特征或改写线上模型。新增的是可复用的离线审计脚本和报告。

## 数据与方法

从 SQLite 只读导出已发布模型及其压缩训练面板，使用原训练开始时间、原算法与选择策略，逐日重新训练并重放。每个测试日只使用当时已成熟标签。结果核对已发布 accuracy 与 Brier，误差超过 1e-6 即停止。

每个时点原模型有 2110 条测试观察，增强方案有 2094 条。按日期、股票取交集，核对 actualReturn 与 exitAt，最终各有 **2094 条、20 个测试日期**；原模型排除 16 条，增强方案未排除。测试信号日从 2026-09-30 开始，标签截至 2026-11-04 收盘。

这仍是已经参与开发诊断的固定研究池，不是全新的留出集，也不等于实际自动发现候选池。不能把约两千条股票观察当成两千次独立市场实验。

固定比较：

1. 原模型排序。
2. 环境增强排序。
3. 简单动量排序：仅按决策时点当日涨幅降序，预先固定，没有按结果优化。
4. 同池均匀选择期望：所有股票同分，边界并列按分数权重公平计入；不是一次幸运随机抽样。

所有结果按日期等权。排序诊断固定每日最多 3 只；原方案另保留 p≥0.5 条件。动量排名值只是排序分数，不是上涨概率。历史样本能够观察价格，不代表实际可成交。

## 相同 20 日、相同股票：每日固定取前 3 名

| 时点 | 原模型 | 环境增强 | 简单动量 | 同池均匀选择期望 |
|---|---:|---:|---:|---:|
| 14:30 | 45.00% | 44.46% | 50.00% | 50.40% |
| 14:45 | 51.67% | 57.48% | 51.67% | 49.73% |

上述比例是前 3 名的次日上涨比例，不是全体股票方向分类准确率。每日并列排名按比例计入，因此不一定对应整数命中数。

## 两个模型都产生看涨候选的相同 16 日

| 时点 | 原模型（p≥0.5） | 环境增强（p≥0.5） | 简单动量前 3 | 同池期望 |
|---|---:|---:|---:|---:|
| 14:30 | 42.71% | 41.67% | 54.17% | 52.71% |
| 14:45 | 47.92% | 58.33% | 54.17% | 48.66% |

环境增强在两个时点均有 4 日退回 PRIOR，所有股票同分，且当日概率低于门槛，没有看涨选择。原模型在 20 日均有选择。不能直接将两个方案各自选择日期的均值当作严格配对比较。

## 问题定位

### 14:30 的问题不只是门槛

环境增强在有选择日期的上涨比例为 41.67%；强制每日取前 3 后为 44.46%，仍低于同池期望 50.40%。原模型每日前 3 也只有 45.00%。这支持“当前前排排序缺乏优势”的诊断，尚不能归因到某一个特征或算法。

原始概率和当时实际采用概率对应的看涨选择成绩一致。这份样本不支持把主要问题归咎于概率校准改变了选股结果。

### 14:45 是观察对象，尚未形成稳定证据

增强方案在其 16 个有选择日期相对同池平均的提升约 9.68 个百分点，现有日期分块 95% 诊断区间约 **[-3.49, 25.60] 个百分点**，仍包含零。14:30 同一指标约 -11.04 个百分点，区间约 [-22.85, 2.08] 个百分点。

上述区间为现有候选评估器的描述性区间，不能替代多重比较后的正式前瞻验收，也不能从中选择一套参数宣称有效。

## 复现与环境限制

在原 Docker 环境成功复现两个时点、两套模型的历史 accuracy/Brier：Python 3.12.13、Linux aarch64、NumPy 2.5.1、scikit-learn 1.9.0、LightGBM 4.7.0。

macOS 本地 Python 3.13.13 在 14:30 通过复现检查，但 14:45 环境增强 accuracy 未通过。审计程序按设计拒绝接受该次结果。原容器运行成功说明冻结输入能在原环境重放；跨环境差异的具体数值计算来源尚未定位，不能简单认定由 Python 版本导致。

重放命令（在原运行环境使用冻结文件）：

```sh
PYTHONPATH=src OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python scripts/audit_overnight_selection.py \
  --inputs <冻结目录>/1430.json.gz <冻结目录>/1445.json.gz \

```

输入每个 gzip JSON 包含 artifact、panel 和 trainingStartedAt。程序只读输入，输出离线报告，不访问行情网络、不发布模型、不改变验收状态。原始输入与逐日明细留在本地审计目录，不提交仓库。

## 验证

离线脚本专项 3 项通过：重复样本拒绝、阈值与强制排名区分、并列公平性、复现不一致拒绝。原 Docker 环境完成两个时点全部重放，accuracy 与 Brier 均通过工件一致性校验。
