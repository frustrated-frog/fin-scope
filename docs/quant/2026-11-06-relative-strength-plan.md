# 尾盘相对强弱与同日选股对照

## 固定范围

本批保留现有尾盘、盘后目标和原始档案，实施同日选股对照与判断前相对强弱输入。不增加交易成本展示，不新增 10:00 预测目标，不凭开发成绩替换主预测。

在独立 worktree 的 `codex/tail-relative-strength` 分支开发，基线为 `bf5dc00b`。原工作区及其服务由其他任务使用，验证采用独立环境与只读数据副本。

## 同日选股协议

`overnight-same-day-selection-v1` 固定比较三组：指数增强、同样本个股基准、仅指数输入。仅指数模型预测的是研究样本整体上涨倾向，同一天所有股票必须得到相同分数；它没有区分股票的输入。

1. **固定前三名**：每个完整日期各组选相同数量 `min(3, 当日股票数)`，不按看涨阈值删日期。低于 50% 仍参与排序诊断，不作为买入建议。
2. **相同候选数量**：按指数增强组高于或等于 50% 的数量确定当日名额，最多 3 个；其他两组在相同日期使用相同名额。无候选的日期保留在总日期与覆盖率分母中，不把它记作猜对，也不将空结果填成 0% 命中率。
3. 并列边界按份额分配，不按股票代码顺序偏置。日期等权；固定两项比较，按日期块重采样区间，仅作开发诊断。
4. 真实验证仍要求自动发现的整日名单完整配对；失败、未生成、数据缺口保留在原分母，原预测不回写新实验字段。

验收同时看固定前三名命中、相同名额下的提升、完整日期数、无候选日期数与覆盖率。个股排序是否优于仅指数组，需要与整体方向命中分开判断。

## 判断前数据

现有分钟特征已经包含个股 30/60 分钟涨跌、日内回撤和相对成交额。当前三个指数的盘中快照有效，但历史可用日期较少；实际快照中的行业成员记录为空。新增工作重点是相对指数输入与明确的数据覆盖，不复制已有特征、不用零值冒充缺失行情，也不将现时行业关系倒灌到历史。

所有新特征须可追溯到判断前的行情和接收时间。历史重建与真实前瞻证据分开，数据不足时继续自动积累并显示原因。
