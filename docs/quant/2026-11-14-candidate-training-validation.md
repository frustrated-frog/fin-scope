# 真实尾盘候选专训：实现与准确性验证

## 结论

真实尾盘候选已正式进入拟合，不再只是用来挑选公共池模型。训练、自动预测挂载、前瞻统计、旧协议隔离和页面展示均已接通。

本轮历史回放的方向正确率略高于原公共池滚动方案，但概率误差更差，排序优势也不稳定。**没有达到可以宣称整体准确性提高的证据要求，不替换主判断。** 参数、特征及训练规则在首次回放前固定，见《2026-11-14-candidate-training-protocol.md》，未依据本轮成绩反复调参。

## 已实现

- 独立候选训练器，固定六项判断时可见特征、L2 逻辑回归，按日期等权；标准化来自候选自身，公共池的截断范围不再压平强势候选差异。
- 只纳入过去完整、已到期的冻结名单；池外候选可以参加拟合。已知公司行为影响只排除拟合记录，不删除验证中的困难样本。核验队列自动扩展到最近冻结候选，未知状态单独记录。
- 14:30、14:45 独立后台重拟合。样本不足时保留历史比例；训练完成后作为 `overnight-candidate-rolling-v3` 对照自动留档，不依赖人工输入股票。
- 原公共池滚动方案继续逐日重建，作为同名单比较组；其历史择模结果保留在 `audit.selection` 中，专训使用固定算法，不按测试成绩择优。
- 新协议不混用 v2 前瞻；生产验收检查来源协议，持久化验收键也包括协议，不能继承旧方案的通过结论。仍须通过独立真实前瞻准入才能替换主判断。
- 研究详情展示专训样本、公共池外样本、缺口、配对历史成绩与真实前瞻进度。极少量看涨记录同时展示日期数和条数，避免孤立显示 100% 造成误解。
- 验证工具支持冻结压缩输入和完全离线复算，输入指纹不匹配直接拒绝。数据库只读、禁止表初始化，原预测、结果和模型均未改写。

- 14:45：`13dd316ee19b5b58e96aeca9fbef6abef953d90e415c368c6dce4ec12fd6e31d`

```bash
cd market-data-service
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 PYTHONPATH=src \
  .venv/bin/python scripts/audit_candidate_rolling.py \
  --input-snapshot /tmp/finscope-candidate-frozen-1430-20261114.json.gz \
  --output /tmp/candidate-replay-new-report.json
```

重新取数据库快照时使用 `--database`、`--through`、`--cutoff` 与 `--snapshot-output`；所有输出要求新文件，不能覆盖旧证据。

- 前端全量 **789 项通过**，TypeScript/Vite 构建通过。保留已有依赖弃用和大分块提示。
- Playwright 检查真实回放数据对应的实际组件，1440px 桌面与 390px 手机；手机展开后页面仍为 390px，表格只在自己的容器横向滚动。
