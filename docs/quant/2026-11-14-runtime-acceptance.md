## 本次发现和改进

1. **训练记录排序错误。** 原查询按任务键倒序截断。键中加入新协议后，新执行的任务反而排在旧任务之后，甚至最新完成的 14:45 任务不在返回的六条记录内。现在先按 `startedAt` 排序再截断，并补充相应 SQLite 索引；前端也按执行时间选择最近任务。
2. **运行中缺少阶段反馈。** 每个训练组件开始、完成及准备、发布阶段持久化进度；写入同时校验任务租约，过期工作线程不能覆盖新任务。完成任务保留已写入的阶段状态。前端在研究详情内区分训练中、上一服务版本、新版完整就绪；旧运行时没有进度时显示等待回报，不伪造零进度。
3. **训练池与真实候选差异此前没有自动核对。** 新增 `overnight-candidate-support-v1` 描述性诊断，在候选样本准备时自动计算、随新训练产物保存，在现有候选详情中展示。同日期配对、日期等权，只使用完整且已到期的候选日；原池中已知不具备训练资格的记录排除。该诊断不调整预测概率，不改变训练资格或准入门槛。
4. **移动端诊断表格。** 详情默认折叠，保留透明背景；数字不换行，表格独立横向滚动并可键盘聚焦。修正展开表格时 Grid 最小宽度撑大页面的问题。
