# 事件研究系统加固实现计划

> **给智能体执行者：** 必须使用子技能：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行本计划。步骤使用复选框（`- [ ]`）语法跟踪。

**目标：** 将 FinScope 从可运行的研究原型升级为高质量事件研究系统，具备真实的研究运行时骨架、经过校验的任务/选题生命周期 API，以及可维护的前后端结构。

**架构：** 保持模块化单体。后端模块补齐缺失的研究骨架对象和编排服务，通过明确的请求 DTO 与服务校验收拢生命周期/状态管理；前端按功能拆分，让 shell 不再承载所有关注点。

**技术栈：** Java 8、Spring Boot 2.7、JdbcTemplate + SQLite、React、TypeScript、Vite、Vitest。

---

## 风格约定

- 本计划中新建或修改的所有 Spring bean 只使用构造器注入。
- 涉及的生产文件中不使用 `@Resource` 或字段级 `@Autowired`。
- Controller 只暴露类型化 request/response 契约。
- Service 负责业务规则和状态校验。
- Repository 只负责 SQL。
- 前端从单文件组合迁移到面向功能的模块。
- 每个行为变更都从失败测试开始。
