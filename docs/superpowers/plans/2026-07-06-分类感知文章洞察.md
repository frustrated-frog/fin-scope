# 分类感知文章解读实现计划

> **给智能体执行者：** 必须使用子技能：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行本计划。步骤使用复选框（`- [ ]`）语法跟踪。

**目标：** 让 AI 文章解读使用按分类定制的中文分析章节，并对英文原文做特殊处理。

**架构：** 新增轻量 `InsightSection` 值对象，并在 `InsightCard` 上持久化 `analysis_sections` JSON。后端 prompt 要求 LLM 根据文章分类输出稳定的 `analysisSections` 数组；前端优先渲染该数组，没有时再回退到旧的固定深度字段。

**技术栈：** Java/Spring/JdbcTemplate/Jackson、SQLite、React/TypeScript/Vitest。
