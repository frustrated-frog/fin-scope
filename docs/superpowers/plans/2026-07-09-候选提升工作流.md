# Intake Promote 工作流第二阶段实现计划

> **给智能体执行者：** 必须使用子技能：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行本计划。步骤使用复选框（`- [ ]`）语法跟踪。

**目标：** 人工 Promote Intake 候选后，不只创建 Article，还自动生成可见的事件、证据、学习任务和内容选题工作包。

**架构：** 保持 Intake 人工入库边界不变；新增窄口径 `PromotionWorkflowService` 复用 `EventClusterService.attachArticle(article)`；`IntakeService.promote` 返回结构化 response；前端 Intake 展示 Promote 后研究工作包摘要。

**技术栈：** Java 8、Spring Boot 2.7、SQLite/JdbcTemplate、React 18、TypeScript、Vitest、JUnit 5、Spring MockMvc。

---

## 文件结构

后端新增：

- `backend/finscope-domain/src/main/java/com/finscope/domain/intake/PromoteIntakeCandidateResponse.java`：Promote API 响应 DTO。
- `backend/finscope-service/src/main/java/com/finscope/service/intake/PromotionWorkflowService.java`：Promote 后研究工作包编排。

后端修改：

- `backend/finscope-service/src/main/java/com/finscope/service/intake/IntakeService.java`：Promote 返回 DTO，并调用 PromotionWorkflow。

- `backend/finscope-web/src/test/java/com/finscope/web/FinScopeApiIntegrationTest.java`：补 Promote 工作流测试。

前端修改：

- `frontend/src/shared/types/index.ts`：新增 `PromoteIntakeCandidateResponse`。

- `frontend/src/App.test.tsx`：补 UI 断言和 mock 返回字段。
