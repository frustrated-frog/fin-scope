# 文章事件证据链路整改 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让文章入库、事件归属和证据治理具备原子性、并发一致性、可追溯性与可信前端状态。

**Architecture:** 后端通过数据库唯一约束、事务边界和幂等冲突恢复保证文章到事件的单归属；证据以标准化 claim key 去重，并对空事件统一归档。前端引入请求 generation、局部刷新与治理 mutation 状态，页面只展示已确认的任务和事件数据。

**Tech Stack:** Java 8、Spring Boot、Spring JDBC、SQLite、React 18、TypeScript、Vitest、JUnit 5、Mockito。
