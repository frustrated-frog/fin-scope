# 文章抓取 SSE 双通道 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为文章 URL 抓取建立 SSE 实时主通道、数据库事实状态和轮询恢复兜底。

**Architecture:** Service 层定义与 Web 无关的任务事件发布契约，Web 层实现支持快照、多订阅者和有界缓冲的 SSE 注册表。任务服务严格执行“先持久化状态，再发布事件”；前端以独立协调器管理 EventSource、低频事实轮询、断线加速轮询和终态确认。

**Tech Stack:** Java 8、Spring MVC `SseEmitter`、Spring JDBC、React 18、TypeScript、Vitest。
