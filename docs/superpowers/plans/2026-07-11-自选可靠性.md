# 自选列表可靠性实现计划

> **给智能体执行者：** 必须使用子技能：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行本计划。步骤使用复选框（`- [ ]`）语法跟踪。

**目标：** 让股票、基金和板块的自选行情、归因数据与归因进度正确、可恢复且足够快。

**架构：** 保持模块化单体边界。行情 adapter 留在 `finscope-rpc`，缓存和自选编排留在 `finscope-service`，持久化查询留在 `finscope-dao`，API/React 状态继续作为类型化响应的薄消费层。

**技术栈：** Java 8、Spring Boot 2.7、SQLite、React、TypeScript、Vitest、JUnit。
