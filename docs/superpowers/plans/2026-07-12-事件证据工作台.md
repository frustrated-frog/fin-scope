# 事件证据工作台实现计划

> **给智能体执行者：** 必须使用子技能：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行本计划。步骤使用复选框（`- [ ]`）语法跟踪。

**目标：** 保留事件研究工作流，同时把证据重建为可追踪的 thesis-and-evidence 工作台。

**架构：** 在 `EventEvidenceThesisService` 背后新增持久化的 `EventEvidenceThesis` 记录和 thesis/evidence 多对多链接。它刻意与现有 Research 页面里的 `ResearchThesis` 分离。`EvidenceService` 捕获证据时同步一个保守、确定性的 thesis。前端通过专用 workbench endpoint 获取数据；事件布局调整仍仅限前端。

**技术栈：** Java 8、Spring Boot 2.7、JdbcTemplate、SQLite、React、TypeScript、Vitest。
