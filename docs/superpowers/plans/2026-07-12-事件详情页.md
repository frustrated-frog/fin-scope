# 事件详情页实现计划

> **给智能体执行者：** 必须使用子技能：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行本计划。步骤使用复选框（`- [ ]`）语法跟踪。

**目标：** 用队列页和应用内原生事件详情页替换拥挤的事件主从工作台。

**架构：** 在现有 App `View` 状态中扩展 `eventDetail`，并复用 `focusedEventId` 承载选择。将只属于队列的关注点拆到 `EventsView`，把获取、解读和治理迁移到新的 `EventDetailView`；不需要后端接口变更。

**技术栈：** React 18、TypeScript、Vitest、现有 Fetch API client 和 CSS tokens。
