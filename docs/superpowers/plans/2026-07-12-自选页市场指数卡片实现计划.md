# 自选页市场指数卡片实现计划

> **给智能体执行者：** 必须使用子技能：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行本计划。步骤使用复选框（`- [ ]`）语法跟踪。

**目标：** 在自选页面的“我的自选”内容上方展示四个固定 A 股市场指数，并保持它们独立于用户自选列表。

**架构：** 后端新增 `INDEX` 新浪行情适配器和只读 `/api/market-indices`。`MarketIndexService` 固定代码、名称与返回顺序，复用 `QuoteService` 的批量抓取、30 秒缓存和降级；前端独立加载该资源，在自选表单前渲染无操作的响应式卡片。

**技术栈：** Java 8、Spring Boot 2.7、JUnit 5、React 18、TypeScript、Vitest、Testing Library、CSS Grid。

---

## 文件结构

- `backend/finscope-rpc/src/main/java/com/finscope/rpc/quote/SinaIndexQuoteAdapter.java`：唯一负责新浪指数协议。
- `backend/finscope-service/src/main/java/com/finscope/service/instrument/MarketIndexService.java`：固定四个产品指数并保持返回顺序。
- `backend/finscope-service/src/main/java/com/finscope/service/instrument/MarketIndexView.java`：服务层内部展示模型，避免 service 依赖 web。
- `backend/finscope-web/src/main/java/com/finscope/web/controller/MarketIndexController.java`：只读 HTTP 入口。
- `backend/finscope-web/src/main/java/com/finscope/web/response/MarketIndexQuoteResponse.java`：与可编辑自选响应隔离的公开契约。
- `frontend/src/shared/types/index.ts`：市场指数接口类型。

```java
@Component
public class SinaIndexQuoteAdapter implements QuoteAdapter {
    public boolean supports(String type) { return "INDEX".equalsIgnoreCase(type); }
    public List<Quote> fetch(List<String> codes) throws Exception {
        String symbols = codes.stream().map(SinaIndexQuoteAdapter::toSinaSymbol)
            .collect(Collectors.joining(","));
        return Arrays.stream(request(BASE_URL + symbols).split("\\n"))
            .map(SinaIndexQuoteAdapter::parseLine).filter(Objects::nonNull)
            .collect(Collectors.toList());
    }
    static Quote parseLine(String line) {
        String symbol = extractSymbol(line);
        Quote quote = new Quote(); quote.setInstrumentCode(stripPrefix(symbol));
        String[] fields = extractPayload(line).split(",");
        if (fields.length < 4 || fields[0].trim().isEmpty()) {
            quote.setValid(false); quote.setNote("未取到有效行情"); return quote;
        }
        quote.setName(fields[0].trim()); quote.setPrice(parseDouble(fields[1]));
        quote.setChangeAmount(round(parseDouble(fields[2])));
        quote.setChangePct(round(parseDouble(fields[3])));
        quote.setValid(quote.getPrice() != null && quote.getPrice() > 0);
        if (!quote.isValid()) quote.setNote("停牌或暂无成交");
        return quote;
    }
}
```

`fetch` 必须以 `s_sh000001,s_sz399001,s_sz399006,s_sh000688` 请求新浪，复用股票适配器的 HTTPS、GBK、Referer、User-Agent 与 8 秒超时。`parseLine` 对空/不完整 payload 返回同代码、`valid=false`、`note="未取到有效行情"`；价格不大于零时标记为无效。不得读写数据库。

- [ ] **步骤 3：实现固定顺序的服务和响应**

```java
private static final List<IndexDefinition> INDICES = Arrays.asList(
    new IndexDefinition("000001", "上证指数"),
    new IndexDefinition("399001", "深证成指"),
    new IndexDefinition("399006", "创业板指"),
    new IndexDefinition("000688", "科创50")
);
private static class IndexDefinition {
    private final String code; private final String name;
    private IndexDefinition(String code, String name) { this.code = code; this.name = name; }
}
private List<String> codes() {
    return INDICES.stream().map(index -> index.code).collect(Collectors.toList());
}
private Map<String, Quote> indexByCode(List<Quote> quotes) {
    return quotes.stream().collect(Collectors.toMap(Quote::getInstrumentCode, Function.identity(), (left, right) -> left));
}

public List<MarketIndexView> list() {
    Map<String, Quote> byCode = indexByCode(quoteService.fetch("INDEX", codes()));
    return INDICES.stream().map(index -> new MarketIndexView(index.code, index.name, byCode.get(index.code)))
        .collect(Collectors.toList());
}
```

`MarketIndexView` 只在 service 层保存固定代码、固定名称与可能为空的 `Quote`；`MarketIndexQuoteResponse.of(view)` 仅公开 `code`、`name`、`price`、`changeAmount`、`changePct`、`quoteValid` 和 `quoteNote`。缺失行情使用 `quoteValid=false`、`quoteNote="暂无行情"`。控制器只提供 `GET /api/market-indices`。不得改动 `/api/watchlist`、`WatchlistService`、`instrument` 或 `watchlist_item`。
