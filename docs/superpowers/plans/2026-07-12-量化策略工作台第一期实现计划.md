# 量化策略工作台第一期 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 FinScope 中交付后端 SQLite 持久化支持的策略工作台：维护基金/股票组合、采用策略模板、孵化股票研究命题和记录复盘。

**Architecture:** 新建独立 `strategy` 领域，复用 `instrument` 而不依赖 `watchlist_item`。Domain、Repository、Service、Controller 各自只承担一层职责；服务层执行不变量与事务，前端只通过 `/api/strategy/*` 访问响应 DTO。

**Tech Stack:** Java 8、Spring Boot 2.7、JdbcTemplate、SQLite、JUnit 5、React 18、TypeScript、Vitest、Testing Library、CSS。

private void validateTargetWeight(Long excludeId, double candidateWeight) {
    if (holdingRepository.sumTargetWeightExcluding(excludeId) + candidateWeight > 100.000001d) {

    }

- [ ] **Step 3: 实现 DTO 与单一控制器。**

```java
@RestController
@RequestMapping("/api/strategy")
public class StrategyController {
    @GetMapping("/overview")
    public StrategyOverviewResponse overview() {
        return StrategyOverviewResponse.of(overviewService.load());
    }
    @PostMapping("/holdings")
    public StrategyHoldingResponse addHolding(@RequestBody AddStrategyHoldingRequest request) {
        return StrategyHoldingResponse.of(holdingService.add(request.getCode(), request.getType(), request.getRole(),
            request.getTargetWeight(), request.getCurrentWeight(), request.getNote()));
    }
    @PatchMapping("/holdings/{id}")
    public StrategyHoldingResponse updateHolding(@PathVariable Long id, @RequestBody UpdateStrategyHoldingRequest request) {
        return StrategyHoldingResponse.of(holdingService.update(id, request.getRole(), request.getTargetWeight(),
            request.getCurrentWeight(), request.getNote(), request.getRevision()));
    }
    @DeleteMapping("/holdings/{id}")
    public void deleteHolding(@PathVariable Long id, @RequestParam long revision) {
        holdingService.delete(id, revision);
    }
}
```

补齐精确路由：`GET /playbooks`、`PUT /playbooks/{code}/status`、`GET/POST/PATCH/DELETE /stock-theses`、`GET/POST/DELETE /reviews`。所有更新/删除均传 revision；行情失败时 overview 的 `quoteValid=false`，不能导致 500。
