# 命题研究报告生成与简报解耦实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立按研究运行隔离、围绕命题组织、证据充分性可迭代且长度有硬上限的独立研究报告，并彻底移除研究运行对每日简报的写入。

**Architecture:** 新增 `ResearchReport` 聚合、run-scoped 上下文、研究规划、相关性筛选、充分性评估和报告生成组件。`ResearchService` 只调用研究报告流水线，动态 Google News RSS 用临时 Source 执行且不污染来源配置；每日简报服务保持独立。

**Tech Stack:** Java 8、Spring Boot 2.7、SQLite、ROME、Jackson、React/TypeScript、JUnit 5、Mockito。
