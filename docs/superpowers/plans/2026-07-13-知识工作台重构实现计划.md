# FinScope 知识工作台重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Topics 与 Learning 合并为结构清晰的 Knowledge 工作台，并建立 Agent 建议、正式学习任务、知识成果、Topic 复习和 Vault 投影的完整后端闭环。

**Architecture:** SQLite 是事实源，Topic 是长期知识聚合，LearningTask 是显式状态机，KnowledgeEntry 是用户成果。跨数据库与文件系统写入使用事务内 projection job 与提交后幂等投影，不伪造跨资源原子性；前端按 Knowledge feature 独立请求和导航，不再把全量任务塞进 App 状态。

**Tech Stack:** Java 8、Spring Boot 2.7、Spring JDBC/Transaction、SQLite、JUnit 5、Mockito、React 18、TypeScript、Vite、Vitest、Testing Library。

---

## Scope and delivery rule

本计划分成三个可运行阶段：

1. Backend integrity：状态机、版本迁移、知识成果、事务完成、Vault 投影、Overview/API。
2. Unified workspace：合并导航、今日工作台、主题档案、待学习工作区。
3. Review and hardening：复习、Topic 资料聚合、响应式、迁移副本验收和性能查询。

每个 Task 完成后只提交该 Task 涉及的文件。不得把未通过测试的后续工作混入当前提交。
