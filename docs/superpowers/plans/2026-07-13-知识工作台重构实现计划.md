# FinScope 知识工作台重构实现计划

> **给智能体执行者：** 必须使用子技能：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行本计划。步骤使用复选框（`- [ ]`）语法跟踪。

**目标：** 将 Topics 与 Learning 合并为结构清晰的 Knowledge 工作台，并建立 Agent 建议、正式学习任务、知识成果、Topic 复习和 Vault 投影的完整后端闭环。

**架构：** SQLite 是事实源，Topic 是长期知识聚合，LearningTask 是显式状态机，KnowledgeEntry 是用户成果。跨数据库与文件系统写入使用事务内 projection job 与提交后幂等投影，不伪造跨资源原子性；前端按 Knowledge feature 独立请求和导航，不再把全量任务塞进 App 状态。

**技术栈：** Java 8、Spring Boot 2.7、Spring JDBC/Transaction、SQLite、JUnit 5、Mockito、React 18、TypeScript、Vite、Vitest、Testing Library。

---

## 范围和交付规则

本计划分成三个可运行阶段：

1. 后端完整性：状态机、版本迁移、知识成果、事务完成、Vault 投影、概览/API。
2. 统一工作台：合并导航、今日工作台、主题档案、待学习工作区。
3. 复习与加固：复习、Topic 资料聚合、响应式、迁移副本验收和性能查询。

每个 Task 完成后只提交该 Task 涉及的文件。不得把未通过测试的后续工作混入当前提交。
