# 研究运行可靠性与报告阅读修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复历史运行报告 404、报告模型长等待、运行过程不可观察以及报告打开后不可见四个问题，并完成 run 15 受控迁移。

**Architecture:** 后端用显式报告能力字段消除前端推断，用单次 LLM 超时和证据充分性门禁控制报告延迟；前端继续使用现有轮询，但将计划步骤投影为可理解的阶段轨道，并把报告切换为独立阅读状态。遗留数据通过现有 regenerate API 补建，成功后再解除 BRIEF 关联。

**Tech Stack:** Java 8、Spring Boot 2.7、SQLite、JUnit 5、React 18、TypeScript、Vitest、Testing Library、ReactMarkdown。
