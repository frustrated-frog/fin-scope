# 自选归因报告回看实现计划

> **给智能体执行者：** 必须使用子技能：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行本计划。步骤使用复选框（`- [ ]`）语法跟踪。

**目标：** 让自选卡片的最新归因摘要可点击回看完整报告，并在报告页查看和切换同一标的的历史归因。

**架构：** DAO 批量向自选视图提供最新已完成报告元数据，避免 N+1；前端将现有归因阅读器拆分为“运行模式”和“只读模式”，只读模式加载完整报告及最近 50 条已完成历史。按钮文案由行情交易日与报告交易日决定。

**技术栈：** Java 8、Spring、JdbcTemplate、SQLite、React、TypeScript、Vitest、Testing Library、CSS。
