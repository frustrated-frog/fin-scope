# 量化策略平台第二期 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 FinScope 中交付 A 股日频多因子策略从数据集、Agent 草案、人工确认到确定性回测和实验解读的完整闭环。

**Architecture:** 新增独立 `quant` 领域，数据、因子、策略、回测和实验按聚合边界拆分。Agent 只输出白名单 DSL，纯 Java 回测核心不依赖 Spring/SQLite/LLM；Web 层只做契约转换，前端以实验流水线呈现结果。

**Tech Stack:** Java 8、Spring Boot 2.7、Spring JDBC、SQLite、Jackson、JUnit 5、React 18、TypeScript、Vitest、CSS/SVG。

---

## 文件结构

- `finscope-domain/.../quant/data/*`：数据集、日线、财务快照、质量问题。
- `finscope-domain/.../quant/factor/*`：因子定义、值和诊断结果。
- `finscope-domain/.../quant/strategy/*`：受限 DSL、草案和不可变版本。
- `finscope-domain/.../quant/backtest/*`：回测输入、曲线、交易、指标和结果。
- `finscope-dao/.../quant/*Repository.java`：按聚合拆分 SQL 映射。
- `finscope-service/.../quant/data/*`：导入、质量、指纹和学习数据。
- `finscope-service/.../quant/factor/*`：目录、计算与诊断。
- `finscope-service/.../quant/strategy/*`：DSL 校验、Agent 与版本确认。
- `finscope-service/.../quant/backtest/*`：无框架依赖的回测与指标核心。
- `finscope-service/.../quant/experiment/*`：实验编排和结果持久化。
- `finscope-web/.../quant/*`：四组 Controller、请求与响应 DTO。
- `frontend/src/features/quant/*`：API、实验室、数据中心、因子库、实验详情和图表。
- `frontend/src/features/strategy/LongTermStrategyView.tsx`：承接一期页面。

## 计划自审

- PRD 的数据、因子、Agent、回测、实验和 UI 均有对应任务。
- 数据可见性、T+1 执行、交易成本、学习数据水印、不可变版本和确定性均有自动化测试。
- 所有后端能力沿 Domain/DAO/Service/Web 分层，没有通用巨型 Service。
- 二期没有 Python 编辑器、基金回测、自动参数搜索和下单能力。
- 实施采用当前会话内执行；用户已明确要求不中途等待选择，因此不再请求执行方式。
