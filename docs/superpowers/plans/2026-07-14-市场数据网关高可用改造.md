# 市场数据网关高可用改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不增加页面数据栏目和手动数据源切换入口的前提下，把现有行情、板块和资金流刷新统一接入后台市场数据网关，实现健康路由、主备竞速、逐标的补洞、熔断、持久化最后成功快照和明确降级提醒。

**Architecture:** `MarketDataGateway` 是业务服务访问外部市场数据的唯一入口。Provider 以能力和故障域注册，网关按优先级、熔断状态、限频余量、成功率和延迟选择健康来源；行情支持 hedge 和逐标的补洞，所有能力都经过质量门禁，失败时返回持久化最后成功快照。现有 REST 路径与页面结构保持不变，只增加只读质量元数据和常驻状态提示。

**Tech Stack:** Java 8、Spring Boot 2.7、JdbcTemplate、SQLite、Jackson、`CompletableFuture`、React 18、TypeScript 5.6、Vitest、Testing Library、Maven。

```java
@Data
public class ProviderResult<T> {
    private final T data;
    private final LocalDateTime retrievedAt;
    private final String payloadHash;
    private final List<String> warnings;

    public static <T> ProviderResult<T> of(T data, LocalDateTime retrievedAt,
                                           String payloadHash, List<String> warnings) {
        return new ProviderResult<T>(data, retrievedAt, payloadHash,
                warnings == null ? Collections.<String>emptyList() : warnings);
    }

    public static String hashOf(Object value) {
        try {
            byte[] bytes = MessageDigest.getInstance("SHA-256")
                    .digest(String.valueOf(value).getBytes(StandardCharsets.UTF_8));
            StringBuilder hex = new StringBuilder();
            for (byte valueByte : bytes) hex.append(String.format("%02x", valueByte));
            return hex.toString();
        } catch (NoSuchAlgorithmException error) {
            throw new IllegalStateException("JDK 缺少 SHA-256", error);
        }
    }
}
```

让 `QuoteAdapter`、`SectorMarketProvider`、`CapitalFlowProvider` 继承 `MarketDataProvider`，并增加返回 `ProviderResult` 的默认包装方法；已有 `fetch` 签名暂时保留以降低迁移风险，网关只调用包装方法。为现有 Provider 固定声明：腾讯优先级 10；新浪 20；东方财富与天天基金按各自唯一能力为 10；来源家族统一为 `TENCENT`、`SINA`、`EASTMONEY`。批量上限、最小间隔和超时必须来自 Provider 元数据，Guard 与网关不得根据厂商名称写分支。

- [ ] **Step 3: 将 Guard 改为 endpoint + family 状态**

```java
public <T> T execute(MarketDataProvider provider, MarketDataCapability capability, Operation<T> operation) {
    EndpointKey key = new EndpointKey(provider.providerCode(), capability);
    State endpoint = endpoints.computeIfAbsent(key, ignored -> new State());
    State family = families.computeIfAbsent(provider.providerFamily(), ignored -> new State());
    assertClosed(endpoint, family, provider);
    sleepOutsideLock(reserveDelay(endpoint, provider.minimumInterval()));
    long started = System.nanoTime();
    try {
        T value = retry(operation);
        recordSuccess(endpoint, family, elapsedMillis(started));
        return value;
    } catch (ProviderContractException error) {
        recordFailure(key, endpoint, provider.providerFamily(), family, error);
        throw error;
    }
}
```

每个 `State` 自己同步更新；只在锁内计算下一次允许时间，不在任何锁内 `sleep`。Endpoint 连续 3 次可重试失败打开 60 秒；30 秒内同一 family 的两个不同能力失败后打开 family 熔断；半开状态使用 `AtomicBoolean probeInFlight` 只放行一次探测。

- [ ] **Step 4: 实现健康权重排序**

```java
public <P extends MarketDataProvider> List<P> order(List<P> providers, MarketDataCapability capability) {
    return providers.stream()
            .filter(provider -> provider.supports(capability))
            .filter(provider -> guard.isAvailable(provider, capability))
            .sorted(Comparator.comparingDouble(provider ->
                    provider.priority() + guard.failurePenalty(provider, capability)
                            + (1.0 - guard.successRateEwma(provider, capability)) * 100.0
                            + guard.latencyEwmaMillis(provider, capability) / 100.0))
            .collect(Collectors.toList());
}
```

固定优先级只提供基线；Guard 每次成功以样本 1、失败以样本 0 更新 EWMA 成功率，并同时更新延迟 EWMA，因此健康失败和延迟会自动改变实际顺序。不要增加任何前端或公开 REST 切源接口。

`MarketDataSingleFlight` 使用 `ConcurrentHashMap<String, CompletableFuture<?>>` 和 `putIfAbsent`。创建者执行任务并在 `finally` 删除自己的 Future，跟随者只等待同一 Future；异常完成也删除 key，避免后续刷新永久复用失败任务。

```java
@SuppressWarnings("unchecked")
public <T> T execute(String key, Supplier<T> supplier) {
    CompletableFuture<Object> created = new CompletableFuture<Object>();
    CompletableFuture<Object> existing = flights.putIfAbsent(key, created);
    if (existing != null) return (T) existing.join();
    try {
        T value = supplier.get();
        created.complete(value);
        return value;
    } catch (Throwable error) {
        created.completeExceptionally(error);
        throw error instanceof RuntimeException ? (RuntimeException) error : new IllegalStateException(error);
    } finally {
        flights.remove(key, created);
    }
}
```

public CapitalFlowGatewayResult fetchCapitalFlow(Instrument instrument, LocalDate asOfDate) {
    List<CapitalFlowProvider> candidates = policy.order(capitalProviders, MarketDataCapability.CAPITAL_FLOW_5M);
    for (CapitalFlowProvider provider : candidates) {
        try {
            CapitalFlowData data = guard.execute(provider, MarketDataCapability.CAPITAL_FLOW_5M,
                    () -> provider.fetch(instrument, asOfDate));
            if (!data.getMinutePoints().isEmpty()) return CapitalFlowGatewayResult.fresh(provider.providerCode(), data);
        } catch (ProviderContractException error) {
            attempts.add(error);
        }
    }
    return CapitalFlowGatewayResult.unavailable(joinAttempts(attempts));
}

## 完成标准

- 用户点击现有刷新按钮时不选择、不感知具体数据源。
- 所有现有外部市场数据调用都通过 `MarketDataGateway` 或其 typed route，不再在业务 Service 中 `findFirst()` Provider。
- 股票和指数具备腾讯与新浪两个独立在线故障域，并能自动 hedge、切源和逐标的补洞。
- 基金、板块和 5 分钟资金流没有等价在线备源时不伪造多源，统一使用持久化最后成功数据。
- 应用重启后旧行情和板块目录仍可兜底。
- 旧数据永远带 `STALE_FALLBACK/PARTIAL_FRESH` 和常驻提醒，不能伪装成刷新成功的新数据。
- Provider 健康、Family 风控、限频、审计和清理均有确定性测试。
- 当前页面没有新增数据栏目，也没有任何手动数据源切换控件或公开 provider 参数。
