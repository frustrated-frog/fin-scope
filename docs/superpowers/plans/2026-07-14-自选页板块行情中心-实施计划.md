# 自选页板块行情中心 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在自选页增加独立的板块行情中心，提供行业/概念领涨领跌排行、任意板块搜索、持久化关注和板块归因入口，同时让下方我的自选只保留股票与基金。

**Architecture:** 使用独立 `SectorMarketProvider` 获取完整板块目录快照，`SectorMarketService` 在同一快照上完成确定性排行、搜索、30 秒新鲜缓存、15 分钟过期降级和 single-flight。关注关系复用 `watchlist_item`，但通过板块专用 REST 合同与普通股票/基金自选隔离；前端拆成独立数据 Hook 和三个区域组件。

**Tech Stack:** Java 8、Spring Boot 2.7、JdbcTemplate、SQLite、Jackson、React 18、TypeScript 5.6、Vitest、Testing Library、Maven。

```java
public interface SectorMarketProvider {
    String providerCode();
    boolean supports(SectorCategory category);
    SectorMarketSnapshot fetch(SectorCategory category);
}

@Component
public class EastmoneySectorMarketProvider implements SectorMarketProvider {
    private static final Pattern CODE = Pattern.compile("BK\\d{4}");
    private final FinanceHttpClient http;
    private final ObjectMapper json = new ObjectMapper();

    @Autowired
    public EastmoneySectorMarketProvider(FinanceHttpClient http) { this.http = http; }

    @Override public String providerCode() { return "EASTMONEY"; }
    @Override public boolean supports(SectorCategory category) { return category != null; }

    @Override
    public SectorMarketSnapshot fetch(SectorCategory category) {
        FinanceHttpResponse response = request(category);
        JsonNode rows = readDiff(response);
        List<String> warnings = new ArrayList<String>();
        Map<String, SectorMarketEntry> entries = new LinkedHashMap<String, SectorMarketEntry>();
        for (JsonNode row : rows) {
            SectorMarketEntry entry = parse(row, category, warnings);
            if (entry != null) entries.put(entry.getCode(), entry);
        }
        return new SectorMarketSnapshot(category, providerCode(),
                LocalDateTime.ofInstant(response.getRetrievedAt(), ZoneId.systemDefault()),
                response.getPayloadHash(), new ArrayList<SectorMarketEntry>(entries.values()), warnings);
    }
}
```

Provider 固定构造东财板块目录请求；行业和概念仅改变内部筛选参数。解析字段映射为 `code/name/price/changeAmount/changePct/turnover/leaderStock*`，无效代码或名称写 warning 后丢弃，缺失领涨股保持 null。

public SectorMarketOverview overview(SectorCategory category, int limit, boolean refresh) {

public WatchlistItem followSector(String code) {
    String normalized = normalizeSectorCode(code);
    Optional<WatchlistItem> existing = watchlistRepository.findByCodeAndType(normalized, "SECTOR");

public WatchlistItemView followedSectorWithQuote(String code) {

@RestController
@RequestMapping("/api/sector-market")
public class SectorMarketController {
    @GetMapping("/overview")
    public SectorMarketOverviewResponse overview(
            @RequestParam SectorCategory category,
            @RequestParam(defaultValue = "5") int limit,
            @RequestParam(defaultValue = "false") boolean refresh) {
        return SectorMarketOverviewResponse.of(sectorMarketService.overview(category, limit, refresh));
    }

    @GetMapping("/follows")
    public List<FollowedSectorResponse> follows(@RequestParam(defaultValue = "false") boolean refresh) {
        return watchlistService.listFollowedSectorsWithQuotes(refresh).stream()
                .map(FollowedSectorResponse::of).collect(Collectors.toList());
    }

    @PutMapping("/follows/{code}")
    public FollowedSectorResponse follow(@PathVariable String code) {
        watchlistService.followSector(code);
        return FollowedSectorResponse.of(watchlistService.followedSectorWithQuote(code));
    }

    @DeleteMapping("/follows/{code}")
    public ResponseEntity<Void> unfollow(@PathVariable String code) {
        watchlistService.unfollowSector(code);
        return ResponseEntity.noContent().build();
    }
}
