# 策略研究中枢第三期 Phase A1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变现有 13 个量化因子与回测结果的前提下，建立资金行为进入量化研究的第一个可运行纵向切片：专业因子契约、真实时点冻结、版本化数据指纹、Provider 扩展点和只读研究 API。

**Architecture:** 保持现有 `domain → dao → service → web` Maven 依赖方向，以 `factorresearch` 逻辑包实现中立研究领域，不新建跨层 Maven 模块。资金源数据从 `market_capital_flow_snapshot` 通过 point-in-time 专用查询冻结到不可变 `quant_capital_flow_daily`；旧因子由兼容 Provider 包装，新资金因子通过同一计算入口接入。严格以 `retrieved_at` 作为 `available_at`，回溯抓取数据不得伪装为历史交易日可用。

**Tech Stack:** Java 8、Spring Boot 2.7.18、Spring JDBC、SQLite、JUnit 5、Mockito、Maven。

---

## Scope boundary

本计划只交付 A1 的可运行接缝，不实现 A2 的 IC/分组收益/中性化/样本外统计，也不实现 C 阶段的研究 Agent 编排。首个资金因子只实现 `MAIN_FLOW_SHARE`，用于验证数据桥与 Provider 架构；其状态最高为 `EXPLORATORY`，不能被标记为 `VALIDATED`。

本计划必须保持以下事实：

- 现有 13 个因子的值、IC 和回测结果不变；
- `DAY_1` 同标的同交易日多版本数据按 `retrieved_at DESC, id DESC` 唯一选择；
- `available_at = retrieved_at`，不得使用历史 `observed_at` 冒充可获得时间；
- Market Intel 的 `600519 + SH` 统一为 Quant 的 `600519.SH`；
- 资金分区进入数据集总指纹；
- `READY` 数据集拒绝原地追加或重新冻结；
- 回溯抓取造成 point-in-time 历史不足时，数据集进入 `BLOCKED` 而不是 `READY`。
