# 资金信号有效性与稳定历史样本实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不伪装多源能力的前提下，用 250 日在线窗口、本地历史合并和质量门禁扩大 Market Intel 单股事件研究样本，并增加相对无条件基线的信号有效性评价及更易读的 Agent 解读字体。

**Architecture:** 在线日线仍经现有市场数据网关获取，刷新协调器将其与持久化历史按交易日和质量合并。评价服务先调用独立历史质量门禁，再执行严格前缀回放和无条件基线比较；不合格数据只产生可解释的拒绝状态。新增统计随版本化评价快照持久化，前端只展示通过发布门槛的数字。

**Tech Stack:** Java 8、Spring、Jackson、SQLite/JdbcTemplate、JUnit 5、React、TypeScript、Vitest、Testing Library。
