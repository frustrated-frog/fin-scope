# 资金行为 Agent 因子化解读实施计划

> **执行要求：** 使用 `executing-plans` 逐任务执行；每个生产代码改动都先写失败测试，遵守 Red → Green → Refactor。

**目标：** 将 Market Intel 资金行为 Agent 从“少量原始数字的语言改写”升级为“确定性资金因子 + 可复算信号 + 不可变证据包 + 严格输出门禁”的结构化解读，并对模型降级、数据不足和失败给出明确提醒。

**架构：** `CapitalFlowPoint` 先进入纯 Java 时间序列算子和独立的 `CapitalFactorRegistry/Engine`，仅正式发布的因子进入 `CapitalSignalEngine` 和 `CapitalAgentEvidenceAssembler`。Agent 只读取证据包并输出 v2 JSON；解析器负责 JSON 提取和一次修复，门禁负责枚举、引用、数字和置信度校验。解释结果以新增 JSON 列持久化，前端按状态和分析维度展示。

**技术栈：** Java 8、Spring、Jackson、SQLite/JdbcTemplate、JUnit 5、React、TypeScript、Vitest、Testing Library。
