# 公司财报分析工作台 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 FinScope 中交付可运行的 A 股非金融企业财报工作台，支持结构化三张表、报告期追踪、累计值与单季度切换、财务质量规则、证据说明和完整前端入口。

**Architecture:** Python 市场数据服务负责把外部财务报表规范化为稳定 JSON；Java `financials` 领域负责报告、科目、指标、规则、持久化和 REST API；React 页面负责公司选择、报告切换、三张表阅读和分析呈现。所有财务数字使用明确来源类型，外部刷新失败时保留本地报告并返回部分状态。

**Tech Stack:** Python 3.11、FastAPI、Pydantic、AkShare、Java 8、Spring Boot 2.7、JdbcTemplate、SQLite、React、TypeScript、Vitest。
