# 数据库驱动作者策略入库 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the runtime playbook catalog constant, persist complete playbook definitions and ordered source-backed rules in SQLite, and show the Chen Xiao strategy in the existing long-term strategy library.

**Architecture:** Extend the existing single-user `strategy_playbook` aggregate and add a child `strategy_playbook_rule` table. A generic JSON seed loader migrates the five existing system cards without embedding their definitions in Java; future author strategies use a transactional create API. The frontend list reads database summaries and lazily loads a database-driven detail dialog.

**Tech Stack:** Java 8, Spring Boot 2.7, Spring JDBC, SQLite, Jackson, JUnit 5/Mockito/MockMvc, React, TypeScript, Vitest/Testing Library.

---
