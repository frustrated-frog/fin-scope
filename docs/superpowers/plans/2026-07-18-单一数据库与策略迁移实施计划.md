# 单一数据库与策略迁移实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让所有本地启动方式使用同一个现有主数据库，并把误生成数据库中独有的策略卡片及规则安全迁入主库。

**Architecture:** 在 Spring Boot 进入容器初始化前，由一个独立的运行时数据引导器解析并校验唯一绝对数据根目录，再同时设置文件存储根目录和 JDBC URL。数据迁移使用 SQLite 在线备份与单事务追加，按策略 code 幂等，不修改源库。

**Tech Stack:** Java 8、Spring Boot 2.7、JUnit 5、SQLite、Maven
