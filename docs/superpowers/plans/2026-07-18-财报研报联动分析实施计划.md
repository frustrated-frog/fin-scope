# 财报研报联动分析 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在公司财报分析页面交付可上传、详细阅读并与三张表事实验证联动的外部券商研报分析 Tab。

**Architecture:** 在 financials 限界上下文内新增独立的 broker research 聚合，原文、预测和观点分别持久化；服务层负责 PDF 解析、LLM/规则解读和查询时财报验证，前端独立面板按当前标的及报告期加载。现有内部 `research_report`、财报事实表和页面 URL 均保持不变。

**Tech Stack:** Java 8、Spring Boot 2.7、JdbcTemplate、SQLite、Jackson、PDFBox、React、TypeScript、Vitest、Testing Library。
