# 研报手动发现与按需导入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 进入研报分析页只读取本地数据，公开研报目录检查和单篇下载解读均由用户明确触发。

**Architecture:** 前端将初始化加载与目录检查拆成两个独立函数；初始化只加载本地列表，按钮调用只读 candidates API。后端删除自动导入 sync 入口和对应业务分支，只保留目录发现与按候选导入两条职责清晰的接口。

**Tech Stack:** React 18、TypeScript、Vitest、Spring Boot 2.7、JUnit 5、Mockito
