# 研报自动获取 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** 让公司财报页自动同步公开个股研报，并把公开 PDF 接入现有详细解读和财报联动管线。

**Architecture:** 以 BrokerResearchSource 隔离外部目录和文件下载，以 BrokerResearchSyncService 编排同步、去重和自动导入；BrokerResearchService 复用上传已有的解析、证据校验和存储流程。前端首次进入自动同步，并呈现已导入和待导入候选。

**Tech Stack:** Java 8、Spring MVC、Jackson、JDK HttpURLConnection、SQLite、React 19、TypeScript、Vitest。
