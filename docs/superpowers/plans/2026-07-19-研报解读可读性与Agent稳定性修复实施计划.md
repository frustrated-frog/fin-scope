# 研报解读可读性与 Agent 稳定性修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复真实券商 PDF 的文本污染、研报长文布局失衡和 45 秒超时导致的 Agent 降级。

**Architecture:** 在 PDFBox 原始文本与 Analyzer 之间增加独立净化器；Analyzer 使用 120 秒主调用和一次 60 秒结构修复，并生成短句级规则降级结果。前端将六维分析改为单列阅读流，原文证据默认折叠，并在顶部展示可操作的降级原因。

**Tech Stack:** Java 8、Spring Boot 2.7、PDFBox 3、Jackson、JUnit 5、React 18、TypeScript、Vitest、Testing Library、CSS。

---
