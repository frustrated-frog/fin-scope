# 量化市场数据可靠同步 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让真实量化数据集能从 Python 多源市场数据服务可审计地增量同步前复权日线，并向用户明确展示运行结果与降级状态。

**Architecture:** Python 路由保留真实 provider provenance、数据语义和最后事实时点；Java RPC 适配器将稳定信封映射为量化 bar batch；service 层以数据集和 PIT 股票池为边界编排幂等同步，DAO 持久化运行审计。前端仅提供一键同步与人可读状态，不暴露 provider 调度细节。

**Tech Stack:** Python 3.11+/FastAPI/Pydantic/SQLite/pytest，Java 8/Spring Boot/JdbcTemplate/JUnit 5/Mockito，React/TypeScript/Vitest。

class DailyBar(BaseModel):
    # existing fields
    adjustment: str = "NONE"

def _daily_bar_as_of(data: list[DailyBar]) -> datetime:
    last_date = max(date.fromisoformat(bar.trade_date) for bar in data)
    return datetime.combine(last_date, time(15, 0), tzinfo=ZoneInfo("Asia/Shanghai"))

def check_ready(self) -> tuple[bool, str]:
    with self._connect() as connection:
        connection.execute("BEGIN IMMEDIATE")
        connection.execute("UPDATE market_data_snapshot SET updated_at=updated_at WHERE 0")
        connection.rollback()
    return True, "snapshot_store_writable"
```

AkShare/Eastmoney bars 标记 `QFQ`，PyTDX 标记 `NONE`。`/ready` 仅检查本地快照库和 provider roster，不访问外网。

@PostMapping("/{id}/market-data-sync")
public QuantDataSyncRun sync(@PathVariable Long id) {
    return syncService.sync(id, "MANUAL");
}

@GetMapping("/{id}/market-data-sync-runs")
public List<QuantDataSyncRun> syncRuns(@PathVariable Long id) {
    return syncService.runs(id);
}

@Scheduled(cron = "${finscope.quant.market-data-sync-cron:0 30 18 * * MON-FRI}", zone = "Asia/Shanghai")
public void refreshBuildingDatasets() {
    for (QuantDataset dataset : datasets.findSyncEligible()) {
        try {
            syncService.sync(dataset.getId(), "SCHEDULED");
        } catch (RuntimeException error) {
            log.warn("scheduled quant market-data sync failed for dataset {}: {}",
                    dataset.getId(), error.getMessage());
        }
    }
}
```
