# 结构化深度研究报告 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前以通用规则模板为主的研究报告升级为对象特定、证据可追溯、结构稳定且具有深度正文的决策型研究报告。

**Architecture:** 报告生成拆为证据档案、结构化论证蓝图、深度正文、程序化 Markdown 组装和质量校验五个边界。模型只生成严格 JSON 内容，程序控制章节、证据锚点、来源附录和降级行为；前端从 Markdown 标题和证据编号构建目录与跳转，不改变现有 API 数据模型。

**Tech Stack:** Java 8、Spring Boot 2.7、Jackson、JUnit 5、Mockito、React、TypeScript、React Markdown、Vitest。

- [ ] **Step 3: 实现目录与证据跳转**

`extractReportSections(markdown)` 只解析 `##` 标题；ReactMarkdown 的 `h2` 自定义 renderer 使用同一 slug。文本中的 `[E1]` 在后端组装时生成标准 Markdown 链接，前端无需正则改写正文。

```ts
export function extractReportSections(markdown: string): ReportSection[] {
  return markdown.split('\n').filter(line => line.startsWith('## ')).map(line => {
    const title = line.slice(3).trim();
    return { title, id: `section-${slugReportHeading(title)}` };
  });
}
```
