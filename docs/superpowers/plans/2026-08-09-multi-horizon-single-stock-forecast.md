# 多周期单股预测实施计划

1. Python 红灯测试：补充 1/5/20 周期、T+1 标签、动态独立锚点、选择性预测与 v4 契约断言。
2. Python 实现：参数化周期、资格与稳定性，输出方向/弃权和覆盖率，修复 bootstrap 极端复利。
3. Java 红灯测试：Web 请求、RPC 契约、运行持久化与历史过滤加入周期维度。
4. Java 实现：薄 Controller、Service 编排、RPC JSON、SQLite 兼容迁移和响应模型。
5. 前端红灯测试与实现：5 日默认、期限结构带、选择性指标、历史周期/到期状态。
6. 分层验证：Python 全测、Java 定向测试、前端全测与构建，按《项目开发规范与代码评审清单》自审。
