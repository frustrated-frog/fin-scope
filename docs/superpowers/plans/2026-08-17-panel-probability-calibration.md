# 有限股票池联合学习实现计划

> 本计划遵循《项目开发规范与代码评审清单》，按测试驱动逐批提交并推送。

## 任务一：面板样本与模型产物

1. 为日期级截面样本、完整/降级特征覆盖和无未来数据约束增加失败测试。
2. 实现 `forecast/panel_features.py`，生成稳定排序、有上限的面板样本和当前截面特征。
3. 为模型产物原子保存、损坏回退、年龄状态和不可覆盖上一版增加失败测试。
4. 实现 `forecast/panel_artifact.py`，序列化轻量模型、校准器、训练分布与审计指标。
5. 运行 Python 聚焦测试并提交。

## 任务二：联合模型竞赛、收缩与漂移门禁

1. 为日期级扩展窗口、面板基线门槛、完整/降级独立验证增加失败测试。
2. 实现面板模型竞赛和全池独立 Platt 校准。
3. 为目标股票 Brier/Log Loss 比较、最大融合权重、WATCH 降权、REJECTED 回退增加失败测试。
4. 实现目标自适应收缩、融合后锁定区评估与漂移报告。
5. 运行 Python 聚焦测试并提交。

## 任务三：两条量化链路复用

1. 为单股接口“无产物/损坏/过期仍成功”增加 API 测试。
2. 让应用启动时只构造本地产物仓库，单股预测只读取产物。
3. 在股票发现完成行情准入后构建有限池，在深度预测前尝试训练并发布；训练失败只增加 warning。
4. 将同一面板运行上下文传入所有深度预测，避免每只股票重复读取和训练。
5. 扩展 Pydantic 结果与股票发现摘要，运行 Python 全量测试并提交。

## 任务四：Java 契约与持久化

1. 为 `panelModel` 必要字段、数值范围和状态关系增加 RPC 失败测试。
2. 在 domain 正确增加面板证据模型，并在 RPC 对 v8 报告严格校验。
3. 保持报告 JSON 原样持久化，不新增重复数据库列；验证历史记录可反序列化新旧版本。
4. 运行相关 Maven 模块测试并提交。

## 任务五：专业可视化

1. 为概率合成台、漂移仪表带、降级原因和发现覆盖矩阵增加前端失败测试。
2. 扩展 TypeScript 类型，实现单股概率合成可视化。
3. 实现股票发现面板覆盖矩阵与候选概率差异图。
4. 完成桌面/窄屏布局、无障碍标签、可读字号和空状态。
5. 运行前端聚焦测试和生产构建，提交并推送。

## 任务六：验证与交付

1. 运行 Python 全量测试、Java 相关及全量测试、前端全量测试和构建。
2. 启动本地服务，以有产物、无产物和板块源失败三种路径验收 API。
3. 用真实浏览器检查单股与股票发现页面，修正布局问题。
4. 对照开发规范检查字段注入、大括号、模块落点、敏感信息和冗余代码。
5. 提交剩余修正、推送分支并给出可复现验证结果。
