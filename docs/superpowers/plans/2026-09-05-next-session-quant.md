# 收盘后次日预测增强实施计划

**Goal:** 在现有股票发现和单股预测中提供真实行情驱动、明确目标交易日、可前瞻结算的次日预测；不增加 Tab。

**Architecture:** 复用 Python 行情与模型、Java 定时任务和不可变报告、React 现有页面。新增次日收盘相对本次收盘的价格预测，与原有 T+1 开盘入场的交易回测分开，避免把 T+2 退出误称为次日表现。现有 1/5/20 日交易研究继续保留。

**Tech Stack:** Python/scikit-learn、Spring/SQLite、React/TypeScript；不引入重型框架。

## 研究依据与取舍

- Qlib 论文 https://arxiv.org/abs/2009.11189 ，以及 microsoft/qlib `qlib/workflow/task/gen.py` 的 RollingGen/trunc_segments：借鉴滚动训练与标签截断设计，不复制代码、不引入 Qlib 常驻依赖。
- CQR https://arxiv.org/abs/1905.03222 ：借鉴独立校准收益区间，保留实际覆盖率；金融时序不能直接承诺交换性下的理论覆盖。
- ACI https://arxiv.org/abs/2106.00170 ：借鉴持续检验漂移的动机，本期不声称实现论文完整自适应算法。
- 上交所 2026 年休市通知 https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml ：准确标注下一交易日；未知年份不猜日期。

## 任务与验收

- [ ] 1. 修正单股/联合模型校准标签边界；先失败测试，再修复；旧联合模型产物失效。
- [ ] 2. 新增独立次日 close-to-close 标签预测：近期滚动训练、独立校准、最后一段按时序验证、模型/基线对比与收益区间；冻结截止日、目标日、模型版本和指纹。少样本/过期报告明确拒绝有效预测。
- [ ] 3. 接入现有 discovery 与 single-stock 报告；在现有页面展示概率、收益区间、预测日期与证据，不增加导航入口。筛选相对研究名单优先使用可靠次日证据，不放松原有交易门禁。
- [ ] 4. 补齐次日到期结算和可见真实结果，保持与原有交易收益不同口径；复用持久化报告，新增结果独立保存，不覆盖旧预测。
- [ ] 5. 检查定时恢复、最新行情与日期门禁；重启 Python、Java、前端，真实 API 与浏览器验证；记录实际可用数据、结果和无法保证的外部条件。

每批改动完成对应测试、自检、英文类型加中文主题提交并推送当前分支。保留用户已有 application.yml 改动及密钥。使用 subagent-driven-development 做独立实现与评审；所有修改在当前工作目录中进行。
