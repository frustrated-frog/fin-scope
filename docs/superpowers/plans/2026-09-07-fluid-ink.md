# 水墨流体与空间粒子实施计划

**目标：** 在当前分支把首页研究脉冲四卡升级为有惯性、涡旋和染料扩散的水墨，并增加受流场驱动的全局粒子背景。用户已批准推荐方案并明确要求直接实施。

**架构：** 前端 `shared/visuals/fluid` 隔离 GPU 算法，`FlowField` 管理 React 生命周期。参考 PavelDoGreat 的 MIT 流体求解与 Volcomix 的粒子平流算法，使用 Three.js 管理半浮点纹理、渲染目标和资源释放。全局背景一个上下文，卡片组一个上下文，四卡独立模拟但共享渲染器；避免跨 DOM 堆叠上下文裁切错误。业务数据和事件保持原接口。

**技术栈：** React 18、TypeScript、Three.js、WebGL2、Vitest、Playwright。

## 验收与预算

卡片中的文本必须位于独立 DOM 层，画布不截获点击。低性能设备逐级降低纹理清晰度和绘制频率；不可见卡片不求解。页面隐藏、系统减少动态效果时不持续绘制。初始化失败或上下文丢失保留 CSS 静态水墨。每次卸载释放纹理、材质、几何与事件监听器。全局颗粒保持低对比，文章和表格背景仍可阅读。

所有改动限于前端及对应说明，不读出、修改或提交现有 `application.yml` 的用户变更。
