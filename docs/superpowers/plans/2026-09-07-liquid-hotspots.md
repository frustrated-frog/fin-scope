# 今日热点液态玻璃实施计划

用户已批准在当前分支实施。目标是三块热点榜单拥有持续流动、可搅动并有惯性的半透明材质；四张脉冲卡片同时收敛为石墨、银白、冰青色系。

复用现有流体求解器和异步加载，无新增依赖。`FlowField` 扩展 panels 模式，一组热点共用一个画布，三个面板各自保存速度和染料状态。材质根据密度/速度梯度计算表面法线，对程序化环境光场进行折射采样，叠加随流动变化的银白薄层；Canvas 透明合成透出全局背景，DOM 文字不参与变形。这不是浏览器 DOM 截屏折射。
