# 三维星空背景修正

用户反馈上一版看不到动效、星空感和三维粒子，授权参考开源实现继续修改当前分支。

## 原因与修正

- 原粒子直接输出二维裁剪坐标，深度只影响大小；改用 PerspectiveCamera 和真实三维坐标，持续穿行、旋转、按距离缩放、鼠标视差，深度循环两端淡出。
- 原尺寸和透明度过低，透明 Canvas 上的常规混合还会使星点在浏览器合成时进一步变暗；先画不透明的低对比蓝灰星云，再合成星点，使最终背景 alpha 为 1。
- 原星云只有静态 CSS 渐变；增加随时间变化的程序化星云，复用背景画布。原 CSS 继续用于无 WebGL 时的静态回退。
- 星点预算分为 768 / 1408 / 2304，复用原质量调节、不可见暂停与减少动态策略；不修改七块彩色流体材质。

开源技术参考见流体目录 THIRD_PARTY.md，无新增依赖。

## 验收

- 先新增透视与宽高比回归测试，确认在原正交实现上失败，再实现修正。
- 5 个测试文件、15 项相关测试通过；生产构建通过，仍有既有主入口大包体提示。
- Chromium 深浅主题下三个画布正常初始化。390px 视口滚动宽度为 390px。
- 读取背景 WebGL 帧缓冲：1.6 秒内 48 帧，320×180 采样区有 516 个像素的 RGB 差值之和超过 12，确认持续运动；减少动态时绘制计数保持 59。
- 控制台无渲染错误；独立只读评审未发现阻断问题。条件括号、类型落点与项目规范已自检，后端用户配置不纳入提交。
