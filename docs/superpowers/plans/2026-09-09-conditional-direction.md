# 市场条件与相对强弱方向模型实施计划

> 使用 executing-plans，当前分支执行，不使用子智能体或 worktree。

**目标：** 用真正 OOF 的市场广度预测、个股排序和交互修正次日绝对上涨概率；以同池较强基础树为明确对照，实测是否提高准确率。

**结构：** 新增 conditional_direction.py 实现日期级市场模型、排序输入和正则残差模型；conditional_experiment.py 编排滚动预测、测试前选择；CLI 从 E0 冻结输入与逐条 OOF 文件读取，保存结果。复用既有 date_weights、ranking_labels、LightGBM 参数和日期分块评价，不增加依赖。

## 结果产生前固定的规则

- 完全使用 E0 冻结的 240 股、54 特征和 60 日期测试，已经看过的历史区间继续标记 RETROSPECTIVE。
- 基础概率为 E0 的 BASE_TREE:RAW（滚动原始概率）；不把 49.65% 的弱校准结果作为唯一基准。同时比较 E0 FIXED_LEGACY（54.04%）和滚动训练先验。
- 每五日重新拟合子模型，最多 505 日期。市场目标为同日目标池次日上涨比例，一日期一个观测；训练日期必须所有现存股票日标签均成熟。市场输入为三个市场指数特征及八个共同 STATE 特征，使用标准化 Ridge(alpha=100)，输出裁剪到 [0.01,0.99]。
- 排序使用现有 LambdaRank 参数及按日五档收益标签。E0 冻结输入没有市场收益目标，明确使用 ABSOLUTE 排序；输出按日期化为居中的排名百分位，不当作概率。
- 修正层 p=sigmoid(logit(pbase)+delta)，正则把 delta 系数收缩向零；仅使用此前最多120日期且已成熟的真实 OOF 子模型输出。最少30日期，否则保持基础概率。
- 四个候选输入：INTERCEPT（仅截距对照）、MARKET（市场预测与基础同日均值）、RANK（排名与基础同日相对分数）、JOINT（两组加市场×排名交互）。正则强度固定 0.01 和 0.1，总计八个，保留 BASE 原样候选；不做测试期阈值优化。
- 修正层标准化只在历史 OOF 上拟合，截距也受正则约束；不得用基础模型的训练内分数训练修正层。
- 选择区与 E0 相同，至少两个连续子时期优于 BASE，BA > 0.5，Brier 不劣于 BASE 超过0.001。合格候选按准确率、BA、Brier选择，无合格者回退 BASE。最终测试不再次选方法。
- 最终报告全部消融、逐股票日概率、市场广度误差、三个子时期准确率、全池覆盖、相对强基准的日期分块区间。不能挑测试最高者替代预选结果。
- 本轮历史表现即使提高也不自动成为前瞻验证通过；如尚未提高，如实报告，避免无限增加候选追逐已知测试期。
