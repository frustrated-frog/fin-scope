# 日线加行业直接分类实验

用户已授权按上一轮四步方案实施，当前分支，无子智能体。目标是验证行业信息能否增加次日方向准确率。

## 数据与限制

申万官网历史文件实测 HTTP 508；巨潮 p_stock2110 已返回真实行业变更数据，使用现有 AKShare 适配参考。仅保留分类编码 008003 的一级行业门类。逐条记录有效日期、供应商、分类口径、采集时间；供应商没有公告可用时间，因此不伪造 available_at。历史对照明确为 VENDOR_RECONSTRUCTION，按变更日后一自然日可用的研究假设；该假设不是已证实发布时间。不能用这些结果直接发布线上模型。

## 固定设计

- [x] providers 层抓取/归一化行业变更，保留原始响应、指纹和失败明细；先获取旧 240 股票研发池，不能声称独立全 A 股。
- [x] 在完整 observable panel 上生成同行剔除自身的 1/5/20 日动量、广度、活动、离散度、相对表现、缺失/覆盖特征。缺失为 NaN 与覆盖指示，不能假装中性。
- [x] 新增直接分类滚动实验：日线 D 与 D+S 两臂使用同一日期、标签、参数、权重、更新方式与固定种子。对全部可观测股票预测，标签只用于成熟训练和事后评分。
- [x] 固定 LightGBM 参数沿用现有 PARAMETERS，每 5 日更新，505 日训练，过去 60 日 OOF 截距校准；先预热 60 日，再评分三个不重叠 60 日窗口，不在测试后选校准或种子。
- [x] 每个窗口及总体报告 RAW 和固定 INTERCEPT（主结果），日期等权命中/BA/Brier、纠错/改错、配对日期分块区间、缺标签覆盖。不是对旧固定冠军的公平新冠军挑战。
- [x] 验证缺未来标签、改变未来标签不影响此前预测；真实数据跑完、重放、测试、代码自检、分批提交推送、服务重启验证。

## 判据

新增信息只有在多窗口方向与概率同时稳定改善时才值得进入影子验证。没有改善如实报告；本轮不调参追赶测试结果。原行业快照特征从 D 中排除（行业相关旧列），市场/截面日线特征保留。外层窗口仍是已发生历史和旧研发股票池，数据的公开可得时点也未证实，任何正结果仍不具有直接生产资格。
