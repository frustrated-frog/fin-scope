# E2 信息增量：可行性核验与首批实施

用户授权：评估桌面任务书并继续增强量化；在当前分支，不使用子智能体。附件作为待核验建议，不作为已有事实或额外授权。

## 决策

继续扩张旧日线校准候选的证据不足；直接堆叠深网无法隔离信息增量；采用真实行业/分钟信息的受控实验。直接二分类为主，残差为辅。现有历史窗口已经参与研发，所有重放只作为回顾证据。不得把筛选规则修复算作模型准确率提升。

## 首批

- [ ] 修复候选选择：BASE 始终合法；挑战者整段方向净增、BA 不退化、Brier 容忍 0.001、至少两段胜出；复杂修正须超过预选期合法截距参照。输出拒绝原因与独立生产资格。
- [ ] 从已存概率生成日期等权的纠错/改错、Brier 恒等分解与逐日概率漂移；同一股票日严校验，不重训、不覆盖旧报告。
- [ ] 核实可观测截面与标签表边界，保存不依赖未来标签的独立面板，兼容旧消费者；缺标签原因不猜测。
- [ ] 核实真实行业/分钟数据覆盖、历史长度及官方权限，给出直接分类实验的实际前置条件。
- [ ] 执行针对性与完整 Python 测试、自检、逐批提交推送；重启受影响服务并检查健康。

## 后续实验契约

有合格真实数据后冻结 D、D+S、D+M、D+S+M，固定股票池、切分、模型复杂度、日期权重和种子，多个不重叠外层窗口。长历史不得被 1061 条加载、505 日训练限制静默截断。先检查分钟聚合与同口径日线对齐；供应商历史重建不能冒充当时已采集。分钟盘后较晚可得时单独规定晚间截止时间，日线基准同步使用相同截止。未完成这些检查前不宣称进入 P2 或上线提高准确率。

## 验证

真实复现 57/57/51 对 56/56/56 的错误选择；测试 BASE、截距参照、小样本、未来标签隔离；归因之日期等权 delta 与原评价完全一致；Brier 两项之和等于原误差。以现有冻结预测计算实际纠错收益，保留输入指纹。线上概率策略不因回顾结果自动替换。
