# 次日方向与概率校准分离

用户授权：根据上一轮只读审计开始修改，当前分支，不开子智能体。

固定方案：RAW 是方向默认基准；是否让 INTERCEPT 改变方向，只看之前已经生成且标签成熟的 OOF 对照。每 5 日更新时评估过去 60 个成熟日期，至少 60 日才允许启用校准。方向门槛：整段准确率严格优于 RAW、BA 不退化、Brier 不退化，三个 20 日段至少两个准确率提升。概率门槛独立：整段 Brier 严格改善、三个日期段至少两个改善。两种输出分别命名，不能把校准概率直接暗当方向依据。
