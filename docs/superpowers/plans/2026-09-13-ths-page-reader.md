# 同花顺页面解读第一版实施计划

目标：手动读取当前 Mac 同花顺龙虎榜，在 FinScope 展示日期、股票、原始字段、买卖席位及固定阅读说明；可将快照带入研究问题。用户已确认此范围并要求直接实施，不使用子智能体。

架构：Mac 上 Swift 仅使用只读 Accessibility 属性，Python 标准库侧车负责限时调用和确定性解析；Java RPC → Service → Controller 接入现有 API；React 页面沿用现有导航与样式。独立采集权限不足时明确提示，不用演示数据冒充实测。无交易、自动切页、定时采集、数据库迁移或模型自动调用。

- [x] Java 接入：复用 FinanceHttpClient、ApiResponses，字段注入；请求有超时，错误归一为明确采集状态。
- [x] 前端：空态、读取中、失败、部分成功、时间标签、数据卡、席位原文、固定说明、研究预填；测试失败后不冒充新数据、无模型自动执行。
