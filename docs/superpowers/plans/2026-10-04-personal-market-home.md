# Market Pulse 个人研究首页

按用户确认的布局在当前 `codex/investment-observation-workspace` 分支开发，不建立工作树，不使用子智能体。

## 已确认设计

保留 Market Pulse 导航和市场概览，在今日雷达中增加双栏：左侧“与你有关的今日变化”，右侧“关注方向的新机会”；下方保留行业筛选、题材地图与赚钱效应。手机端单列。

自选名单用于关联已保存的事件、归因报告和行业。复用事件详情、归因报告、股票发现，不新建研究详情体系。

## 实现与验收

- [x] 轻量读取自选成员与已登记行业归属，不触发行情刷新。
- [x] 读取自选股票近七日事件、观察变化、归因报告，以观察日期截止。
- [x] 依据已登记行业及同日股票发现的行业成员关联自选；保留其他市场方向。
- [x] 双栏个人首页、分类切换、候选加入自选、原有页面跳转。
- [x] 后端相关测试、前端回归、构建与浏览器深浅主题及窄屏验收。
- [x] 分批提交推送当前分支，交付运行说明。

不修改运行配置和密钥；不会因浏览个人首页自动启动新的采集或模型任务。日期不匹配的最新股票发现名单不冒充历史候选；行业卡片仍使用正在查看的 Market Pulse 截面。
