# FinScope Research Agent 工作流设计

完整 TRD 已记录在 `docs/技术需求-研究智能体工作流.md`。

已确认方向：

1. 优先建设受治理的研究管线。
2. 在其上逐步叠加研究任务工作区。
3. 继续把确定性的 FinScope 服务作为执行主干。
4. Agent 能力用于任务理解、受控 LLM 节点、trace、budget、fallback 和恢复。

第一段实现切片：

1. 增加持久化的研究运行计划状态。
2. 在研究运行详情中返回计划步骤。
3. 在 Research 标签页展示计划步骤和更丰富的 trace 元数据。
4. 自然语言任务、澄清和恢复控制留到后续阶段。

自检：

1. 没有占位内容。
2. 不与完整 TRD 矛盾。
3. 范围有意收窄到 第一阶段，便于立即实现。
