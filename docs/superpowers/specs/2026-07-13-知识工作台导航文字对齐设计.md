# 知识工作台导航文字对齐设计

## 1. 目标

修正知识工作台四个一级导航项的文字重心，使主标题与辅助提示作为一个整体，在各自等宽导航框内水平、垂直居中，并建立清晰但克制的字号层级。

## 2. 调整范围

本次只调整 `KnowledgeNavigation` 的文字排版，不修改：

- 四等分导航结构；
- 导航高度；
- 激活态颜色、底部指示线和背景；
- 导航文案与交互行为；
- 知识工作台其他区域的字号和间距。

## 3. 排版规则

每个导航项继续使用单行布局：

```text
┌──────────────────────────┐
│     工作台首页  下一步    │
└──────────────────────────┘
```

- 导航项使用 flex 布局，主轴和交叉轴均居中；
- 主标题字号 `15px`、字重 `650`、行高 `1.2`；
- 辅助提示字号 `11px`、字重 `500`、行高 `1.2`；
- 主标题与辅助提示间距 `8px`；
- 四个导航项使用完全相同的排版规则；
- 移动端横向滚动导航复用同一文字规则。

## 4. 方案边界

不采用上下双行排版。双行排版虽然能进一步强调层级，但会改变当前导航的紧凑节奏并增加导航高度，不符合本次小范围修正目标。

不只修改 `text-align`。当前问题来自 flex 交叉轴使用基线对齐，因此必须将导航项的交叉轴改为居中，才能保证整组文字位于框体视觉中心。

## 5. 验收标准

1. 桌面端四组文字在对应等宽导航框中水平、垂直居中。
2. 四个主标题字号、字重和行高一致，辅助提示层级一致。
3. 主标题比辅助提示清晰一级，但不显得拥挤或过大。
4. 激活态底线、背景、点击行为和 URL 导航逻辑不发生变化。
5. 在 `720px` 以下视口中，导航仍可横向滚动，文字不换行、不挤压。
6. 现有知识工作台导航交互测试和前端构建通过。
