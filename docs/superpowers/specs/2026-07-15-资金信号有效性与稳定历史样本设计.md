# 资金信号有效性与稳定历史样本设计

- 日期：2026-07-15
- 状态：已确认，进入实施
- 适用页面：`Market Intel · 资金行为`
- 目标版本：`capital-evaluation-v2`

## 1. 决策

第一版采用单标的时间序列事件研究，不把结果称为横截面 IC 或 Rank IC。页面回答的是：同一只股票过去出现相同资金信号后，未来 1/3/5 个交易日相对该股票同期无条件基线表现如何。

全市场横截面 IC 需要稳定的股票池、交易日截面和批量日线数据集，继续由现有 Quant Dataset 边界承载，不与 Market Intel 的单股刷新链路混用。

## 2. 目标与非目标

### 2.1 目标

1. 将历史资金流窗口从约 20 日扩展到最多 250 个交易日。
2. 在线返回与本地成功历史按交易日合并，短返回不得删除或遮蔽已保存的好数据。
3. 在评价前执行新鲜度、样本量、价格覆盖、成交额覆盖和日期唯一性门禁。
4. 增加无条件收益基线、超额平均收益、超额中位收益、时间稳定性和多周期衰减。
5. 数据不稳或样本不足时不展示收益百分比，并给出中文原因。
6. Agent 只能引用通过数据门禁的探索性评价。
7. 适度增大 Agent 解读卡片字体，提高正文和证据行可读性。

### 2.2 非目标

- 本阶段不宣称资金流在线能力已经具备两个独立生产数据源。
- 不自动把任何信号升级为 `VALIDATED`。
- 不执行显著性检验、Bootstrap 置信区间或横截面 Rank IC。
- 不改变当前页面已展示的行情字段和刷新交互。

## 3. 历史数据稳定性

### 3.1 在线窗口

东方财富历史资金流和配套日线行情请求统一扩展到 250/260 个交易日。两个返回仍独立容错；资金流存在但行情缺失时保留资金事实并标记 `PARTIAL`，不伪造价格标签。

### 3.2 本地历史水库

刷新后始终读取最近 320 条已持久化日线，与在线日线按 `dataDate` 合并：

1. 同一交易日优先 `COMPLETE`；
2. 质量相同时优先较新 `retrievedAt`；
3. 在线短返回只补充或更新，不截断更早的本地历史；
4. 最终按日期升序输出，并限制为最近 250 个唯一交易日；
5. UI 的 20/60 日展示窗口保持不变，扩展历史只服务于因子计算与评价。

### 3.3 评价数据门禁

`CapitalHistoryQualityGate` 对评价输入生成确定性报告：

- 唯一日线样本至少 60 个；
- 最新样本距刷新基准日不超过 7 个自然日；
- 有效价格覆盖率至少 95%；
- 有效成交额覆盖率至少 90%；
- 交易日无重复，日期严格递增；
- 未来标签缺失率不得高于 10%。

未通过时，资金快照和规则解读仍正常保存，历史评价状态为 `DATA_UNRELIABLE`，百分比统计不发布，页面和 Agent 都显示明确缺口。

门禁不把周末和节假日误判为缺失交易日，不依赖自然日连续率。

## 4. 信号有效性评价

### 4.1 严格前缀回放

沿用 v1 的严格时点原则：事件日信号只读取截至当日的资金事实，未来价格只用于计算标签。任何未来资金字段都不能参与事件触发。

### 4.2 无条件基线

对每个 1/3/5 日周期，在相同评价窗口内计算所有可成熟交易日起点的前向收益，作为该股票自身的无条件基线。

每个信号输出：

- 信号平均/中位前向收益；
- 无条件平均/中位前向收益；
- 超额平均收益 = 信号平均收益 - 无条件平均收益；
- 超额中位收益 = 信号中位收益 - 无条件中位收益；
- 正收益占比、平均 MFE、平均 MAE；
- 前后半段超额收益方向是否一致；
- 1/3/5 日之间是否保持、增强或衰减。

基线只是控制该股票在同一窗口内的整体涨跌偏置，不代表市场基准超额收益。

### 4.3 发布状态

- `UNTESTED`：有效事件少于 5；
- `EXPLORATORY`：事件至少 5、数据门禁通过，可展示描述统计；
- `INVALIDATED`：本阶段不自动产生，保留给未来人工/实验门禁；
- `VALIDATED`：本阶段不自动产生，必须由后续更严格的统计检验和样本外验证授予。

Agent 引用仍只允许 `EXPLORATORY/VALIDATED` 且样本数达到门槛的评价。

## 5. 领域与持久化

`CapitalBehaviorEvaluation.VERSION` 升级为 `capital-evaluation-v2`。评价聚合增加：

- `historyQualityStatus`
- `priceCoverageRate`
- `amountCoverageRate`

单信号评价增加：

- `baselineAverageReturn`
- `baselineMedianReturn`
- `excessAverageReturn`
- `excessMedianReturn`
- `decayStatus`

已有评价表通过新迁移增加聚合层列；单信号新增字段继续保存于 `signals_json`，保持旧记录可反序列化。评价 fingerprint 包含门禁版本和合并后的有序历史事实。

## 6. 页面与交互

历史表现卡片增加“历史质量”摘要，并优先展示超额平均/中位收益，同时保留原始收益和波动统计。`DATA_UNRELIABLE` 使用琥珀色提示，不显示被门禁拦截的百分比。

Agent 观察卡片字体调整范围限定为：

- 维度标题 `10px -> 12px`；
- 因子数量 `8px -> 10px`；
- 观察正文 `11px -> 13px`；
- 证据标签/名称/值 `8/9/8px -> 10/11/10px`。

不改变整页字号体系，避免主次层级失衡。

## 7. 失败与降级

- 在线历史失败：使用本地历史水库，页面明确显示截至日期。
- 在线历史短返回：与本地合并，不覆盖旧好数据，并记录短返回告警。
- 历史门禁失败：行情刷新可成功，评价标记 `DATA_UNRELIABLE`。
- 评价服务异常：不阻断资金快照主链路，沿用“历史评价暂不可用”提醒。
- 旧评价记录：按 v1 字段兼容读取，不参与 v2 Agent 引用。
