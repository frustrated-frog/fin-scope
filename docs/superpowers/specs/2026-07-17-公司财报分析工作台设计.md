## 设计结论

FinScope 新增独立顶层入口 `Financials / 财报分析 / FI`，首期服务 A 股非金融企业。它同时解决两类核心需求：

1. 财报发布后快速理解本期经营变化；
2. 持续跟踪一家公司最近多个季度和年度。

产品采用“结构化三张表 + 财报 PDF 原文 + 确定性规则 + 按需 AI + Strategy 命题验证”的组合方案。自动抓取是主路径，用户上传 PDF 是低频补充入口。

## 核心页面

```text
综合结论
利润表
资产负债表
现金流量表
勾稽与财务质量
原文证据
历史档案
```

三张表必须直接呈现具体科目与数值，默认展示关键科目并允许展开完整报表。页面同时支持累计值和单季度值、同比、环比、结构占比、单位切换、科目释义和来源定位。

## 关键边界

- 结构化数据负责数值与计算，PDF 负责原文与页码证据。
- `REPORTED / DERIVED / CALCULATED / AI_EXTRACTED` 是明确的数据来源类型。
- 年报、季报、快报、更正公告和用户上传版本分别保存，不静默覆盖。
- AI 不修改原始数字，不自动修改 Strategy 投资命题，不生成买卖建议。
- 金融企业、OCR、复杂估值、同行比较和完整行业模板不进入第一期。
- Market Intel 保留市场行为职责，基本面深度分析统一进入 Financials。

## 技术方向

- 主应用新增独立 `financials` 领域并持久化不可变报告版本。
- 现有 Python 市场数据服务增加规范化财务报表能力。
- Java RPC 负责公告清单、PDF 下载和受控文件管理。
- PDF 首期按页提取文本，不依赖 PDF 表格抽取作为数值主来源。
- 财务金额和比率使用 `BigDecimal`。
- 单季度数据由版本化引擎从累计值推导并保存输入引用。
- 指标、规则、模型解释和命题影响均引用不可变研究快照。
- 外部数据、PDF 和 LLM 各维度允许部分成功并独立暴露质量状态。

## 交付顺序

```text
Phase A：报告、版本、结构化三张表与页面
  → Phase B：PDF、上传、原文证据和更正版本
  → Phase C：单季度推导、指标、勾稽和学习视图
  → Phase D：AI 解释、Strategy 命题影响和事件证据桥接
```

详细需求、验收标准、领域模型、数据表、API、错误处理和测试策略分别以对应 PRD 和技术方案为准。
