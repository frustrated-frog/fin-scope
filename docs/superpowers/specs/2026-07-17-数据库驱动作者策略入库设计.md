# 数据库驱动作者策略入库设计

> 日期：2026-07-17
> 状态：待用户复核
> 首个导入来源：《中长线股票策略基础》，陈潇，2020 年 3 月

## 1. 目标与产品决策

将外部书籍或文章中的完整投资方法整理为可追溯的个人策略，并展示在：

```text
策略 → 长期投资工作台 → 策略库
```

首个导入策略命名为“中长线质量趋势策略”。页面将它展示为一张完整策略卡，详情中再展开基本面筛选、趋势过滤、量价买点和风险纪律四个组成部分。

本次同时移除 `StrategyPlaybookService` 中的策略目录常量。策略定义、作者、来源和组成规则全部由数据库提供；后续导入其他作者策略时，不需要修改 Java 或前端代码。

本期不把书中观点直接标记为已验证策略，不自动生成买卖建议，也不自动发起回测。

## 2. 当前问题

当前 `strategy_playbook` 表只保存：

- `code`；
- 用户采用状态 `status`；
- 备注 `note`；
- 版本与时间字段。

标题、范围、摘要、执行节奏和风险边界来自 `StrategyPlaybookService.CATALOG`。服务只遍历该常量，因此向数据库直接插入一个新 `code`，页面仍然不会显示它。

现有卡片也没有作者、原始来源、证据状态和策略组成规则，无法区分“项目预置纪律”“作者经验”和“经过数据验证的研究结论”。

## 3. 页面设计

### 3.1 策略卡

“中长线质量趋势策略”卡片展示：

- 适用范围：A 股中长线；
- 状态：研究中；
- 摘要：以盈利质量建立候选池，用周线趋势确认方向，以量价形态选择买点，并用预设纪律控制退出；
- 执行节奏：每周检查，财报期复核；
- 风险边界：不在下跌趋势中抄底，不因下跌盲目补仓，趋势破坏后按预设规则退出；
- 来源：陈潇《中长线股票策略基础》；
- 验证状态：作者经验，尚未由 FinScope 验证。

保留“开始使用”和“暂停”操作。采用状态表达用户是否训练这套纪律，验证状态表达证据强度，二者不得混用。

### 3.2 策略详情

卡片新增“查看详情”入口，以沿用现有页面交互模式的对话框展示四个有序章节：

1. **基本面筛选**：扣非利润/EPS、经营现金流、营收增长、ROE、净利率、行业可比性和周期行业例外；
2. **趋势过滤**：先判断大盘和板块环境，再判断个股周线趋势，重点观察 20 周线；
3. **量价买点**：上涨趋势中的缩量回调至支撑位，以及放量平台突破；
4. **风险纪律**：不抄底、不盲目补仓、预先定义退出条件、允许空仓和错过机会。

每条规则必须展示规则性质和可验证性；有明确出处时同时展示原文页码。书中没有统一口径的内容必须显式标注，例如：

- 净利率门槛在不同页面出现 5%、8% 和 10%，不固化为自动规则；
- 12% 止损是作者举例，不视为已确认参数；
- “即将向上”“缩量”“平台突破”和“支撑位”尚未被操作化；
- 2020 年的板块判断和个股案例只作为历史例证。

## 4. 数据模型

### 4.1 扩展 `strategy_playbook`

在现有表上增加策略定义和溯源字段：

| 字段 | 含义 |
|---|---|
| `title` | 页面标题 |
| `scope` | 适用市场与持有周期 |
| `summary` | 策略摘要 |
| `cadence` | 执行与复核节奏 |
| `risk_boundary` | 核心风险边界 |
| `author` | 作者或提出者 |
| `source_title` | 原始书籍或文章名称 |
| `source_type` | `BOOK`、`ARTICLE` 或 `SYSTEM` |
| `source_ref` | 本地文件引用或可追溯标识，不向前端暴露不可用的绝对路径 |
| `source_published_at` | 来源发布日期，可为空 |
| `validation_status` | `UNVALIDATED`、`IN_RESEARCH`、`SUPPORTED`、`REFUTED`、`INCONCLUSIVE` |

现有 `status` 继续只表示 `RESEARCHING / ACTIVE / PAUSED`。`revision` 继续用于乐观锁。

### 4.2 新增 `strategy_playbook_rule`

每条规则独立保存，避免把详情重新硬编码成前端数组：

| 字段 | 含义 |
|---|---|
| `id` | 主键 |
| `playbook_id` | 所属策略，外键指向 `strategy_playbook` |
| `section_code` | 自由扩展的章节编码，如 `FUNDAMENTAL`、`TREND`、`ENTRY`、`RISK` |
| `section_title` | 面向用户的章节标题 |
| `rule_type` | `PRINCIPLE`、`FILTER`、`ENTRY`、`EXIT`、`CAUTION` 等规则性质 |
| `rule_text` | 面向用户的规则说明 |
| `testability` | `QUALITATIVE`、`CANDIDATE_RULE`、`DETERMINISTIC` |
| `source_page` | 原始页码，可为空 |
| `parameter_json` | 已明确的候选参数；未明确内容不得猜测填充 |
| `sort_order` | 页面顺序 |

策略与规则使用事务写入。相同 `code` 不允许静默覆盖，更新必须带 `revision`。

## 5. 数据迁移与入库

1. 数据库初始化器补齐新字段和规则表，不删除现有状态、备注或版本。新增字段在兼容迁移期间允许旧记录为空；迁移完成后，Service 对新建记录执行完整必填校验。
2. 将原来 Java `CATALOG` 中的五张预置卡移入版本化数据资源 `backend/finscope-dao/src/main/resources/db/seed/strategy-playbooks-v1.json`，由通用种子加载器幂等写入数据库，然后删除该常量。预置数据属于迁移资产，运行时服务不再包含任何策略定义。
3. 迁移数据只负责兼容已有预置内容；以后新增策略统一走创建接口或导入服务，不再增加代码分支。
4. 通过创建 Service 将“中长线质量趋势策略”及其规则事务性写入当前本地 `data/finance.db`，初始状态为 `RESEARCHING / UNVALIDATED`；不绕过业务校验执行裸 SQL。
5. 种子迁移以稳定 `code` 幂等写入，重复启动不生成重复卡片，也不覆盖用户状态。创建 API 收到重复 `code` 时返回业务冲突，避免把不同来源误当成同一策略。

推荐稳定编码：`STOCK_QUALITY_TREND_CHEN_XIAO_2020`。

## 6. API 与数据流

### 6.1 API

- `GET /api/strategy/playbooks`：完全从数据库返回策略卡摘要，不再合并代码目录；
- `GET /api/strategy/playbooks/{code}`：返回完整策略、来源信息和有序规则；
- `POST /api/strategy/playbooks`：创建一个数据库驱动策略及其规则，供后续书籍导入复用；
- `PUT /api/strategy/playbooks/{code}/status`：保留现有采用状态更新协议与乐观锁。

创建接口本期服务于本地导入，不新增面向普通用户的策略编辑器。后续书籍解析流程可以调用同一 Service，而不是直接操作 Repository。

### 6.2 数据流

```text
PDF 阅读与人工复核
  → 结构化策略定义
  → StrategyPlaybookService.create
  → strategy_playbook + strategy_playbook_rule（同一事务）
  → GET /api/strategy/playbooks
  → 策略库卡片
  → GET /api/strategy/playbooks/{code}
  → 四部分策略详情
```

模型或解析器只能生成候选内容。真正入库前必须保留作者、来源、页码、验证状态和不确定项，不得把推断伪装成作者原话。

## 7. 错误处理

- 缺少 `code/title/summary/source_title` 或没有任何规则时返回参数错误；
- `code` 重复时返回业务冲突，不覆盖已有策略；
- 策略写入成功但规则写入失败时整体回滚；
- 详情请求找不到策略时返回资源不存在；
- 未知验证状态、采用状态或规则性质在服务边界拒绝；
- 前端详情加载失败时保留卡片列表，并提示详情暂不可用；
- 本地来源文件不存在时仍可展示已入库策略，但显示“原始文件当前不可访问”。

## 8. 测试与验收

### 8.1 后端

- 数据库初始化测试覆盖新增字段、规则表、外键和索引；
- Repository 测试覆盖策略与有序规则读写；
- Service 测试证明列表完全来自数据库，且代码中不存在策略目录常量；
- 创建服务测试覆盖事务回滚、重复编码和字段校验；
- 状态更新测试继续覆盖乐观锁；
- Controller 测试覆盖列表、详情、创建和错误信封。

### 8.2 前端

- 策略库能显示数据库返回的“中长线质量趋势策略”；
- 卡片展示作者来源和“尚未验证”提示；
- 点击详情后按数据库顺序展示四个部分；
- 详情中能区分作者原则、候选规则和未明确参数；
- 开始使用只改变采用状态，不改变验证状态；
- API 失败、空规则和长文本均有稳定展示。

### 8.3 验收场景

1. 启动项目并进入“策略 → 长期投资工作台 → 策略库”。
2. 页面显示“中长线质量趋势策略”，状态为“研究中”，验证提示为“尚未验证”。
3. 打开详情，可以看到基本面、趋势、量价和风险四部分及来源页码。
4. 数据库新增另一条合法策略后，刷新页面即可显示，无需修改或重新编译策略目录代码。
5. 点击“开始使用”后状态变为“使用中”，来源与验证状态保持不变。

## 9. 非目标

- 本期不自动解析任意 PDF 并无人审核入库；
- 不将作者策略直接接入实盘交易或自动下单；
- 不声称书中策略已经有效；
- 不在本期实现周线指标、平台突破检测或完整回测；
- 不重构量化平台或知识工作台，只保留未来关联边界。
