# 顶栏轻量控制台设计

## 目标

将顶栏右侧由一组外观相同的浅灰按钮重构为具有明确层级的研究终端控制区，在深浅主题下都保持清晰、克制并具科技感。

## 设计

- Articles 与 Topics 组成一个共享外框的数据舱，标签弱化、数字突出，并使用等宽数字字体。
- 主题与刷新保持独立按钮：主题为紧凑方形图标按钮，刷新使用图标加文字，避免与统计信息混淆。
- 状态信息成为独立状态轨道，使用绿色脉冲指示、上方微型状态标签和单行省略，表达“系统回执”而非普通按钮。
- 深色模式采用深蓝黑半透明材质、青绿色细描边与局部辉光；浅色模式使用相同结构的低对比表面。
- 窄屏时允许控制区换行，状态轨道占满可用宽度；保留键盘焦点与减少动态效果设置。

## 边界

不修改顶栏数据来源、刷新逻辑、主题切换逻辑或消息文案，只调整语义结构、可访问标签和视觉表现。

## 验证

- 组件测试验证数据舱、控制按钮和状态轨道的语义结构。
- 运行前端完整测试和生产构建。
