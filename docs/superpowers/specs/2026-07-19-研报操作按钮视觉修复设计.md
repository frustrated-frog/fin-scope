# 研报操作按钮视觉修复设计

## 目标

修复研报分析页操作按钮退化为浏览器默认白底样式的问题，建立清晰的操作层级，并与财报工作台现有深色视觉系统保持一致。本次只调整展示与交互反馈，不改变自动同步、导入、阅读和重新解析的数据流。

## 操作层级

1. `同步最新研报` 是同步区唯一主操作，使用蓝色渐变、40px 高度和轻微高光；同步中显示禁用态与旋转指示。
2. `导入并详细解读` 是候选卡片主操作，使用紧凑的蓝绿色实心样式，强调会产生下载与解析动作。
3. `阅读详细解读` 是已导入卡片的次级操作，使用低强调蓝色描边样式。
4. `重新详细解析` 是工具性操作，使用深色次级样式，并与当前研报选择器保持相同高度。

## 组件边界

`ResearchReportAnalysisPanel.tsx` 只为按钮增加语义化 class、状态标记和装饰性图标节点；`styles.css` 负责所有视觉规则。继续使用原生 button，保留键盘、禁用与辅助技术语义，不增加图标库或新依赖。

## 视觉规则

- 所有按钮统一为 40px 高度、10px 圆角、13px 字号和明确字重。
- 主操作采用主题蓝色渐变；导入操作采用主题青绿色；阅读和重新解析采用深色表面加主题描边。
- hover 只做 1px 上浮、边框和阴影变化；active 回到原位；focus-visible 使用可见焦点环。
- disabled 降低透明度、移除位移与阴影，不使用原生灰白外观。
- 文本和图标均不换行，候选卡片按钮保持紧凑，不挤压标题主体。
- 窄屏下卡片改为纵向布局，操作按钮占满可用宽度。
- `prefers-reduced-motion` 下关闭位移动画和同步旋转动画。

## 验收

- 四类按钮均不再出现浏览器默认白底样式。
- 主次操作层级一眼可辨，加载、禁用、悬停和键盘焦点状态完整。
- 同步、导入、阅读、重新解析原有行为及测试保持通过。
- 财报研报目标测试、前端全量测试与生产构建通过。
