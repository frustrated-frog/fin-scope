# 研究报告证据锚点显示修复设计

## 问题

确定性研究报告在每条证据标题前写入 `<a id="evidence-e1"></a>`。`react-markdown` 默认不解析原始 HTML，因此该标签以普通文本显示。与此同时，报告阅读器已经根据 `### E1 · ...` 标题生成 `id="evidence-e1"`，原始 HTML 锚点是重复实现。

## 设计

采用双层兼容修复：

1. 后端报告生成器不再输出原始 HTML 锚点，只保留 `### E1 · ...` 标题和指向 `#evidence-e1` 的引用。
2. 前端在渲染前仅移除格式严格匹配 `<a id="evidence-e数字"></a>` 的历史锚点，使已保存的旧报告无需重新生成即可恢复正常显示。
3. 继续由现有 `h3` 渲染器为证据标题设置稳定 ID，保证 `[E1]` 链接仍可跳转。

不启用 `rehype-raw`，避免为一个内部锚点扩大任意 HTML 的渲染和安全边界；不执行数据库迁移，保留历史报告原文。

## 验收标准

- 新生成报告不包含 `<a id="evidence-e1"></a>`。
- 旧报告中的该标签不出现在页面文本中。
- `E1` 证据标题仍具有 `id="evidence-e1"`。
- 报告中的 `[E1](#evidence-e1)` 链接保持有效。

## 测试

- 后端生成器回归测试验证 Markdown 不再包含原始 HTML 锚点。
- 前端阅读器测试使用包含旧锚点的报告，验证标签不可见、引用链接和标题 ID 正确。
