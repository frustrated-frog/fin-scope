# Dashboard 研究指挥台设计

## 目标

将首页从系统库存概览升级为个人投研的每日入口。用户进入页面后应在一屏内判断：今天出现了什么值得研究的变化、哪些任务需要处理、已有判断是否需要复习，以及各工作区是否正常运行。

## 页面职责

受众是维护个人研究工作流的投资者。Dashboard 的单一职责是排序和分发工作，而不是复制文章、知识、研究或内容模块的完整功能。每个区块只显示最近且可行动的信息，并提供进入原工作区的入口。

## 信息架构

1. `今日研究脉冲`：展示新内容、待处理线索、到期复习、进行中运行四个实时计数，以及最近一次抓取与来源健康状态。
2. `优先处理`：展示最高重要度事件、未完成学习任务和进行中研究运行；每一项可进入对应工作区。
3. `工作区概览`：研究流、知识与判断、投资观察、内容沉淀四个紧凑区块，分别用真实的事件、主题、研究命题和选题数据说明状态。
4. `运行账本`：保留最近抓取记录，但压缩为状态、有效新增、重复内容和来源名称，方便检查系统健康。

## 数据边界

不新增后端接口。Dashboard 复用 `App` 已加载的 `sources`、`articles`、`briefs`、`events`、`evidenceItems`、知识概览、学习任务、内容选题、研究运行、研究命题、Agent 运行和抓取批次。`App` 将完整知识概览保留在状态中，而不只保留活跃主题数。

## 视觉方向

Dashboard 采用“研究指挥台”而非营销首页的形态：

- 画布：沿用现有深色工作台与低反差面板。
- 信号色：墨青 `#0f1b22`、面板 `#17262e`、信息青绿 `#5ad1b5`、注意琥珀 `#d7a843`、风险珊瑚 `#de6b5a`、正文 `#e3ecec`。
- 字体：标题使用现有宋体衬线栈；正文使用系统中文字体；数字、状态与时间使用等宽字体。
- 标志元素：研究脉冲带以四段真实工作流状态构成，段长和状态色来自当前数据，不使用纯装饰图形。

## 交互与适配

每个行动项和工作区区块使用明确的“打开研究流”“继续学习”“查看运行”等命令进入既有导航。窄屏按今日优先级、工作区概览、运行账本的顺序单列显示。悬停仅提供轻量边框与层级反馈，遵守减少动态效果设置。

## 验收

- 首页能展示研究流、知识与判断、投资观察、内容沉淀和运行健康五类信息。
- 信息来自现有真实数据，不加入静态占位业务数据。
- 用户能从每个主要区块进入对应既有工作区。
- 当数据为空或某类接口未成功加载时，页面提供明确的空状态。
- 新增前端测试覆盖 Dashboard 的新信息与导航；完整前端测试和生产构建通过。
