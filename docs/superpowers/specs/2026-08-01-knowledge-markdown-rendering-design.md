# 知识判断 Markdown 阅读渲染设计

## 目标

知识工作台的结论由用户或模型以 Markdown 保存。当前界面将其作为纯文本展示，导致 `##` 等格式符直接出现在“当前判断”“我的回答”和“当前结论 / 下一次复习”中。本次改动将受控 Markdown 转换为适合复习的阅读层级，不改变存储格式或编辑能力。

## 方案

新增前端只读渲染组件，输入为 `contentMarkdown` 字符串，输出受限的 React 节点：

- ATX 标题（`#` 至 `######`）映射为语义标题，标题层级受展示容器限制。
- 连续普通行组合为段落；空行分隔内容块。
- 有序和无序列表映射为原生列表。
- 不支持的 Markdown 语法去除格式符后按纯文本展示；任何内容均不使用 HTML 注入。

组件会用于主题工作台的当前判断、知识脉络中的学习回答与当前结论，以及复习模式中的原结论。学习编辑器保持 textarea 形式，继续让用户直接输入 Markdown。

## 视觉与交互

内容采用紧凑的研究笔记排版：标题与正文以稳定间距分隔，列表用于承载验证项和失效条件。时间线内的标题尺寸较小，避免压过节点标签；当前判断使用更完整的层级。纯文本内容保持与当前页面相同的阅读密度。

## 验收与测试

- 含 `##` 的结论不再在页面可见。
- 标题、段落和列表分别以对应语义元素呈现。
- 相同结论在当前判断、时间线和复习比较区表现一致。
- 纯文本回归保持原样。
- 添加组件级测试，并运行相关主题工作台测试与完整前端测试、生产构建。
