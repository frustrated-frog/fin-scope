# 移除雷达“最新变化”冗余数据设计

## 背景

研究雷达页面顶部的“最新变化”与实时资讯承担的即时信息职责重叠。雷达应聚焦值得进一步研究的事件列表、筛选和详情操作。

## 决策

从研究雷达接口及其 Redis 页面快照中移除 `latestChanges` 字段；同时移除雷达页顶部的“最新变化”区块。

雷达页下部的高优先级事件继续使用 `events`。事件详情、筛选、搜索、阅读/关注状态和研究跳转均保持不变。

## 边界与兼容性

- 后端 `ResearchRadarView` 不再构造或序列化 `latestChanges`。
- 前端 `ResearchRadarSnapshot` 不再声明该字段，并移除仅服务该字段的回退和同步代码。
- 知识库首页的每日市场变化仍从 `events` 投影，不依赖 `latestChanges`。
- 这是一个本地 API 的有意收敛；任何独立客户端如直接消费该字段，需要改为读取 `events`。

## 验证

- 更新雷达页面测试，断言不再显示“最新变化”，且高优先级事件仍可显示和打开详情。
- 更新服务端视图与控制器测试，确保响应不包含 `latestChanges`。
- 运行相关前端测试、后端服务与 Web 测试，以及前端生产构建。
