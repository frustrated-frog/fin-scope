# 单标的二十日收益预测设计

## 目标

在策略工作台中增加面向单只自选股的正式量化研究入口。系统基于服务端持久行情缓存和严格的时间序列验证，预测从 T+1 开盘买入到第 20 个交易日收盘退出后的净收益是否为正，并输出上涨概率、预期收益区间、样本外证据和可执行性边界。

本功能不做全市场选股，不承诺确定性涨跌，也不使用 LLM 直接生成数值预测。没有样本外增量价值时必须明确给出“未发现可靠预测能力”。

## 范围

- 单只 A 股，股票代码由用户输入或从自选股选择。
- 日线级预测，固定 20 个交易日预测周期。
- 尽量读取上市以来历史，首版上限 5,000 根日线。
- 使用前复权 OHLCV/成交额生成特征，按 T 日收盘信号、T+1 开盘执行。
- 使用佣金、印花税和滑点计算预测标签与模拟收益。
- 使用简单、可解释的小型统计模型，并用扩展窗口滚动验证。
- 页面展示当前预测、收益区间、历史校准、基准比较、数据质量和近期样本外记录。

## 非目标

- 全市场横截面选股、自动下单、分钟级或日内交易。
- 自动搜索最优参数或同时尝试大量模型。
- 将预测包装成确定性投资建议。
- 首版接入基本面、新闻情绪或行业指数映射。

## 数据架构

Python market-data-service 继续拥有外部行情接入和持久缓存。日线请求上限提升到 5,000 根；缓存命中除了检查交易日新鲜度，还必须检查已缓存记录数能否满足本次请求，避免 120/250 根快照错误满足量化的长历史请求。

Java 侧通过 `QuantDailyBarSource` 读取相同服务端缓存，不直接打开 Python SQLite。量化预测服务对返回数据执行代码、复权方式、OHLCV、截止日和最小样本量校验，并依据排序后的完整行生成 SHA-256 数据指纹。每次预测结果携带指纹、来源、截止交易日和样本数，确保结果可解释和可复查。

考虑到首版只有单标的、最多 5,000 行，暂不引入列式存储。Python 侧继续使用 SQLite 快照，Java 侧在单次请求内计算；当未来需要跨会话预测档案时，再将结果写入专用运行表，不能复用全市场实验表伪装单标的语义。

## 标签与成本

对每个可用信号日 T：

```text
grossReturn = close(T+20) / open(T+1) - 1
netReturn   = grossReturn - buyCommission - sellCommission - stampDuty - slippage
label       = netReturn > 0
```

默认成本沿用现有量化研究约束：双边佣金、卖出印花税和滑点。首版使用前复权价格近似执行收益，因此结果必须显示“复权日线模拟，不代表真实成交回放”的限制；后续若引入原始价格和复权因子，可替换执行收益计算而不改变预测接口。

## 特征

首版只使用 T 日收盘时已知的数据：

- 5 日收益、20 日收益、60 日收益。
- 收盘价相对 MA20、MA60 的距离。
- 20 日实现波动率。
- 20 日成交额相对过去 60 日均值。

所有特征只使用当前及过去数据。模型训练阶段的标准化均值和方差只能来自当次训练窗口，不能用全样本统计量。

## 模型与滚动验证

使用带 L2 正则的逻辑回归输出上涨概率。模型保持固定特征、固定正则和固定迭代规则，不提供“自动调参”。

验证采用扩展窗口：前 60% 的可标注样本作为首次训练集，之后按时间顺序预测；每 20 个交易日使用当时已成熟的标签重新训练。指标使用非重叠的 20 日锚点计算，避免重叠标签夸大有效样本量。

验证输出：

- 样本外预测数和非重叠评估数。
- 准确率、Brier Score、基准 Brier Score。
- 基准上涨率与模型概率校准。
- 高置信预测的命中率。
- 最近样本外预测记录。

当前预期收益和区间使用历史样本外预测中与当前概率相近的结果分布估算；样本不足时回退到全部样本外结果并降低置信度。

## 结论门禁

- 少于 750 根日线：`INSUFFICIENT_DATA`，只说明数据不足，不生成正式概率。
- 750–1,499 根：允许计算但标记低置信度。
- 至少 1,500 根且样本外 Brier Score 优于无条件上涨率基准：可评为 `CONDITIONAL_EDGE`。
- 同时满足概率校准、准确率和高置信样本要求：可评为 `EVIDENCE_SUPPORTED`。
- 未超过基准：`NO_OBSERVED_EDGE`。

任何状态都必须返回原因、局限和数据质量警告。

## 前端体验

策略工作台增加“单股预测”页签并作为量化模式的第一入口。页面采用研究终端而非表单后台的视觉语言：

- 顶部输入股票代码并运行研究。
- 主视觉突出 20 日上涨概率、预期净收益和证据等级。
- 收益区间使用横向分布带，不用夸张仪表盘。
- 样本外证据区展示模型与基准的 Brier、准确率、样本量。
- 最近预测记录用紧凑表格展示信号日、概率、实际净收益和是否命中。
- 数据不足或无优势时保持中性配色，不用绿色误导用户。
- 明确显示数据截止日、指纹、来源和“不是投资建议”。

## 错误处理

- 行情服务不可用：返回统一业务错误，页面保留上次结果并显示失败提示。
- 数据少于门槛：返回结构化不足状态，而不是 HTTP 失败。
- 行情乱序、重复、OHLC 非法或缺少成交额：拒绝正式预测并列出质量问题。
- 模型数值不收敛：返回 `MODEL_UNAVAILABLE`，不回退成伪概率。

## 测试与验收

- Python：长历史请求、缓存覆盖不足自动补齐、缓存满足覆盖时不重复调用。
- Java：特征无未来泄漏、T+1/T+20 标签、滚动训练边界、概率范围、基准比较、数据不足和确定性结果。
- Web：Controller 契约和错误映射。
- React：运行入口、加载/失败/不足/有证据/无优势状态、结果可访问性。
- 全量执行 Python tests、相关 Maven 模块测试、前端 Vitest 和生产构建。
