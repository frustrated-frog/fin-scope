# 产业链新建输入框焦点态修正

## 问题

产业链目录的新建输入框聚焦时，同时命中了全局 `input:focus`、全局 `:focus-visible` 和组件容器的 `:focus-within`，形成多层绿色描边、阴影与位移。禁用状态的加号按钮面积和对比度也偏高，抢占了输入任务的视觉重心。

## 设计

- 由 `.ic-create` 容器统一表达焦点状态，只保留一层细青灰描边和极弱外光。
- 在组件作用域内显式清除输入框聚焦时继承的全局边框、轮廓、阴影、背景和位移。
- 输入框默认背景保持透明，placeholder 使用低对比中性色。
- 加号按钮缩小视觉重量：禁用时透明、无大色块；可用时使用克制的青色描边与轻微底色。
- 键盘焦点依然清晰可辨；减少动态偏好下不执行过渡动画。

## 验收标准

1. 聚焦输入框时只出现容器的一层焦点反馈。
2. 输入框本身不再出现绿色内框、外框、阴影或向上位移。
3. 禁用加号不抢占视觉重心，可用状态仍可明确识别。
4. 产业链目录现有创建行为、键盘操作与响应式布局保持不变。

## 测试

- 样式回归测试验证组件作用域中存在完整的聚焦重置规则。
- 运行产业链组件测试与前端生产构建。
- 在真实浏览器中聚焦输入框并截图检查。
