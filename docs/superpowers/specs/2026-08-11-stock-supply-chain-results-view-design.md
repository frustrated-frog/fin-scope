# 股票产业链结论页设计

## 目标

股票产业链页只承担“快速读懂公司在产业链中的位置与关系”的任务。页面不展示证据编号、来源链接、来源摘录或证据索引，但后端仍保留证据数据并继续用它约束结论生成。

## 信息结构

1. 顶部工具栏使用“产业链结论”语义，提供“更新产业链”操作。
2. 结论摘要展示产业位置、核心总结和快照更新时间。
3. 主体按“上游供给—公司位置—下游需求”三层展示关系节点。
4. 节点保留关系类型、说明和可信度，可信度是结论质量提示，不提供证据跳转。
5. 原“证据边界”改为“结论边界”，说明匿名客户、未披露供应商等不能下确定结论的部分。

## 状态文案

- 首次生成：正在建立产业链结论。
- 手动更新：正在更新产业链结论，旧快照继续可读。
- 失败：展示具体失败原因和“重新生成”。
- 空状态：说明系统只呈现有公开信息支持的关系，但不展示底层证据。

## 数据与兼容性

仅调整 React 展示组件、样式和组件测试。API、后端生成流程、SQLite 快照结构与证据字段保持不变，避免削弱生成准确性或破坏已有数据兼容性。

## 验收标准

- 页面中不存在“证据索引”、E1/E2 引用、来源链接和摘录。
- 页面可读地展示定位、总结、三层节点、可信度、更新时间和结论边界。
- 更新、轮询、失败重试和移动端布局保持可用。
