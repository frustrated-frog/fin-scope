# 产业链目录折叠与新建控件设计

## 目标

让产业链目录可在完整浏览与沉浸式看图之间切换，并消除新建产业链输入区域的嵌套边框感。

## 交互设计

- 桌面端目录标题右侧提供“收起目录”按钮；收起后目录缩成窄轨道，只保留 `IC` 标识和“展开目录”按钮。
- 折叠状态只保存在当前组件会话中，不写入数据库或本地存储。
- 折叠时主画布自动占用释放出的宽度，布局变化使用短促、克制的过渡动画。
- 760px 以下保持现有移动端完整目录，不提供折叠，避免窄屏产生不可用的纵向窄轨道。
- 新建产业链采用单层表单：外层是唯一边框，输入框无自身边框；右侧提交区用垂直分隔线划分，按钮不再绘制第二层卡片。

## 可访问性

- 折叠按钮使用明确的 `aria-label`、`aria-expanded` 和 `aria-controls`。
- 折叠后目录本体仍保留 `产业链目录` landmark，展开按钮可通过键盘聚焦。
- 保留减少动画和高对比度媒体查询支持。

## 验收标准

- 用户可以收起和展开桌面端产业链目录，操作后主内容宽度同步变化。
- 收起时目录列表和新建表单不参与布局或键盘导航。
- 新建产业链输入区视觉上只有一层边框，原提交逻辑与禁用状态保持不变。
- 产业链前端测试与生产构建通过，并用真实浏览器验证展开态、收起态和输入聚焦态。
