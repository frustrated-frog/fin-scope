# 产业链语义图谱深化设计

## 背景与目标

产业链的行业结构属于低频变化的认知底座。FinScope 不把产业链继续扩展为知识库，也不把它改造成高频研究任务流，而是在现有图谱上增加足够完整的产业结构、技术路线、价值分配和公司生态，让图本身成为主要阅读与探索界面。

本期目标：

- 远看能够理解产业主干、环节顺序和价值流向。
- 展开环节能够看到材料、设备、部件、产品、技术和应用。
- 深入节点能够理解成本、价值获取、瓶颈、替代关系和公司位置。
- 内容增加后仍保持默认图谱简洁，不形成难以阅读的密集网络。
- 行业稳定结构与公司层内容分层展示，允许未来分别更新。

## 产品原则

1. 图谱是主界面，信息通过节点、关系、专题图层和检查器呈现。
2. 默认只展示稳定主干，用户深入时逐层展开。
3. 每种节点和关系都必须有明确语义，不使用装饰性连线。
4. 颜色、线宽和尺寸只编码可解释信息，不做无意义的大屏效果。
5. 当前研究面板中的内容拆回图谱，不新增章节式知识库。
6. 公司级明确供货关系仍以披露为准；推测关系不得表现为确定事实。

## 信息架构

### 第一层：产业主干

默认视图只显示：

- 产业链根节点。
- 按顺序排列的产业环节。
- 环节之间的主要价值流。

这一层回答行业边界、上下游顺序和核心价值流向。

### 第二层：生产解剖

展开产业环节后显示：

- 原材料。
- 生产设备。
- 核心部件和中间产品。
- 主要产品。
- 终端应用。
- 环节输入、输出和关键依赖。

这一层回答“该环节如何生产、依赖什么、产出什么”。

### 第三层：技术路线

从产品、部件或环节继续展开：

- 主流技术路线。
- 路线适用范围。
- 成本、性能与量产难点。
- 路线成熟度。
- 替代或竞争关系。
- 代表产品与公司。

这一层回答“行业为什么这样做、未来可能怎样演进”。

### 第四层：公司生态

公司节点作为最深层业务实体，展示：

- 所属环节与覆盖范围。
- 核心产品和采用的技术路线。
- 下游市场与客户行业。
- 竞争对手。
- 国产替代位置。
- 一体化程度。
- 关键观察变量。

公司层可独立于稳定产业骨架进行刷新。

## 数据模型

### 节点类型

保留：

- `INDUSTRY_CHAIN`
- `STAGE`
- `PRODUCT`
- `COMPANY`

新增：

- `MATERIAL`：原材料或关键耗材。
- `EQUIPMENT`：生产设备或工艺设备。
- `COMPONENT`：核心部件或中间组件。
- `TECHNOLOGY`：技术、工艺或技术路线。
- `APPLICATION`：终端应用或客户场景。

### 节点语义画像

在修订级研究内容中增加 `nodeProfiles`，通过 `nodeKey` 与任意非根节点关联。节点画像包含：

- `definition`：节点定义。
- `function`：在产业链中的作用。
- `inputs`、`outputs`：主要输入与输出。
- `costDrivers`：成本驱动。
- `valueDrivers`：价值获取来源。
- `barriers`：行业或技术壁垒。
- `coreMetrics`：跟踪指标。
- `risks`：主要风险。
- `maturity`：`EMERGING` / `SCALING` / `MATURE` / `DECLINING`。
- `valueLevel`：`HIGH` / `MEDIUM` / `LOW`。
- `bottleneckLevel`：`HIGH` / `MEDIUM` / `LOW`。
- `localizationLevel`：`LOW` / `MEDIUM` / `HIGH` / `LEADING`。

现有 `stageProfiles` 和 `companyProfiles` 保持兼容；前端优先使用专属画像，再回退到通用节点画像。

### 关系类型

保留现有包含、流向、生产和参与关系，新增：

- `DEPENDS_ON`：关键依赖。
- `ENABLES`：技术赋能。
- `USED_IN`：产品或技术应用于场景。
- `SUBSTITUTES`：替代关系。
- `COMPETES_WITH`：同类技术、产品或公司竞争。

关系增加可选语义：

- `strength`：`PRIMARY` / `SECONDARY`。
- `directionNote`：对流向或作用的简短解释。

现有 `nature`、`confidence` 和公司供货披露约束继续生效。

## 语义缩放与展开规则

### 默认层级

- 初始只渲染 `INDUSTRY_CHAIN`、`STAGE` 和阶段间主干关系。
- 画布缩放不直接改变数据；展开状态由用户动作控制，避免轻微缩放造成界面跳变。

### 展开动作

- 单击节点：选中并打开右侧检查器。
- 双击节点或点击检查器中的“展开”：显示该节点的直接子节点和一阶语义关系。
- 再次双击或点击“收起”：隐藏其展开分支。
- 每次展开最多显示 12 个直接子节点；超出时按类型分组并显示数量。
- “聚焦链路”只保留当前节点的一阶上下游、父节点与已展开子节点。

### 布局

- `STAGE` 继续沿水平方向构成稳定主轴。
- 材料、设备和技术位于对应环节上方。
- 部件、产品和应用位于对应环节下方或流向侧。
- 公司以紧凑铭牌聚合在关联业务节点外围。
- 展开和收起后保持已选节点的屏幕位置稳定，减少视觉迷失。

## 专题图层

顶部增加图层切换器，同一时刻只能启用一个主专题：

1. `STRUCTURE`：默认结构图，强调节点类型和价值流。
2. `VALUE`：按 `valueLevel` 强调价值量和利润池。
3. `BOTTLENECK`：按 `bottleneckLevel` 强调关键卡点。
4. `TECHNOLOGY`：突出技术节点、替代和赋能关系。
5. `LOCALIZATION`：按 `localizationLevel` 表示国产化阶段。
6. `COMPANY`：突出公司覆盖范围和竞争关系。

专题图层只改变视觉编码和默认关系过滤，不生成另一套图数据。

### 视觉编码

- 高价值节点：低饱和金色顶部刻度。
- 高瓶颈节点：琥珀边框和明确“瓶颈”标签。
- 技术路线：青蓝色细线；替代关系使用虚线分叉箭头。
- 公司竞争：低饱和紫灰虚线，只在公司专题中显示。
- 非当前专题节点降低对比度但不完全消失。
- 图例始终显示文字标签，颜色不是唯一载体。

## 右侧语义检查器

检查器根据节点类型切换内容，而不是显示统一大段描述。

### 环节节点

- 环节作用、主要输入和输出。
- 商业模式、成本结构和价值获取。
- 上下游议价权、瓶颈、壁垒和指标。
- 子节点类型统计和展开入口。

### 材料、设备、部件和产品节点

- 定义、用途和上下游依赖。
- 成本与价值驱动。
- 关键指标、风险和替代项。
- 相关技术、应用和公司。

### 技术节点

- 技术原理、适用范围和成熟度。
- 性能、成本与量产难点。
- 替代对象、赋能对象和代表公司。

### 公司节点

- 产业位置、覆盖环节和核心产品。
- 技术路线、下游市场和竞争优势。
- 竞争关系、国产替代位置和观察变量。

## 前端结构

现有“产业全景”升级为主要语义图谱视图：

- 顶部：搜索、专题图层、聚焦、展开层级和刷新。
- 中部：语义图谱画布。
- 右侧：可折叠语义检查器。
- 底部角落：图例和小型导航概览。

现有“研究面板”不再作为内容继续扩展。其状态带、瓶颈、价值驱动和环节画像逐步复用到专题图层与检查器；在兼容期保留入口，待新图谱能力完整后再决定是否移除。

## 生成、校验与兼容

1. `IndustryChainSynthesisAgent` 输出新增节点类型、关系类型与 `nodeProfiles`。
2. 输出继续使用单次结构化合成和一次修复机会。
3. 校验器检查节点画像引用、枚举、重复关系和关系两端类型。
4. V2 图谱按现有方式展示；缺少新画像时回退到节点描述和既有画像。
5. 新生成图谱 schema 升级为 `INDUSTRY_CHAIN_V3`。
6. 发布仍采用修订级原子替换，生成失败保留上一版。

## 响应式设计

- 桌面端：目录、画布、检查器三栏；检查器宽度 320–380px。
- 平板端：目录收窄，检查器覆盖在画布右侧。
- 手机端：画布保留最小可操作高度；检查器使用底部抽屉；默认仅展示产业主干。
- 所有展开、聚焦和图层按钮支持键盘操作与清晰焦点态。
- 遵循 `prefers-reduced-motion`，展开仅使用短距离透明度和位置过渡。

## 测试与验收

### 后端

- 新节点、关系与画像解析。
- 非法枚举、悬空引用和重复关系拒绝。
- V2 兼容读取与 V3 往返持久化。
- 未披露公司供货关系继续被过滤。

### 前端

- 默认只显示主干节点。
- 展开、收起和聚焦规则。
- 六个专题图层的过滤与视觉状态。
- 不同节点类型的检查器内容。
- 旧图谱回退与空画像。
- 桌面、平板和手机布局。

### 成功标准

- 默认画布在常见行业中不超过 8 个可见主干节点。
- 单次展开不超过 12 个直接子节点。
- 用户可在三次交互内从产业主干定位到具体公司。
- 切换专题不改变图谱拓扑位置。
- 1440px 桌面宽度下，主轴、展开分支和检查器同时可读。

## 非目标

- 不建设行业知识库、文章章节或文档目录。
- 不引入高频行情、新闻流或自动定时刷新。
- 不复用完整 Research Agent 循环。
- 不绘制未经披露的确定性公司供货关系。
- 不在本期实现跨产业链合并图、时间轴回放或用户手工编辑图谱。
