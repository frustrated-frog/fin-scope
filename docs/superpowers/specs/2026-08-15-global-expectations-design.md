# 全球预期监控设计

## 目标

在 FinScope 中建立一个独立的只读“Global Expectations”一级页面，持续观察少量与 A 股研究有关的海外预测市场预期变化。它输出待核验的研究线索，不生成股票评分、交易建议或下单能力。

## 产品边界

- 页面位于侧栏“知识与判断”，不属于 Research、Market Intel 或 Watchlist。
- 首期数据来自 Polymarket 的公开 Gamma、Data 与 CLOB 市场数据接口；不使用钱包、私有 API、交易接口或 WebSocket。
- 监控市场由本机配置的关键词池发现，并以主题分组：中美关系、科技供应链、能源资源、全球宏观、中国相关、全球地缘。关键词按完整单词或短语匹配，避免子串误命中。
- 定时任务拉取并持久化概率、成交量、未平仓量和买卖价差；异动是概率变化与市场质量共同满足的结果。
- Dashboard 与 Daily Brief 只显示摘要；用户可将确认值得回看的异动记入 Timeline。首期不自动关联研究主题、产业图谱或自选股。

## 页面设计

页面的单一工作是让用户判断“哪些海外问题正在被重新定价，是否需要进一步核验”。视觉使用深靛蓝的预测带、冷青的上行轨迹与暖珊瑚的下行轨迹；关键元素是横向概率带，直接显示 YES 的位置而不把它误包装成股票涨跌。

```text
Global Expectations
  监控覆盖 / 最近刷新 / 当前异动数
  [主题过滤] [只看异动] [刷新]
  ┌ 预期异动 ─────────────────────────────────────────────┐
  │ 62¢  +9.4pp  问题 / 到期日 / 流动性 / 观察方向         │
  │ ━━━━━━━━━●━━━━━━━━━━━━ YES 概率带                       │
  └───────────────────────────────────────────────────────┘
  观察清单：按五个主题分组的市场卡片
```

每张卡片展示问题、当前 YES 概率、1h/24h/7d 变化、成交量、OI、价差、到期日、观察方向与原市场链接。没有足够快照时明确显示“等待建立基线”。

## 架构与数据流

`PolymarketPublicClient (rpc) -> GlobalExpectationRefreshService (service) -> SQLite repositories (dao) -> GlobalExpectationsController (web) -> GlobalExpectationsView (frontend)`。

领域模型保存市场身份与用户本地的主题/观察方向，快照以市场 ID 和观察时间构成唯一业务键。刷新失败时保留最后成功快照并在页面返回降级状态，不阻断页面读取。异动计算只读取本地快照，以避免展示请求直接依赖外部市场。

## 交互与关联

- Dashboard 展示最多三条异动摘要并跳转至 Global Expectations。
- 每日简报由服务端附加最多三条已触发异动的“海外预期温度计”。
- 用户点“记入大事记”时，创建 `PREDICTION_SIGNAL` 来源的大事记，保留问题、概率和变化描述；这是唯一的跨页写关联。

## 验收

- 无外部凭据时能够获取公开市场并持久化快照；下游失败时读取旧数据并标明状态。
- 具有足够流动性且 24 小时概率变化超过阈值的市场标记为异动，反之不标记。
- 新页面在窄屏可读、可按主题/异动过滤、可打开原市场并可归档到 Timeline。
- 现有 Dashboard、Brief、Timeline 行为不回归。
