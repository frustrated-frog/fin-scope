# 全球预期详情弹窗溢出修复设计

## 问题

详情图表最多渲染 96 根柱子。每根柱子当前具有 `4px` 最小宽度，柱间距为 `5px`，导致图表产生约 860px 的最小内容宽度。弹窗是 540px 的单列 CSS Grid，子项的自动最小宽度将网格轨道撑宽，使指标栏、图表和关闭按钮越过弹窗边界。

## 方案

保持全部历史点，不增加横向滚动，也不减少数据。弹窗网格轨道使用 `minmax(0, 1fr)`，弹窗内容与图表允许收缩；柱子使用零基准弹性宽度并取消固定最小宽度。弹窗采用 border-box 宽度、视口最大高度和内部纵向滚动，保证桌面与窄屏都不越界。

## 验证

增加 CSS 契约测试锁定网格收缩、图表收缩和弹窗视口约束。真实页面分别在桌面和窄屏读取弹窗及子项边界，要求所有内容落在弹窗内，且弹窗无水平溢出。
