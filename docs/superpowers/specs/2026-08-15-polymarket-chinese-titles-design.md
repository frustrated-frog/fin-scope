# Polymarket 中文标题设计

## 目标

全球预期页面直接展示 Polymarket 官方中文市场标题，不引入额外翻译服务。

## 方案

在现有 Gamma 市场列表请求中追加 `locale=zh`。Gamma 返回的 `question` 继续沿用当前解析和 Redis 快照流程；市场 ID、英文 slug、概率、成交量与原市场链接保持不变。主题目录匹配同时读取中文标题和包含英文 slug 的市场 URL，避免中文标题破坏现有英文关键词观察范围。

不使用 `zh-CN`，因为 Gamma 会将其判定为不支持的 locale。也不调用现有 LLM，避免翻译延迟、调用成本和新增缓存一致性问题。

## 失败与缓存行为

语言参数不改变现有异常处理。Gamma 调用失败时继续使用已有 Redis 快照；下一次成功刷新会用官方中文标题覆盖旧英文快照。

## 验证

RPC 客户端测试应断言两个分页请求均包含 `locale=zh`，并继续验证分页、排序和响应解析行为。服务测试应验证中文标题能够通过英文 slug 进入原有主题，并且最终展示字段保持中文。
