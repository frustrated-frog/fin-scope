# 单股预测与股票发现量化可视化设计

## 目标

不增加新 Tab，不改变预测、资格门禁和排名算法，在现有“单股预测”和“股票发现”页面中把已有量化证据转化为可比较、可追溯的视觉表达。

## 设计原则

- 图形只投影后端已经冻结的数据，不在浏览器中重新计算模型结论或排名。
- 每张图必须回答一个研究问题，并保留文字、数值和无障碍标签，不能只靠颜色传达结论。
- 正收益使用青绿色，负收益和回撤使用氧化红，基准使用琥珀色；延续现有研究账本的字体和纸面结构。
- 图形在移动端允许横向滚动或降为单列，不压缩到无法阅读。
- 空数据必须展示明确说明，不能绘制伪造的零值图形。

## 单股预测

### 因子贡献坐标轴

按贡献绝对值排序，使用以零点为中心的正负横向条形图。每行同时展示因子名称、方向、贡献值和历史分位。图形只解释模型在本次预测中如何使用因子，不声称因果关系。

### 收益与水下回撤联动

收益区域继续展示策略与“同股买入并持有”，下方增加共享时间轴的水下回撤面积。最大回撤起点、谷底和恢复日期以摘要标注。鼠标悬停不是读取数据的唯一方式，SVG 的无障碍说明包含累计收益和最大回撤。

### 参数稳定性面板

将预声明的相邻参数场景投影为“持有期 × 阈值”单元格。颜色表达相对买入持有的超额收益，主方案带轮廓和文字标识；因为首版参数面是稀疏的，不对缺失组合做插值，也不把最佳点包装成推荐参数。

## 股票发现

### 筛选漏斗

复用现有五阶段计数，增加相对上一阶段的保留率和按数量缩放的视觉轨道。阶段为板块成分、资金与质量门禁、轻量量化、深度预测和最终入选。计数为零时保留阶段，不隐藏失败位置。

### 风险收益分布

使用本批全部深度候选，而不只展示最终前五。横轴为最大回撤绝对值，纵轴为风险调整收益，气泡大小表示校准上涨概率；最终入选候选高亮并显示名称，其余候选保持低对比度。图形用于解释为什么高概率但高回撤的股票未必排名靠前。

### 前五候选因子矩阵

从候选轻量因子中选取相对动量、60 日动量、趋势一致性、流动性、波动率和60日回撤六项。各列在当前前五内部做稳健的相对归一化，风险因子反向着色。单元格同时保留原始值和“强/中/弱”标签，避免把相对颜色误读为绝对好坏。

## 数据与边界

本期不新增 Python 或 Java 字段：单股使用 `factorExplanations`、`equityCurve`、`performance` 和 `parameterStability.scenarios`；发现使用 `funnel`、`deep_evidence`、`final_candidates` 与 `candidates[].factors`。浏览器只执行坐标投影、抽样和当前批次内的展示归一化。

## 测试与验收

- 组件测试覆盖正常数据、稀疏参数、空数据、负贡献、零候选和非前五深度候选。
- 页面测试确认六张图嵌入现有两个页面，且没有新增手动刷新或运行按钮。
- 生产构建、前端全量测试和真实浏览器宽屏/移动端截图均通过后提交。
