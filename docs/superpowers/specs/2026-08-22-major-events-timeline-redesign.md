# 大事记时间轴改版设计

## 目标

把“大事记”从普通文章列表改造成面向个人投资研究者的时间档案：用户应能快速判断记录覆盖范围、沿日期扫读事件、区分来源，并重新打开原始材料。

本次只调整前端呈现与交互，不修改 `/api/major-events` 契约、记录逻辑或数据模型。

## 设计方向

推荐“研究刻度轨”，不采用卡片瀑布流或报纸分栏：大事记的核心信息是发生顺序，连续时间轴比独立卡片更能表达事件之间的先后关系。

- 色彩：沿用 FinScope 的墨绿与纸白基底，以琥珀色 `#d58a2d` 标记发生日期，以深墨色 `#13201c` 承载档案封面。
- 字体：标题使用项目现有的系统无衬线字体；日期与来源使用等宽字体，形成研究台账感，不引入新字体依赖。
- 布局：顶部是“市场记忆”档案封面，展示记录总量、覆盖月份和最近记录；下方是来源分段筛选与按月分组的单列时间轴。
- 标志元素：一条贯穿月份和事件的“研究刻度轨”，日期节点使用实心琥珀圆点，表达真实发生顺序而非装饰编号。
- 动效：仅在事件悬停时轻微抬升，并支持 `prefers-reduced-motion`；不做滚动触发或环境动画。

## 信息结构

```text
┌──────────────── 市场记忆 / 大事记 ────────────────┐
│ 用发生日保存关键变化       记录数 / 覆盖月份 / 最近记录 │
└─────────────────────────────────────────────────┘
  [全部] [实时资讯] [文章研究] [研究雷达]

  2026 年 08 月 ─────────────────────────── 3 件
        22 AUG  ●  来源 / 分类
                  事件标题
                  摘要
                  当时判断
                  打开原始来源 ↗
```

## 行为与状态

- 首次进入显示加载状态，避免请求完成前闪现“空档案”。
- 数据按 `occurredDate` 倒序展示，确保最近事件优先；同日保持接口返回顺序。
- 来源筛选使用可见的分段按钮，按钮显示当前结果数量；点击后继续使用现有 `originType` 查询参数。
- 无记录时区分“档案尚空”和“当前来源无记录”，并给出下一步提示。
- 原始来源在新窗口打开，保留现有安全属性。

## 响应式与无障碍

- 桌面端封面为标题与三项统计双栏布局；窄屏改为纵向，统计保持三列。
- 时间轴在手机端缩短日期栏和间距，不隐藏来源、标题或判断。
- 筛选使用原生 `button`、`aria-pressed` 和可见焦点；时间使用 `dateTime`。
- 深色模式完全依赖现有主题变量和 `color-mix`，避免维护另一套硬编码主题。

## 验收

- 自动化测试覆盖加载后的摘要、月份分组、倒序、来源筛选请求和筛选空状态。
- `npm test` 与 `npm run build` 通过。
- 在桌面和移动宽度分别截图检查，确认无横向溢出、文字遮挡或主题对比度问题。
