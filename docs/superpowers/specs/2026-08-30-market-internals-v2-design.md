# 市场结构驾驶舱一期设计

## 目标

把“市场宽度”从单日涨跌家数扩展为可连续观察的市场内部结构驾驶舱，回答五个问题：当天涨跌分布是否极端、多少股票处于中长期趋势之上、创新高与创新低哪一侧占优、参与度是在扩散还是收缩、这些结构相较上一交易日发生了什么变化。

本期不恢复指数行情卡片，不生成个股候选，也不替代股票发现页面。Market Pulse 负责市场和行业层判断，个股筛选继续从既有股票发现入口承接。

## 用户体验

### 市场宽度

保留现有涨跌家数、成交额、涨跌停和中位数，并新增：

- 七档涨跌幅分布：`≤-7%`、`-7%~-3%`、`-3%~0`、`0`、`0~3%`、`3%~7%`、`≥7%`。
- MA20、MA60、MA120、MA250 趋势宽度，展示收盘价位于对应均线之上的股票比例和有效样本数。
- 20 日、60 日、250 日新高/新低家数。
- 当日净上涨家数和 60 日滚动 A-D Line，观察市场参与度的连续变化。
- “昨日到今日”变化摘要，直接描述扩散、趋势宽度、新高新低和成交活跃度的变化。

### 历史演变

在现有冻结判断列表上方增加 60 个交易日的结构轨迹，按同一时间轴展示：

- 上涨比例与 MA20/MA60 趋势宽度；
- 新高减新低；
- A-D Line；
- 涨跌中位数。

用户可以选择轨迹中的日期查看当日结构数值；已有“查看当日复盘”流程保持不变。

### 今日雷达

增加一张简洁的“今日结构变化”卡，展示由相邻交易日数据计算出的变化摘要，不加入股票名单，不展示指数行情。

## 数据与口径

Python 市场数据服务是全 A 日 K 面板的唯一计算方：

1. 在线现货数据负责当天涨跌幅分布和基础宽度。
2. 本地 `DAILY_BARS` 快照负责历史收盘价面板、均线、滚动新高新低和 60 日结构轨迹。
3. 当天日 K 尚未完整入库时，基础宽度仍可返回；历史型指标置空并附带结构化警告，不把缺失值伪装成 0。
4. 每个趋势宽度都返回有效样本数。MA250 只统计至少有 250 根有效日 K 的股票。
5. 新高/新低使用包含当日在内的滚动最高/最低价；至少达到对应窗口长度才进入统计。
6. `netAdvances = advanceCount - declineCount`；`advanceDeclineLine` 为最近 60 个交易日净上涨家数累计值，作为可复现的滚动参与度轨迹，不宣称是交易所全历史绝对值。
7. 历史序列最多返回 60 个交易日，日期升序；当天基础宽度优先采用现货结果，历史日期采用日 K 面板计算结果。

## 接口设计

`GET /v1/markets/CN-A/breadth` 升级为 `market-breadth-v2`，在既有字段上增加：

- `return_distribution[]`
- `trend_breadth`
- `new_high_low`
- `net_advances`
- `advance_decline_line`
- `history[]`

Java RPC 严格校验 v2 合同并映射到 `finscope-domain` 中的独立领域类型。`MarketBreadthService` 根据最近两个历史点生成 `changeSummary`，避免让 Python 数据层承担中文产品文案职责。工作区继续通过现有 JSON 快照持久化，不需要数据库结构迁移。

## 可靠性与降级

- 在线源失败时继续沿用同业务日冻结快照。
- 历史日 K 样本不足时，只降级相关指标；基础涨跌宽度不受影响。
- v1 缓存不能通过 v2 模型反序列化时，视为旧缓存，重新计算；不会静默展示为完整数据。
- 前端对每个增强区块独立判空，避免某个指标缺失导致整个页面不可用。

- React 测试覆盖新增面板、60 日轨迹和缺失指标降级。
