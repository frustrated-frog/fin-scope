# 投资观察：市场反应观察室

## 第一版契约

从当前分支创建 `codex/investment-reaction-observatory`，不使用 worktree。保留旧观察表与历史读取接口，新建事件反应样本，不按历史分数自动转成样本。

输入来自已保存大事记的不可变快照（真实来源类型/键、标题、摘要、链接、日期、首次本地捕获时间）。系统按标题提示业绩/合同候选，不自动断定关联公司或公告时间。用户可以保存待确认，确认股票（交易所后缀）、名称、事件类型、北京时间公开时刻、关联依据后开始观察。确认后这些字段冻结；错误样本可归档，避免偷偷改写观察起点。唯一键为大事记 ID + 股票代码；重复登记返回已有记录。

股票收益使用同一批前复权日线，基准为明确身份的 000300.SH。复用 QuantDailyBarSource 的来源、复权、as-of 校验，以及 FinanceHttpClient、ApiResponse、BusinessException、交易日历和版本化 SQLite 迁移能力；不新增依赖。基准当前数据提供方同样采用 QFQ 协议标识，指数本身不做股票除权处理。

观察首日是公告日当日（15:00 前）或其后首个交易日（15:00 起及休市日）。起点为首日前一交易日收盘。窗口是交易所的前 1/3/5 个交易日，停牌不能延后窗口。盘中公告提示包含当日公告前行情；仅使用已收盘日期，尚未到期不填零，缺行情与已知零成交停牌分开表示；没有停牌证据时只称缺数据。累计相对表现 = 股票累计收益 - 沪深300同期累计收益，单位百分点，不解释为因果贡献。

详情展示事件前最多五个交易日到事件后五日的同一起点归一化走势、每个窗口的原始与相对表现、来源与截止时间。路径标签只在完整五日窗口后按固定描述规则形成（首日 >=2pp 且五日 <= 首日-2pp 优先归为回吐；否则首日相对 >=2pp 且五日 >= 首日的一半为优势保留；首日绝对相对 <1pp 且五日 >=2pp 为后续走强；五日 <=-2pp 为相对走弱；其余不强行归类）。标签不是预测，阈值随方法版本留存。

同类对照按已确认事件类型筛选，曲线按交易日序号对齐，显示每个样本实际窗口；本版不输出上涨概率或统计显著性。历史补录（公开日期早于登记日期）单独标记并可筛选；与同股票重叠窗口的其他已登记事件并排提示，明确未覆盖全部市场消息。

状态为 DRAFT / OBSERVING / ARCHIVED。开始观察须满足上述字段；归档恢复保留快照。保存及状态变更使用 revision；刷新 RPC 在事务外执行，持久化时校验版本。刷新失败保存错误与尝试时间，保留上一份成功计算；读取不冒充刷新。手动逐项/整页刷新和收盘后定时刷新复用同一服务，重叠执行跳过；后台有界批次游标处理。

新增 /api/investment-reactions：列表分页、候选、创建草稿、确认、归档/恢复、单项/批次刷新。旧接口只用于历史资料展示，不沿用旧来源 ID 跳转，避免把大事记 ID 当雷达 ID。

## 界面

沿用工作台字体与 CSS 变量，主色墨蓝 #233b53、次色青绿 #37766f、背景 #f7f9fb、辅助文字 #697586、边线 #dfe6ed。正文继承系统中文字体，数据用 ui-monospace；最醒目元素是按事件时点对齐的反应曲线与矩阵。首屏直接呈现待确认/观察中/归档切换及事件类型筛选，点击行在页面内展开详情，不铺大号统计卡或证据评分条。窄屏改为逐行卡片，图表保留相同的可读数据表。

## 验收与兼容

测试周末/节假日、盘后/盘中、未收盘、窗口未成熟、缺失起点、停牌、基准缺失、复权/as-of、重复登记、确认校验、并发冲突、失败保留、归档恢复、同类对照和数据缺口。已核验交易日历目前仅覆盖 2026 年，未知年份明确失败；不是用周一至周五猜测。原表完全保留，回滚代码不需删除新表。

## 实现与使用

- 导航仍为「投资观察」。在「登记事件」从大事记提示的候选保存草稿，再在「待确认」核对代码（如 `600519.SH`）、名称、公开时刻、事件类型与关联依据。确认后自动尝试第一次计算；失败不会撤销登记。
- 「反应矩阵」展示 1/3/5 日相对表现；打开行可看个股/沪深300路径、原始来源、行情日期与逐日数据。「对照 +」最多并排查看 4 个同类型案例。「把这个差异带入研究」仅预填问题，不自动启动研究任务。
- `investment_reaction_sample` 由独立迁移 410 创建。旧 `investment_observation` 不改写、不删除，原文可在「历史资料」读取，旧的混用来源 ID 跳转不再出现在新页面。
- 自动任务在北京时间工作日 16:00–23:40 每 20 分钟调度，每批最多 20 个未完成样本，跳过最近 20 分钟已尝试的项。采用独立单线程、零队列执行器；重叠执行跳过，下一轮可重试。完成五日观察的样本只在用户显式操作时重算。
- 部署时需要同时更新并重启 Java 后端和 Python `market-data-service`，后者新增 `/v1/calendar/event-window`。使用现有行情源和配置，无新增依赖或密钥。
- 当前交易日历仅有已核验的 2026 年覆盖；窗口跨出覆盖范围时明确失败。没有分钟行情、自动公司实体匹配、行业基准、历史概率或严格时点回放；这些不属于本版。
