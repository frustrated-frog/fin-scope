# PRD：A 股标的研究数据中心

## 1. 文档信息

- 产品：FinScope
- 功能：A 股标的研究数据中心
- 主要入口：独立顶层 Tab「Market Intel / 标的研究数据」
- 文档日期：2026-07-14
- 状态：实施中（资金行为与龙虎榜事实切片已实现）
- 参考项目：`simonlin1212/TradingAgents-astock` 的 A 股数据工具层

### 1.1 当前实现状态（2026-07-17）

- 已支持从 Market Intel 选择 A 股股票并独立刷新资金行为与龙虎榜维度。
- 龙虎榜当前接入东方财富公开数据中心，查询最近 120 个自然日；查询 API 支持 30、60、120 日窗口。
- 已实现上榜事实、买卖金额、净额、换手率、买入/卖出 TOP5、机构专用和沪/深股通专用标签。
- 数据经过网关路由、限流/熔断、快照降级、不可变版本存储和分维度刷新状态后再提供给页面。
- “未上榜”按成功空集处理；席位子接口局部失败时保留上榜事实并标记 `PARTIAL`。
- 当前不做人名化游资映射、账户身份推断、看多/看空结论，也不向 Agent 或量化回测链路开放。
- 第二龙虎榜数据源尚未接入；主源不可用时仅可使用最近一次成功快照，并明确显示过期/降级状态。

## 2. 背景

FinScope 的自选 Tab 已经能满足当前的基础行情查看需求，包括股票、基金和板块的基本报价与归因研究入口。当前缺口不是“更多行情卡片”，而是对具体标的进行深度研究时所需的结构化上下文：

1. 大笔资金流向、成交金额、换手率及其日内/跨日时间线；
2. 龙虎榜、机构席位和游资痕迹；
3. 限售股解禁、股东减持与供给压力；
4. 个股原生新闻、公告和公司事件；
5. 行业、概念、板块归属与横向比较；
6. 基本面、财务报表、估值和盈利预期；
7. 市场热度、政策快讯和可用于后续验证的观察信号。

TradingAgents-astock 对上述能力做了较集中的接口封装，但其输出主要面向 Python Agent 文本上下文。FinScope 要吸收的是数据获取、容错和数据源组合经验，不是照搬 Python 运行时或直接保存其 Markdown 报告。

## 3. 产品定位

A 股标的研究数据中心是 FinScope 面向股票标的的“研究事实底座”。它以共享 `Instrument` 为主键，按统一时点组织市场信号、公司事件、行业关系、基本面和资讯证据，并服务于：

- 独立「标的研究数据」Tab；
- 自选标的的深度归因；
- 策略页的股票研究命题；
- 事件与证据工作台；
- 研究 Agent 的受控工具和不可变数据快照；
- 每日简报与后续研究记忆。

自选仅是可选的标的入口，不是数据所有者。没有加入自选、但已存在于 `instrument` 的 A 股标的同样可以被查询和研究。

## 4. 目标

1. 在不扩展现有基础行情范围的前提下，补齐 A 股研究所需的结构化数据。
2. 用纯 Java 主链路实现外部数据源适配，不向 FinScope 主应用引入 Python 运行时。
3. 所有数据都带有来源、业务日期、抓取时间、时效状态、原始负载指纹和降级说明。
4. 页面能明确回答“现在有哪些数据、是什么时候的、来自哪里、哪些已过期或缺失”。
5. 外部数据源局部失败时返回部分结果并记录真实错误，不伪造完整快照。
6. 研究 Agent 只消费通过数据质量门的结构化快照，不直接不受控地访问第三方接口。
7. 将“大笔资金是否持续、发生在什么成交环境”设为第一阶段首要研究问题，而不是只展示一个主力净流入数字。
8. 将专业指标自动翻译为通俗、可核验的解释，并允许用户按需启动 Agent 深度解读。

## 5. 非目标

1. 不重做自选页已有的股票、基金和板块基础行情。
2. 不接入券商，不下单，不生成自动买卖指令。
3. 不规避登录、验证码、付费墙、反爬或访问非公开数据。
4. 不将第三方网页/App 内部接口宣称为有 SLA 保证的官方开放 API。
5. 不在第一阶段建设历史回测数据库；实时和近实时研究数据不得冒充 point-in-time 历史数据。
6. 不为了复用 `mootdx` 而默认引入 Python Sidecar；只有后续证明其数据不可替代时才单独立项。
7. 不一次性复制 TradingAgents-astock 的全部数据函数、Prompt、LangGraph 或 Streamlit UI。
8. 不将所谓“暗盘资金”、主力拆单或隐藏账户身份作为已确认事实；没有 Level-2 逐笔数据时只能输出低置信度假设。

## 6. 用户与核心场景

| 用户场景 | 主要问题 | 成功结果 |
| --- | --- | --- |
| 查看自选股票 | 大笔资金何时流入/流出，成交是否同步放大？ | 看到资金、价格、成交金额和换手率的同轴时间线 |
| 看不懂专业指标 | 这些数字组合起来意味着什么？ | 页面自动给出通俗解释，并能定位到原始指标 |
| 深入判断资金行为 | 是否存在持续流入、拆单、吸筹或出货迹象？ | 点击 Agent 解读，查看假设、支持信号、反证、置信度和观察点 |
| 研究异动 | 是公司、行业、资金还是供给冲击？ | 同屏对照龙虎榜、解禁、新闻和板块表现 |
| 长期跟踪股票命题 | 近期证据是在支持还是削弱原命题？ | 将有时间和来源的研究事实关联到命题复盘 |
| 运行归因研究 | 网页搜索结果是否有市场数据支撑？ | 在现有证据轨道中加入受控的市场数据快照 |
| 处理数据源故障 | 报告为什么缺少某个维度？ | 查看每个维度的来源、错误、缓存和降级状态 |

## 7. 数据能力范围

### 7.1 第一优先级：市场行为与供给压力

1. **大笔资金与成交行为（第一阶段最高优先级）**
   - 当日成交金额、成交量、换手率和量比；
   - 主力、超大单、大单、中单和小单的流入、流出、净流入及占当日成交金额比例；
   - 1 分钟原始时间线与 5 分钟聚合视图，同轴展示价格、区间成交金额、累计成交金额和各档资金净流入；
   - 最近 5、10、20 个交易日的成交金额、换手率、资金净流入、净流入占比和连续流入/流出天数；
   - 客观异常标签，包括成交放大但大笔资金流出、缩量流入、价格与资金背离和尾盘资金突变；
   - 异常标签只描述可复算的市场现象，不解释为吸筹、出货或买卖建议；
   - 平台若只提供某档资金净额，则对应流入/流出保持缺失，不通过净额反推不存在的数据；
   - “主力”“大单”等均保留数据平台口径，不解释为已识别的真实机构、账户或暗盘资金。

2. **规则化通俗解释（默认自动展示）**
   - 页面查询到已保存资金数据后，自动生成一段不依赖 LLM 的通俗说明；
   - 固定回答“发生了什么、为什么值得注意、有哪些限制、下一步观察什么”；
   - 每句话关联到具体指标、时间窗口和规则版本，可从解释跳回对应图表位置；
   - 数据不足时明确显示“暂时无法判断”，不使用模糊话术补齐结论；
   - 规则解释失败或版本不支持时不影响原始资金图表展示。

3. **按需 Agent 资金解读**
   - 用户点击「Agent 解读」后才运行，不随页面打开或每次刷新自动消耗模型调用；
   - Agent 输入只包含已保存的规范化资金快照、可复算信号、平台口径和数据质量，不直接访问第三方接口；
   - 输出包含通俗摘要、确定性事实、资金行为假设、支持信号、反证、置信度、数据缺口和后续观察点；
   - “拆单、隐性资金、吸筹、出货”只能进入假设区，必须使用“可能、迹象、尚不能确认”等措辞；
   - 没有 Level-2 逐笔委托/成交证据时，“拆单、暗盘或隐藏账户”假设的最高置信度为 `LOW`；
   - Agent 不生成买入、卖出、仓位或收益承诺。

4. **龙虎榜**
   - 上榜日期、上榜原因、买卖金额、净买入和换手率；
   - 买入/卖出席位 TOP5；
   - 机构专用席位和可识别的席位标签。
   - 当前状态：事实查询、结构化持久化、独立刷新、健康状态与前端席位展开已实现。

5. **解禁、减持与股东变化**
   - 历史解禁和未来 90 天待解禁批次；
   - 解禁类型、股份数、占比与业务日期；
   - 后续增加股东减持、股东户数和质押线索。

6. **行业与概念**
   - 标的所属行业、概念和地域标签；
   - 所属行业与全市场行业涨跌对比；
   - 行业内上涨/下跌家数和领涨股。

### 7.2 第二优先级：个股新闻与公告

1. 以股票代码为入口拉取个股新闻，而不是仅依赖通用搜索词。
2. 优先接入公司公告、交易所/信息披露线索和主流财经平台个股资讯。
3. 新闻复用现有 `Article` 、去重、事件、证据与知识工作台，不建立第二套文章库。
4. 建立文章与 `Instrument` 的显式关联，记录匹配方法、相关度和人工/系统确认状态。
5. 资讯列表可按公告、公司新闻、行业新闻、政策和背景分类。

### 7.3 第三优先级：基本面与市场上下文

1. 最新财务报表摘要和报告期/披露日期；
2. PE、PB、总市值等当前估值与市场快照；
3. 盈利预期与行业横向比较；
4. 热股、涨停原因、政策与全球市场快讯；
5. 实时北向资金可作为市场背景，但历史数据断供或仅本地累积时必须显示明确说明。

### 8.1 导航位置

在「投资工作台」导航组增加：

```text
Watchlist  自选观察
Market Intel  标的研究数据
Strategy  策略工作台
```

Tab 建议代码为 `MI`，内部 View id 为 `marketIntel`。

### 8.2 页面布局

1. **标的选择区**
   - 默认提供自选股票快捷入口；
   - 支持按代码或名称选择已有 `Instrument`；
   - 展示标的名称、代码、市场和基础行情摘要，不重建完整行情面板。

2. **数据健康条**
   - 最后刷新时间；
   - 成功、过期、缺失和不支持的维度数量；
   - 数据源降级、限流和局部失败提示；
   - 「刷新研究数据」操作。

3. **主要研究面板**
   - 大笔资金与成交行为（默认首屏主面板）；
   - 通俗解释卡（随资金数据自动生成）；
   - Agent 深度解读抽屉（用户点击后运行）；
   - 龙虎榜；
   - 解禁与股东风险；
   - 个股新闻与公告；
   - 行业与概念；
   - 基本面与估值；
   - 来源与数据健康。

4. **研究动作**
   - 从当前数据快照发起深度归因；
   - 将新闻/公告打开到事件与证据工作台；
   - 将有价值的事实关联到股票研究命题；
   - 后续支持生成受证据约束的研究摘要。

### 8.3 空状态与错误状态

- 未选标的：引导从自选或代码选择。
- 未刷新：展示可用数据维度和首次刷新会发生的操作。
- 部分成功：已取得的维度正常展示，失败维度展示错误、最新可用缓存和重试入口。
- 数据过期：保留显示但使用 `STALE` 标识，不冒充当前数据。
- 不支持：明确说明市场、标的类型或数据源暂不支持。

## 9. 数据信任与证据边界

### 9.1 数据源等级

| 等级 | 定义 | 示例 | 使用原则 |
| --- | --- | --- | --- |
| `PRIMARY_DISCLOSURE` | 一手信息披露 | 交易所、公司公告、官方政策 | 可作为公司事件的直接证据 |
| `MARKET_PLATFORM` | 主流财经平台展示的市场数据 | 东财、新浪、腾讯、同花顺 | 记录平台口径，不伪装成主体级一手数据 |
| `FINANCIAL_MEDIA` | 专业财经媒体 | 财联社等 | 用于时效线索和背景，重要结论寻找独立印证 |
| `DERIVED_LOCAL` | FinScope 本地计算或累积 | 趋势、本地历史快照 | 必须指向原始数据和计算口径 |

### 9.2 统一时间语义

每条数据至少包含：

- `dataDate`：数据所属业务日期；
- `publishedAt`：对外公布时间，适用于公告、新闻和财务数据；
- `effectiveAt`：开始生效的时间，适用于解禁、分类或成分关系；
- `retrievedAt`：FinScope 实际取得时间；
- `pointInTimeSafe`：是否可用于严格历史研究；
- `qualityStatus`：`FRESH / STALE / PARTIAL / UNAVAILABLE`。

### 9.3 结论边界

- 资金流平台口径是数据特征，不等于已确认的真实买卖主体。
- 资金异常标签和规则解释必须能由保存的资金、价格和成交数据复算，不输出“吸筹”“出货”等意图判断。
- Agent 可以提出拆单、吸筹、出货或隐性资金假设，但必须与确定性事实分区展示，并受数据质量和证据门限制置信度。
- 龙虎榜上榜和机构席位是事实，“看多/看空”属于后续推断。
- 解禁计划是供给压力线索，不等于解禁后必然卖出。
- 个股新闻的相关性不等于因果性；必须经过现有证据门和反证轨道。
- 未通过 point-in-time 验证的数据不得进入量化回测数据集。

## 10. 核心用户流程

```text
打开 Market Intel
  -> 从自选或 Instrument 选择 A 股标的
  -> 查看已保存的最新快照与数据健康
  -> 必要时手动刷新
  -> 各数据维度独立执行并保存运行状态
  -> 页面展示成功数据、过期数据和局部错误
  -> 规则解释器自动把资金指标翻译为通俗说明
  -> 用户需要时点击 Agent 解读
  -> Agent 基于同一快照输出事实、假设、反证和观察点
  -> 打开某条新闻/公告的证据详情
  -> 从当前数据快照发起归因或研究命题复盘
```

## 11. 分阶段实施目标

### 第一阶段：研究数据底座与首批市场信号

**实现目标**

1. 增加独立 Market Intel Tab、标的选择器、数据健康条和手动刷新流程。
2. 建立 Java `marketintel` 领域、数据源 SPI、刷新运行、结构化持久化和分维度错误状态。
3. 优先实现大笔资金与成交行为：当日摘要、1/5 分钟时间线、5/10/20 日趋势和可复算异常标签。
4. 实现默认自动展示的规则解释卡，每条解释能定位输入指标和规则版本。
5. 实现点击触发的资金解读 Agent，复用既有 Agent 控制面、Trace、LLM 和置信度门。
6. 龙虎榜事实切片已实现；解禁日历、行业/概念和行业比较继续按第一阶段推进。
7. 建立统一 HTTP 客户端、数据源限流、超时、有界重试、负载大小限制和原始负载指纹。
8. 首期仅支持 `STOCK` 类型 A 股，不扩展基金和板块研究数据。

**阶段完成标志**

- 用户可选择一只 A 股并得到至少四个维度的结构化数据；
- 资金主面板能查看当日成交摘要、日内时间线和最近 5/10/20 日趋势；
- 任一资金时间点均能定位到数据源、平台口径、业务时间和抓取时间；
- 资金异常标签能通过固定输入样本确定性复算，且不包含暗盘、吸筹或出货判断；
- 页面无需调用 LLM 即可稳定展示通俗规则解释；
- 点击 Agent 解读后能查看运行进度、输入快照、模型、输出和降级原因；
- Agent 的事实与假设分区展示，拆单/暗盘类假设在缺少 Level-2 时不超过 `LOW` 置信度；
- LLM 未配置、超时或输出非法时，规则解释和资金图表仍可正常使用；
- 任意单个数据源失败不会使整个页面失败；
- 所有展示数据都能看到来源和抓取时间；
- 单元、Repository、Service、Controller 与前端关键流程测试通过。

### 第二阶段：个股新闻、公告与证据串联

**实现目标**

1. 实现代码定向的个股新闻适配器和至少一条公告/信息披露链路。
2. 复用现有 `Article` 入库、去重和事件证据流程。
3. 增加 `Instrument` 与 `Article` 关联，展示匹配原因、相关度、发布时间和来源等级。
4. 在 Tab 中建立公告、公司新闻、行业新闻和政策背景时间线。
5. 支持从资讯打开原文、事件、证据和后续研究入口。

**阶段完成标志**

- 个股资讯不再只依赖 Tavily 实时搜索；
- 同一 URL 或相同内容不重复入库；
- 新闻和公告能被现有事件/证据服务消费；
- 错误关联可被识别和修正，历史关联不被静默覆盖。

### 第三阶段：基本面、预期与数据可靠性

**实现目标**

1. 增加最新财务报表摘要、披露日期、当前估值和盈利预期。
2. 增加热股/涨停原因、股东变化与可用的市场背景。
3. 为高价值数据维度提供备用数据源、熔断、缓存 TTL 和字段漂移检测。
4. 增加数据源健康详情、刷新历史和不同口径冲突告警。
5. 明确标记只适合当前研究、不可用于历史回测的数据。

**阶段完成标志**

- 基本面数据包含报告期与披露日期；
- 备用源被使用时页面和运行记录可见；
- 字段缺失、口径冲突和过期数据不会被静默吞掉；
- 外部网络不可用时仍能查看最新已保存快照及其时效标识。

### 第四阶段：归因、命题与 Agent 研究整合

**实现目标**

1. 将研究数据组装为带指纹的不可变 `StockResearchSnapshot`。
2. 向归因研究的 `MARKET / COMPANY / INDUSTRY / COUNTER` 轨道提供受控数据工具。
3. 将公告、新闻和市场数据区分为事实、背景和推断，复用现有证据置信度上限。
4. 支持将快照关联到股票研究命题和复盘，保留当时可见数据。
5. 提供“当前支持、反证、数据缺口和下一观察点”的结构化研究摘要，不生成买卖指令。

**阶段完成标志**

- 每次 Agent 运行都可回溯到确切数据快照与来源；
- Agent 不能提高数据/证据门给出的最高置信度；
- 归因报告能将搜索证据与市场数据快照联合展示；
- 命题复盘能查看当时数据，不被后续刷新覆盖。

## 12. 总体验收标准

1. Market Intel 是独立 Tab，不改变自选 Tab 现有行情交互。
2. 数据以 `Instrument` 为所有者，不要求标的必须在自选列表。
3. 首批五个维度的数据能持久化、重新查询并显示来源、业务日期和抓取时间。
4. 刷新运行可查询每个维度的状态、尝试数、错误类型、降级来源和输出数量。
5. 局部失败不阻断其他维度，也不把过期缓存伪装成当前数据。
6. 新闻和公告复用现有文章、去重、事件与证据领域。
7. 任何提供给 Agent 的输入都含快照指纹、来源、时间和质量状态。
8. 实时/近实时研究数据与量化回测数据集保持分离。
9. 后端 Repository、Service、Controller 与前端关键用户流程都有自动化测试。
10. 外部接口合同使用固定样本进行解析测试，默认 CI 不依赖真实网络。
11. 大笔资金主面板同时展示绝对金额和相对成交金额占比，不允许只用单一净流入数值代替完整成交上下文。
12. 通俗规则解释能定位到输入快照、指标和规则版本；Agent 判断还必须定位到 Prompt、模型版本及运行 Trace。

## 13. 产品指标

1. 选择标的后，已保存快照在 300ms 内完成主要页面查询（本地环境，不含外部刷新）。
2. 刷新运行对单源失败可降级为 `PARTIAL`，不影响已成功数据查看。
3. 资讯入库不重复率、标的错关联率和数据源过期率可通过运行记录计算。
4. 归因报告使用市场数据时，所有引用都能定位到保存快照。
5. 资金时间线的缺失点率、最后更新时间和跨来源时间对齐告警可通过运行记录计算。

## 14. 风险与取舍

1. **外部接口不稳定**：通过 SPI、固定样本测试、限流、缓存和数据健康状态隔离变化。
2. **平台口径不透明**：保留原始字段口径和来源，不在存储层添加看多/看空判断。
3. **请求过密被限制**：按数据源统一节流，手动刷新合并相同标的的活跃运行。
4. **范围扩张**：按四个阶段交付，不将基本面、Agent 整合和历史回测混入第一阶段。
5. **与现有数据重复**：基础行情复用 `QuoteService`，资讯复用 `Article`，证据复用 `EvidenceItem/AttributionEvidence`，仅新建市场研究数据专属模型。
6. **资金口径被误读**：页面并列展示成交金额、换手率、占比、来源和算法说明；事实/规则层不提供暗盘或账户身份推断，Agent 只能在假设区低置信度表达。
7. **Agent 过度解读**：事实、规则解释和模型假设三层隔离；置信度门可下调模型结论，模型不能覆盖原始数据。
