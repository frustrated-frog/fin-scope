# 产品需求：策略研究中枢第三期

> 状态：待评审
> 日期：2026-07-15
> 适用范围：资金行为、量化工作台、因子研究 Agent
> 核心原则：专业不等于复杂；先建立可信证据链，再提升 Agent 能力，最后扩展因子数量。

## 1. 背景

FinScope 已分别具备两类能力：

- 资金行为页面能够展示主力净流入、分档资金、历史事件评价和数据质量；
- 量化工作台能够冻结行情数据集、计算一组内置因子、执行横截面选股回测并保存实验。

但两者目前仍是两套研究语言。资金行为的结论无法直接进入量化实验，量化工作台中的因子又缺少完整的经济假设、数据来源、计算口径、适用边界和验证证据。用户看到若干专业指标，却难以判断“它在说什么、证据够不够、什么时候会失效、下一步该做什么”。

本期不通过增加更多卡片和图表制造专业感，而是把资金行为和量化研究接入同一套可审计流程，让每个结论都能够沿着“数据—定义—计算—评价—实验—结论”回溯，并由 Agent 帮助普通用户完成研究，而不是替用户编造确定答案。

## 2. 产品定位

将现有量化工作台升级为“策略研究中枢”：一个面向认真学习投资研究的个人研究系统。

它不是自动荐股工具，也不是展示大量技术指标的行情终端。它负责回答五个问题：

1. 这个因子到底衡量什么？
2. 这个数字来自哪里，是否使用了当时真实可获得的数据？
3. 它在历史上是否稳定有效，还是只在某段样本中碰巧有效？
4. 把它加入策略后，收益、风险、换手和成本发生了什么变化？
5. 当前证据支持、反驳还是无法判断最初的研究假设？

## 3. 路线选择

本期采用 **A → C → B**：

1. **A：研究专业化。** 先统一数据、因子定义、评价协议、统计门禁与证据展示。
2. **C：受控半自主 Agent。** Agent 在用户批准的研究边界内规划并调用确定性工具，形成可复查结论。
3. **B：因子扩展。** 在准入机制成熟后，再逐步增加资金行为、风险控制、基本面及经典表达式因子。

不采用“先导入大量因子、再补验证”的路线。因子数量不是本期成功指标，能够解释和证伪才是。

## 4. 目标与非目标

### 4.1 产品目标

- 打通资金行为页面与量化工作台，使资金行为指标能够以冻结、可复现的数据进入因子研究和策略实验。
- 建立专业的因子档案、生命周期和验证协议，使每个因子的来源、含义、计算口径、适用范围和历史证据清晰可查。
- 为非专业用户提供逐层解释：先给结论和风险，再解释原因，最后按需展开公式与统计细节。
- 建立受控的研究 Agent，使其能够提出研究计划、调用确定性工具、比较实验、主动寻找反证并形成结构化研究记忆。
- 将实验结果与使用的数据集、因子版本、策略版本、成本假设和工具调用完整绑定。

### 4.2 非目标

- 不接入券商交易，不自动下单，不提供收益承诺。
- 不允许 Agent 任意执行 Python、SQL 或系统命令。
- 不让 Agent 自动把候选因子升级为“已验证”或“可生产使用”。
- 不把资金行为与量化模块的现有注册表粗暴合并。
- 不在本期一次性复刻 Qlib、Alphalens 或商业量化平台的全部功能。
- 不用复杂动画、更多菜单或更多默认图表包装专业性。

## 5. 目标用户与核心场景

### 5.1 首要用户

对量化研究感兴趣、但尚不能独立理解 IC、显著性、横截面中性化和样本外验证的个人投资者。用户愿意学习，但需要系统把专业判断翻译成可理解的问题。

### 5.2 次要用户

能够检查公式、统计假设和实验参数的进阶研究者。其需要完整的专业详情、可复现实验和证据导出，而不是被简化信息限制。

### 5.3 核心用户故事

- 作为普通用户，我在资金行为页面看到“主力连续流入”后，可以一键创建研究草稿，了解它是否只是个股现象，还是在同日股票池中具有普遍区分能力。
- 作为普通用户，我看到“ICIR 0.42”时，不需要先知道术语，也能理解为“排序方向有一定一致性，但证据是否足够还要结合样本数、置信区间和样本外表现”。
- 作为研究者，我可以查看因子的公式、来源、可获得时间、缺失处理、中性化方式、版本及所有历史评价。
- 作为用户，我可以批准 Agent 在指定数据集、因子范围、实验次数、时间和工具预算内继续研究，并在关键决策点重新确认。
- 作为用户，我能看到 Agent 找到的反证、失败实验和失效条件，而不是只看到最优结果。

## 6. 产品原则

### 6.1 专业不等于信息密度

默认界面只回答“是什么、证据如何、风险是什么、下一步做什么”。公式、统计检验、指纹和明细表放在“为什么”和“专业详情”中渐进展开。

### 6.2 数字由代码计算，文字由 Agent 解读

收益率、IC、分组收益、统计检验、换手、成本和数据质量必须由版本化的确定性程序产生。Agent 只能引用结果、比较证据、解释限制和组织结论，不得自行生成数值。

### 6.3 先提出假设，再运行实验

每次研究必须先记录研究问题、预期方向、经济解释、失败条件和评价口径。系统不鼓励从大量结果中事后挑选一个看起来最好的指标。

### 6.4 同一信号允许两种评价，但不能混为一谈

- 个股事件评价回答：同一只股票历史上出现该信号后，未来 1/3/5 日相对自身基线如何。
- 横截面因子评价回答：同一天的股票池中，因子排名较高的股票是否具有更高的未来收益排名。

页面必须明确标注评价类型，Agent 不得使用一种评价替代另一种评价。

### 6.5 所有结论都有证据边界

系统只输出“支持”“反驳”“证据不足”三类研究结论，不输出“必涨”“强烈买入”等确定性判断。结论必须同时展示数据区间、样本数量、标的范围、成本假设和失效条件。

## 7. 总体信息架构

策略研究中枢在界面上是一个统一工作区，不新增七个一级菜单。默认入口始终是“研究桌面”，系统依据当前任务在同一工作区中切换上下文；下列七项是能力分区，不等同于七张独立页面：

1. **研究桌面**：研究问题、当前结论、证据强弱、风险和下一步行动。
2. **数据中心**：数据集、覆盖率、时间范围、可用时间和数据质量。
3. **因子实验室**：因子档案、计算验证、分布诊断、单因子评价和准入状态。
4. **实验矩阵**：不同因子、参数、股票池、调仓频率和成本假设的可比实验。
5. **稳健性实验室**：样本外、滚动窗口、市场阶段、参数扰动、成本压力与多重检验。
6. **策略库**：策略版本、组成因子、组合规则、历史实验和变更原因。
7. **研究记忆**：假设、工具调用、发现、反证、结论、失效条件及证据链接。

资金行为页面保留自身的实时观察定位，只新增进入研究中枢的桥梁，不变成第二个量化工作台。数据、因子、实验、稳健性和记忆默认以摘要、抽屉或任务步骤呈现；只有用户主动进入“专业详情”时才显示完整研究台账。

## 8. 关键体验：三层解释

每个因子、评价结果和实验结论统一提供三层信息。

### 8.1 第一层：一句话结论

面向小白，固定回答：

- **它衡量什么**：例如“主力流入占成交额的比例，用于比较不同规模股票的资金流入强度”。
- **目前证据**：支持、反驳或证据不足。
- **为什么这样判断**：用一至三条自然语言证据解释。
- **主要风险**：例如样本太少、只在小盘股有效、换手过高或样本外失效。
- **建议下一步**：补数据、做中性化、运行样本外检验或停止研究。

### 8.2 第二层：为什么

用生活化例子、方向解释和对照组说明：

- “净流入 1 亿元”不能直接跨股票比较，因为对小盘股可能很大、对大盘股可能很小；除以成交额后才更接近可比较的强度。
- “最高组收益更高”仍不足以证明稳定有效，还要看其他分组是否大体单调、不同时间段是否一致以及扣除成本后是否仍成立。
- 每个专业词提供行内解释，并展示它回答的研究问题，而不是只给定义。

### 8.3 第三层：专业详情

折叠展示公式、字段口径、来源链接、可获得时间、缺失处理、去极值、标准化、中性化、IC 序列、统计检验、数据集指纹、计算版本及实验标识。

### 8.4 禁止的表达

- 不单独展示“ICIR 高”“胜率不错”“显著有效”等缺少上下文的判断。
- 不以绿色/红色代替结论依据。
- 不把回测收益直接翻译成未来收益预期。
- 不隐藏失败实验、成本假设或数据质量问题。

## 9. 功能需求

### 9.1 资金行为到量化研究的桥接

资金行为页面为可研究信号提供以下操作：

- 查看因子定义；
- 查看个股历史事件评价；
- 创建量化研究会话；
- 送入策略实验室形成实验草稿。

“创建研究会话”只带入标的范围、候选信号、观察时间、当前证据和建议评价口径，不自动运行回测。“送入策略实验室”只创建草稿，不改变已保存策略。

量化研究页面反向展示：因子源自哪个资金行为字段、对应哪些历史事件评价、当前使用哪个冻结数据版本，以及原始证据入口。

### 9.2 冻结研究数据集

系统支持两类数据集：

- **学习数据集**：可使用虚拟或小样本数据，只用于理解流程，始终显示“不能用于验证真实有效性”的水印。
- **研究数据集**：使用真实、按时点可获得、质量门禁通过的冻结数据，方可进入正式评价。

资金行为数据必须随行情和基本面数据一同冻结并生成指纹。已有实验永远读取其绑定的冻结版本，后续线上刷新不得改变历史结果。

### 9.3 因子档案

每个因子必须具备以下信息：

- 名称、编码、版本、分类、方向、频率和单位；
- 一句话解释、经济假设、预期生效机制、可能风险暴露；
- 数据来源、原始字段、可获得时间、回看窗口、缺失处理和复权口径；
- 公式或受控计算器、去极值、标准化和中性化规则；
- 固定来源链接或论文标识、改编说明和许可证信息；
- 适用股票池、评价周期、数据集指纹、评价指标和历史状态；
- 已知失效场景、反证和最近一次复核时间。

因子状态依次为：候选、定义已评审、实现完成、计算已核验、探索中、已验证、具备生产资格、已失效或已退役。状态变更必须保留原因和操作者。

### 9.4 因子评价

正式评价至少覆盖：

- 数据覆盖率、缺失率、异常值、截面数量和可获得时间检查；
- 因子分布、极值集中、行业/规模/波动率/流动性暴露；
- 多持有期 Pearson IC、Rank IC、均值、波动、ICIR、正 IC 比例和置信信息；
- 分位数组合收益、最高组减最低组、单调性和衰减；
- 换手率、排名自相关、调仓敏感性、涨跌停约束、费用和容量风险；
- 中性化前后表现、与已有因子相关性及增量价值；
- 样本内/样本外、滚动窗口、不同市场阶段、参数扰动和股票池变化；
- bootstrap、多重检验与策略层面的风险调整后评价。

系统应把统计量翻译为用户可理解的判断，并保留原始结果供复核。

### 9.5 首批资金行为候选因子

本期优先研究可解释、可比较的候选因子：

- 主力净流入占成交额；
- 主力流入强度的 20 日标准分；
- 5 日归一化主力流入累计值；
- 5 日归一化主力流入趋势；
- 超大单贡献度；
- 5 日资金流持续性；
- 价格—资金背离；
- 行业内相对资金强度。

原始净流入金额不得直接作为跨股票比较因子。盘中峰值、反转等依赖高频路径的信号先保留为事件标签，数据条件成熟后再考虑因子化。

### 9.6 受控研究 Agent

Agent 由用户问题启动，先生成研究计划，计划至少包含：

- 研究假设及预期方向；
- 使用的数据集、股票池、时间范围和因子版本；
- 评价指标、对照实验、失败条件和预计工具调用；
- 最大实验次数、时间预算和成本预算；
- 需要用户确认的关键节点。

用户批准后，Agent 可在边界内顺序调用确定性研究工具、比较结果、追加低风险诊断并形成结论。以下行为必须再次确认：

- 扩大数据范围或工具预算；
- 引入新的数据来源；
- 修改正式策略；
- 发布或升级因子状态；
- 执行超出已批准计划的新实验方向。

Agent 必须展示运行进度、工具输入摘要、成功或失败状态、消耗预算、证据链接和停止原因。单个工具失败不能被描述为整个研究成功。

### 9.7 研究记忆

研究记忆不是聊天摘要，而是结构化记录：研究问题、假设、计划、工具调用、实验、发现、反证、结论和失效条件。每条结论必须绑定数据集指纹、因子/策略版本、实验编号和证据。

后续 Agent 可以检索历史结论，但必须检查版本和适用范围。过期或条件不一致的记忆只作为线索，不作为当前事实。

### 9.8 实验比较与策略版本

用户可以并排比较基线和候选实验，差异视图至少包含：

- 改了什么；
- 收益、回撤、风险调整后表现、换手和成本变化；
- 数据、因子、参数及市场阶段是否一致；
- 哪些指标改善、哪些指标恶化；
- 是否存在样本外退化或复杂度上升；
- Agent 的解释及引用证据。

任何策略修改生成新版本，不覆盖旧版本。策略发布前必须通过独立于 Agent 文本判断的门禁。

## 10. 状态、异常与空数据体验

- 数据不足时明确说明缺少多少样本、缺少哪些字段、能够做什么和不能做什么。
- 数据质量未通过时允许查看和诊断，但禁止标记为已验证。
- 评价运行中显示当前阶段、已完成工具、剩余预算和可安全取消状态。
- 工具超时或失败时保留已有结果，标明未完成的证据，不自动得出支持结论。
- 指纹或版本不一致时禁止直接比较，并提供重新冻结或重新运行入口。
- 没有显著结果是正常研究结果，应允许保存为反证或证据不足。

## 11. 成功指标

### 11.1 可信度指标

- 100% 新建正式实验绑定数据集指纹、因子版本、策略版本和成本假设。
- 100% Agent 展示的数值可追溯到确定性工具结果。
- 100% “已验证”因子通过版本化验证门禁并保留审批记录。
- 资金行为候选因子能够同时展示事件评价和横截面评价，且类型标识清晰。

### 11.2 易懂性指标

- 用户在不展开专业详情的情况下，能够回答“因子衡量什么、证据够不够、最大风险是什么、下一步做什么”。
- 每个核心统计术语都有面向当前结果的解释，而不是词典式释义。
- 可用性走查中，新手能够在三步内从资金行为信号创建研究草稿并理解为何尚不能直接用于策略。

### 11.3 研究效率指标

- 同一研究计划中的实验可自动比较，减少人工记录参数和复制结果。
- 失败实验和反证可被检索并阻止重复研究。
- Agent 在预算内完成计划或给出明确、可恢复的停止状态。

不以回测收益、因子数量或 Agent 对话轮数作为本期核心成功指标。

## 12. 分期交付

### 12.1 A1：研究契约与数据桥

- 建立中立的因子研究领域、因子档案和生命周期；
- 冻结资金行为日频数据并纳入数据集指纹；
- 建立个股事件评价与横截面评价的明确边界；
- 完成三层解释组件和资金行为到研究草稿的双向链接。

### 12.2 A2：评价协议与稳健性门禁

- 完成多周期 IC、分组收益、换手、暴露、中性化和样本外评价；
- 建立版本化验证策略与学习/研究数据集分级；
- 首批资金行为候选因子进入探索阶段。

### 12.3 C：受控半自主 Agent

- 上线研究计划审批、确定性工具调用、预算和审计轨迹；
- 上线稳健性复核和结构化研究记忆；
- 支持基线—候选—反证实验自动比较。

### 12.4 B：受控扩因子

- 先增加行业、规模、波动率、流动性等控制因子；
- 再增加可解释的价格量、基本面和资金行为因子；
- 最后评估 Qlib 表达式和经典公式因子，每个候选仍须通过完整准入流程。

## 13. 验收标准

1. 从资金行为页面选择候选信号后，可创建一个包含来源证据、因子版本、建议股票池和评价口径的研究草稿；不得自动运行或修改策略。
2. 使用同一冻结数据和同一版本重复实验，结果及指纹完全一致。
3. 任一正式因子均可从结果回溯到因子定义、原始字段、可获得时间、计算版本、数据集和来源。
4. 系统能对同一资金行为信号分别给出个股事件评价与横截面评价，并在页面和 Agent 文本中明确区分。
5. 学习数据集、数据质量不合格或仅有样本内结果时，系统不得将因子升级为已验证。
6. Agent 提交计划并获得批准后，只能调用白名单工具且不能突破数据、因子、实验次数、时间和预算边界。
7. Agent 的所有数字均能打开对应工具结果；无法验证的文字必须明确标记为推断。
8. 新手默认视图能够用自然语言说明结论、证据、风险和下一步，专业详情可查看完整公式与统计结果。
9. 失败实验、反证、工具异常和门禁拒绝均可被保存、检索和复查。
10. 策略或因子的正式状态变更均需人工确认并生成不可覆盖的版本与审计记录。

## 14. 风险与治理

- **过拟合风险**：通过预注册假设、样本外、滚动验证、参数扰动和多重检验控制。
- **未来数据泄漏**：所有字段记录可获得时间，数据冻结与评价均执行 point-in-time 检查。
- **Agent 权威幻觉**：数值只来自工具，解释必须引用证据，并强制展示反证与限制。
- **用户误解**：默认使用“支持/反驳/证据不足”，明确研究结果不构成交易建议。
- **复杂度失控**：默认视图限制为结论、证据、风险、下一步；新增专业指标必须说明它回答哪个问题。
- **外部来源漂移**：引用固定版本或 DOI，并记录本地改编，不把第三方实现直接视作正确答案。

## 15. 参考原则

本期借鉴但不照搬以下公开研究工程思想：

- Qlib 的表达式化因子与数据处理思想；
- Alphalens 的 IC、分位收益、换手、衰减等因子评价维度；
- RD-Agent 的“假设—实验—运行—反馈—追踪”研究闭环；
- FinRobot 的“数字由代码计算，叙事由 LLM 辅助”；
- TradingAgents 的角色分工与人工检查点；
- 101 Formulaic Alphas 的可复现表达式案例；
- 因子动物园、多重检验和 Deflated Sharpe Ratio 对数据挖掘偏差的警示。

这些来源用于建立研究纪律，不作为因子有效性的背书。
