# PRD：自选页板块行情中心

## 1. 文档信息

- 产品：FinScope
- 功能：自选页板块行情中心
- 页面入口：自选观察
- 文档日期：2026-07-14
- 状态：待评审
- 对应技术方案：`docs/技术方案-自选页板块行情中心.md`

## 2. 背景

当前自选页已经具备两类能力：顶部展示上证指数、深证成指、创业板指和科创 50；下方“我的自选”统一展示股票、基金和板块。现有设计能查看已知板块的行情，却不能回答以下问题：

1. 今天哪些行业和概念最强、哪些最弱；
2. 用户如何从全市场排行中发现板块并持续关注；
3. 用户如何关注一个当前没有进入涨跌榜的任意板块；
4. 板块关注如何避免与股票、基金自选混在一起或重复展示。

因此，自选页需要在“市场指数”和“我的自选”之间增加独立的“板块行情”区域，将全市场扫描和个人板块跟踪放在同一工作区。

## 3. 产品定位

板块行情中心是自选页中的“市场结构层”：</n+
```text
市场指数     回答大盘整体表现
板块行情     回答资金和涨跌集中在哪些方向
我的自选     回答个人股票与基金表现
```

板块行情中心同时提供：

- **全市场板块**：系统自动展示行业与概念的领涨、领跌排行；
- **我的关注**：用户主动关注的板块，可持续查看行情和进入深度归因。

板块关注仍然属于用户的关注关系，但不再出现在下方“我的自选”中。下方“我的自选”只保留股票和基金。

## 4. 目标

1. 在市场指数下方、我的自选上方新增边框和背景均独立的板块行情区域。
2. 支持行业板块、概念板块切换，并同时展示领涨前 5 和领跌前 5。
3. 支持从排行榜一键关注或取消关注板块。
4. 支持按板块名称或 `BKxxxx` 代码搜索并关注未进入排行榜的板块。
5. 在“我的关注”中展示已关注板块的行情，并保留现有深度归因与报告回看能力。
6. 下方“我的自选”只查询和展示股票、基金；新增标的类型中移除“板块”。
7. 复用现有后端关注持久化与板块行情能力，既不复制数据，也不依赖浏览器本地存储。
8. 外部板块行情失败时明确展示数据质量，不影响市场指数和股票/基金自选。

## 5. 非目标

1. 第一期不建设板块详情页、K 线页或成分股完整列表。
2. 第一期不增加板块资金净流入、上涨/下跌家数和连续强度评分；这些指标后续接入结构化市场研究数据后再扩展。
3. 第一期不支持拖拽排序、板块分组和关注提醒。
4. 不将公共排行榜结果写入 `instrument` 或 `watchlist_item`；只有用户执行关注时才持久化。
5. 不新增第二套板块关注表，不迁移或删除现有板块关注记录。
6. 不改变股票、基金现有分组、排序、刷新和归因规则。

## 6. 信息架构与布局

### 6.1 页面层级

```text
市场指数（现有独立区域）

板块行情（新增独立面板）
├── 全市场板块
│   ├── 行业 / 概念切换
│   ├── 领涨前 5
│   └── 领跌前 5
└── 我的关注
    ├── 搜索并关注板块
    └── 已关注板块卡片

我的自选（现有独立面板）
└── 股票 / 基金
```

### 6.2 桌面端

- 板块行情使用一个独立大框，与市场指数、我的自选之间各保留明确间距。
- 面板上半部分为全市场板块；领涨榜、领跌榜各占一列。
- 面板下半部分为我的关注，使用分隔线与上半部分区分。
- 已关注板块使用紧凑卡片网格，避免与市场指数大卡片形成视觉重复。

### 6.3 响应式

- 中等宽度：领涨和领跌仍保持双列，关注卡片减少列数。
- 窄屏：领涨/领跌改为分段切换或上下单列，关注卡片单列展示。
- 搜索结果浮层不得超出视口，键盘操作和触屏操作均可完成关注。

## 7. 功能需求

### 7.1 全市场板块排行

1. 默认打开“行业”分类，用户可以切换“概念”。
2. 每个分类展示领涨前 5 和领跌前 5。
3. 每行至少展示：
   - 板块名称；
   - 涨跌幅；
   - 领涨股名称及涨跌幅；
   - 关注状态按钮。
4. 板块代码不作为主视觉信息，但可在悬浮提示或辅助信息中显示。
5. 红色表示上涨，绿色表示下跌，零涨跌使用中性色，沿用现有 A 股颜色语义。
6. 已关注板块显示实心关注状态，未关注板块显示空心状态。
7. 行业/概念切换后保留已取得的数据，避免反复闪烁和不必要请求。
8. 榜单必须来自同一批次的板块目录快照，不能由多个不同时间的单板块请求临时拼接。

### 7.2 搜索并关注任意板块

1. “我的关注”标题区提供搜索框，支持板块名称和 `BKxxxx` 代码。
2. 搜索覆盖行业板块和概念板块，不局限于当前排行或当前分类。
3. 输入后延迟触发搜索，避免每次按键都请求服务器。
4. 搜索结果展示板块名称、分类、代码、当前涨跌幅和关注状态。
5. 已关注结果不可重复添加；关注操作在服务端保持幂等。
6. 搜索失败不影响已经展示的排行榜和关注卡片。
7. 无结果时明确显示“未找到匹配板块”，不得将网络失败伪装成无结果。

### 7.3 我的关注

1. 自动承接数据库中已有的 `SECTOR` 类型自选记录，无需用户重新添加。
2. 每张卡片展示：
   - 板块名称、代码；
   - 最新点位、涨跌额和涨跌幅；
   - 成交额；
   - 行情日期或更新时间；
   - 最新归因摘要（存在时）；
   - 深度归因/重新归因入口；
   - 取消关注入口。
3. 第一版按现有 `sort_order`、关注时间倒序展示，不提供拖拽排序。
4. 取消关注后只删除关注关系，不删除 `instrument` 和历史归因报告。
5. 空状态提供搜索引导，并说明可从上方排行榜点击关注。
6. 单个板块行情失败时保留卡片，显示失败原因；不得删除或隐藏关注关系。

### 7.4 我的自选调整

1. “加入自选”的类型选择只保留“股票”和“基金”。
2. 下方自选数量只统计股票和基金。
3. 下方分组、排序、全部展开/收起只作用于股票和基金。
4. 现有板块记录不在下方重复展示，但会出现在“板块行情 → 我的关注”。
5. 通过旧接口直接向普通自选添加板块时，服务端返回明确错误并提示使用板块关注接口。

### 7.5 刷新、加载和降级

1. 页面首屏并行请求市场指数、板块排行、关注板块和股票/基金自选。
2. 四类资源拥有独立加载和错误状态，任何一类失败都不阻断其他区域。
3. 现有“刷新行情”按钮统一刷新市场指数、当前板块排行、关注板块和股票/基金自选。
4. 强制刷新期间禁用重复点击，并显示刷新中状态。
5. 新数据无效但页面已有有效数据时，保留旧数据并明确提示“已保留上次有效行情”。
6. 排行榜允许在实时源失败时返回短期过期快照，但必须展示“数据已过期”和快照时间。
7. 首次访问且没有可用榜单时，在板块排行区域展示不可用状态和重试入口。

## 8. 核心用户流程

### 8.1 从排行榜关注

```text
打开自选页
  -> 查看行业领涨/领跌
  -> 点击某板块的关注按钮
  -> 服务端幂等创建关注关系
  -> 排行榜更新关注状态
  -> 该板块立即出现在“我的关注”
  -> 下方“我的自选”不出现该板块
```

### 8.2 搜索关注

```text
在“我的关注”输入名称或 BK 代码
  -> 查看行业与概念匹配结果
  -> 点击关注
  -> 关注卡片出现
  -> 清空搜索或继续关注其他板块
```

### 8.3 取消关注

```text
从排行榜或关注卡片取消关注
  -> 幂等删除关注关系
  -> 排行榜变为未关注状态
  -> 关注卡片移除
  -> Instrument 与历史归因报告保留
```

### 8.4 深度研究

```text
查看关注板块卡片
  -> 点击深度归因或最新归因摘要
  -> 复用现有归因运行与报告阅读器
  -> 返回后仍停留在自选页板块行情区域
```

## 9. 数据与信任边界

1. 排行榜属于第三方市场平台口径，不代表交易所官方行业分类。
2. 行业、概念分类和领涨股名称均保留数据源口径。
3. 排名只对同一快照中存在有效涨跌幅的板块进行排序。
4. 缺失涨跌幅、板块代码或名称的数据不得进入榜单，但应计入数据质量警告。
5. 公共板块目录不写数据库；关注时才按现有规则按需创建 `Instrument(type=SECTOR)`。
6. 排行榜缓存时间、实际抓取时间和数据质量状态必须透传前端。

## 10. 验收标准

### 10.1 页面与交互

- 市场指数、板块行情、我的自选是三个边界明确的区域。
- 行业/概念可切换，分别看到领涨前 5 和领跌前 5。
- 可从排行关注和取消关注，并立即同步到我的关注。
- 可搜索未进入排行榜的板块并关注。
- 已关注板块只在板块行情区域出现一次。
- 下方新增类型只有股票和基金，数量和分组均不包含板块。
- 关注板块仍能发起归因和打开历史报告。
- 桌面、平板和手机宽度均无横向溢出。

### 10.2 数据与可靠性

- 关注操作重复执行不会产生重复数据或错误状态。
- 排行榜、关注板块、自选、市场指数任一失败时，其余区域仍正常使用。
- 强制刷新失败时保留上一次有效数据，并展示可识别的过期/降级状态。
- 现有 `SECTOR` 自选数据无迁移、无丢失，升级后自动进入我的关注。
- 取消关注不会删除标的主数据或归因历史。

### 10.3 质量门禁

- 后端 Provider 解析、服务排序缓存、关注幂等和接口隔离均有自动化测试。
- 前端覆盖分类切换、关注/取消、搜索、刷新、失败隔离和板块不重复展示。
- 现有市场指数、股票/基金自选和归因测试继续通过。

## 11. 后续路线

第二期可基于市场研究数据增加：

- 板块主力净流入和净流入排名；
- 上涨/下跌家数、涨停家数和市场宽度；
- 连续强势天数、强度衰减和板块轮动；
- 关注板块异动提醒；
- 板块详情页、成分股和关联事件。

这些能力需要更严格的历史快照和时间语义，不进入本期范围。
