# 财报研报联动分析产品需求文档

## 1. 产品定位

在“公司财报分析”页面新增“研报分析”Tab，将券商研报从静态 PDF 转换为可学习、可核对、可追溯的结构化研究材料。页面不只给出摘要，而是完整呈现研报的核心观点、业务与行业分析、盈利预测、关键假设、催化因素、风险、术语解释和原文证据，并用当前公司已入库的财报数据验证研报观点。

财报数据是客观事实层，研报是外部观点与预测层，Agent 结论是推断层。三层信息必须在页面和接口中明确标识，不允许把预测值写入财报事实表。

## 2. 目标用户与核心场景

目标用户是希望通过阅读财报和券商研报学习公司研究方法的个人投资研究者。

核心场景：

1. 进入某家公司后自动获取最新公开券商研报，也可上传一篇合法取得的研报 PDF 作为补充。
2. 快速看到机构、分析师、发布日期、评级、目标价和研报类型。
3. 阅读详细解读，而不是只看一句话摘要。
4. 查看收入、净利润、EPS、毛利率等预测及其关键假设。
5. 将研报观点与当前或后续财报指标联动，判断观点是已验证、已证伪还是待观察。
6. 随时查看研报原文和解析出的完整文本，学习分析师的论证过程。

## 3. 第一期范围

### 3.1 纳入范围

- A 股非金融企业。
- 自动同步最近 365 天公开个股研报目录，最多展示 20 篇，自动导入并解读最新 1 篇。
- 其余公开研报按需导入；PDF 上传作为自动来源未覆盖时的补充。
- 文本型 PDF 自动解析，扫描件明确标记待 OCR。
- 详细结构化解读：摘要、投资逻辑、公司与业务分析、行业与竞争、盈利预测、关键假设、催化因素、风险、学习提示、术语。
- 研报预测与已入库财报实际值对照。
- 研报观点与财报指标/科目的证据联动。
- 原文文件、解析文本、原文摘录和页码追溯。
- LLM 可用时做详细解析；不可用或输出不合法时保留原文并提供确定性基础解读，不阻断导入。

### 3.2 暂不纳入

- 绕过登录、付费墙或版权限制抓取研报。
- 扫描 PDF 的本地 OCR 引擎。
- 自动生成买卖建议、收益承诺或仓位建议。
- 多机构一致预期、分析师准确率排行榜和提醒系统。
- 金融企业专用指标体系。

## 4. 信息架构

“研报分析”Tab 由以下部分组成：

1. **研报资料库**：自动同步状态、公开研报候选、研报选择器、机构、分析师、日期、评级、目标价、解析质量和补充上传入口。
2. **核心结论**：三至五条有原文证据的核心观点，区分观点、事实和推断。
3. **详细解读**：投资逻辑、业务拆解、行业竞争、关键假设、催化因素、风险提示、学习提示和术语解释。
4. **盈利预测与实际对照**：按财年展示预测值、实际值、差异和验证状态。
5. **财报联动验证**：展示关联的财报指标/科目、实际值、报告期、验证理由和证据来源。
6. **原文学习区**：展示解析后的详细原文并提供 PDF 原件入口。

## 5. 关键规则

### 5.1 预测验证状态

- `VERIFIED`：实际结果与观点方向一致，或预测偏差处于可接受区间。
- `CONTRADICTED`：实际结果与观点方向明显相反，或预测偏差显著。
- `PENDING`：预测期尚未结束或尚无对应财报。
- `INSUFFICIENT_EVIDENCE`：存在口径冲突或证据不足。

### 5.2 数值口径

- 收入与利润优先使用财报 `concept_code` 对应的归一化值。
- EPS、毛利率等指标优先使用 `financial_metric`；不存在时不擅自补造。
- 单季度、累计、年度必须显式区分。
- 预测期尚未结束时只显示“待观察”，不能判错。
- 页面同时展示预测单位和实际单位，后端统一为可比较的标准数值后再计算偏差。

### 5.3 可信度与版权

- 每条实质性研报观点保留原文摘录；能识别页码时一并保存。
- 只有摘要或低质量文本时，页面显式显示证据不足。
- 原文只用于用户本地研究，不向外发布。
- 所有页面保留“不构成投资建议”的声明。

## 6. 交互流程

1. 用户选择公司与财报报告期。
2. 进入“研报分析”，页面自动同步公开目录并导入最新研报。
3. 后端保存公开原文、提取文本、生成详细结构化解读并计算财报联动。
4. 页面展示已自动导入和待按需导入的研报；用户也可补充上传 PDF。
5. 用户切换研报时加载对应详情；切换财报报告期时重新展示与该报告期相关的实际值验证。
6. 用户可以重新同步或重新解析，但同一来源与同一原文不重复保存。

## 7. 验收标准

- 新 Tab 可在现有财报页面直接使用，不改变原有 URL 与其他 Tab。
- 首次进入可自动取得公开研报，无需先上传文件；同步失败不影响已有研报和财报功能。
- 自动同步展示来源、完成时间、成功/跳过/失败数量；其余候选可以按需导入。
- 可以上传合法 PDF，非法文件和超过 30MB 文件得到明确错误。
- 导入后可看到详细解读、盈利预测、财报联动、风险和原文学习区。
- 同一 PDF 重复上传不会产生重复研报。
- LLM 未配置时仍能完成导入并展示基础解读和原文。
- 有对应财报指标时展示实际值及验证状态；没有时显示待观察或证据不足。
- 后端测试、前端测试和生产构建全部通过。
