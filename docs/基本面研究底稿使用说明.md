# 基本面研究底稿

## 使用

在 Watchlist 点击股票名称，打开「基本面研究」。默认展示本地底稿；首次点击「更新底稿」读取公开公司资料，并复用现有财报补齐流程。原有季度趋势、财务指标、估值曲线与同行比较在「季度趋势与估值」中。

1. 公司怎样赚钱：东方财富公司资料提供公司简介、行业和经营范围；收入来源、客户回款、关键成本与竞争优势由用户整理成经营笔记，可附材料链接。刷新公开资料不会覆盖笔记。
2. 利润、现金与资金投入：使用最新已结束且未标记冲突、不可用或待核验的合并财报，整理四个维度的事实与下一步核查项。
3. 近期公告：关联本地投资观察中该股票最近 12 条非草稿、未排除的事件。回购预案、贷款承诺、股东披露分别解释，承诺额度不记为实际提款或实际回购。
4. 验证清单：从财务变化或最近三项公告加入观察，也可自行新增。保存前可以修改判断、事实基线、支持条件、反证条件和计划复核日期。复核时追加新事实，并选择持续跟踪、得到支持、出现反证或已结束。

经营笔记、验证事项和复核历史均存入当前配置的 SQLite 数据库。每次复核保留原始基线；页面显示每项最近 10 条复核，数据库保留全部记录。每家公司最多展示 100 项验证，进行中事项优先；进行中达到 100 项后需先结束部分事项。

## 财务规则

- 本页为年初至报告期末的累计口径，资产负债项目为期末值；不混入单季度值。单季度派生继续由原有趋势页面负责。
- 金额只读取报告主来源、同币种、对应期间角色的结构化项目；同概念数值冲突时不计算该项。缺失数据不按零值处理。
- 营收同比只比较上一年同报告期、同报告类型、同合并口径、同币种和同来源的报告，前期营收须为正。
- 现金兑现使用经营现金流 / 合并净利润，归母净利润单独展示。合并净利润缺失或非正时不计算该比例。经营现金流低于合并净利润一半时提示优先核对。
- 应收账款同比增速高出营收同比至少 15 个百分点时，提示核对回款与结算变化。
- 「经营现金流减资本开支」直接展示两项之差，不作为自由现金流估值。当前版本的财务结论由确定性规则生成，经营原因由后续材料和复核验证。

## 接口与恢复

统一入口为 `/api/watchlist/stocks/{code}/fundamental-research`，当前支持本地已登记的 A 股股票。

| 方法 | 路径后缀 | 用途 |
| --- | --- | --- |
| GET | 无 | 读取本地底稿，不触发外部抓取或财报刷新 |
| POST | `/refresh` | 显式刷新公司资料和财报；任一来源失败仍保留已有资料与用户记录，并返回缺口 |
| PUT | `/notes` | 保存经营笔记，要求当前 `revision` |
| POST | `/watches` | 新增验证，以股票和 `originKey` 唯一约束防止重复覆盖 |
| PATCH | `/watches/{id}/review` | 追加复核，要求当前 `revision`，同时更新状态 |

笔记或复核版本过期时返回 409，重新读取后再编辑。状态更新与复核历史在同一事务提交，历史写入失败时状态一并回滚。新增表由启动迁移幂等创建，不需要手工执行 SQL。
