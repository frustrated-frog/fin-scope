# 自选股票自动展示增强

## 范围与约束

- 保留自选卡片、分组、配色和页面布局，展示增强进入现有股票行情详情。
- 基金页面与基金持仓不在本次范围内；不恢复“关注理由”。
- 默认自动整理数据，不要求用户画线、设置规则或手动维护观察内容。
- 在当前 `codex/tail-direction-reliability` 分支开发，不创建工作树。

## 数据契约与口径

1. 行情沿用 Python 市场数据服务与 Java RPC；传递来源、质量、复权、观测时间和日线完整性。
2. 收益、回撤、量价观察和历史事件仅使用已完成且校验通过的日线；N 日收益需要 N+1 个收盘价。
3. 年初至今收益需要上一年末基准收盘价，历史不足时展示原因；不使用当前年首条记录冒充年末基准。
4. 基准对比使用共同交易日、共同起点与终点，展示沪深300身份和日期范围；不填补缺失交易日。
5. 放量比使用之前完整交易日的均量，排除当日；盘中未完成数据不与整日成交量直接比较。
6. 自动标记和价格位置来自历史价格计算，显示日期与计算窗口，不表述为确定预测。
7. 财务趋势区分累计与单季度，披露期、币种、来源和缺口可见；估值仅展示真实本地历史及有效样本分位。
8. “上次查看以来”使用浏览器本地快照，首次访问明确建立基线，不把新增自选、基金或失败数据计为股票变化。

## 批次

### A. 行情分析计算

新增纯函数与领域测试：多周期涨跌及最大回撤、YTD、均线距离、相对成交量、连续涨跌、近期高低位、自动技术事件、共同交易日相对收益曲线。

### B. 行情数据契约

复用现有日线与基准数据，补全元信息、历史长度与显式基准读取，新增股票历史聚合接口。次要数据失败不阻断主图，来源失败必须可见。

### C. 股票展示集成

在现有行情详情自动呈现多周期表现、量价观察、相对强弱曲线、价格位置和事件标记；保留已有行情与产业链入口。自选页增加紧凑的股票变化回顾，不调整卡片布局。

### D. 财务与估值展示

复用财务、估值模块及缓存，自动读取并在必要时补齐数据，展示财务趋势、估值历史曲线和分位样本。外部失败保留已有数据，独立显示缺口与重试入口。

### E. 验收

- 计算规则测试覆盖窗口边界、除权口径、未完成日线、缺失值、重复日期和基准日期错位。
- 接口测试覆盖股票/基金边界、上游失败、部分数据、元信息与序列化。
- 前端测试覆盖自动展示、切换股票、防止旧请求污染、刷新及原有基金功能回归。
- 前端构建、相关后端/Python测试与桌面/窄屏视觉验证通过。
- 每批先做规格审查，再做代码质量审查；通过后独立提交并立即推送当前分支。

## 完成记录

- 股票详情自动展示 5/20/60/120/252 日与年初至今表现、收盘回撤和区间小图；展示 MA20/MA60 距离、相对均量、连续涨跌、沪深300累计涨跌对比、近期价格位置与完整的最近20日事件。
- 原自选卡片与基金入口保留；股票变化回顾独立比较本浏览器上次访问的价格、异动区间及新增归因报告。
- 财务与估值标签自动补齐最近8个已结束季度，展示营业收入、归母净利润、经营现金流、毛利率；保留来源、币种、披露期和缺口。
- 估值展示真实历史曲线、有效样本分位及最多8个同日、同来源的本地同行样本；没有数据时明确展示缺口。
- 针对未完成日线、未知复权、均线浮点边界、共同日期对齐、访问快照回退、行情失败但报告更新、财报刷新部分写入及相邻累计依赖等情况，已增加回归测试并完成独立审查。
- 全量前端133个文件、710项测试通过；新增图表小曲线后的18项定向测试通过，前后端生产构建通过。相关后端接口、编排、季度派生、同行查询及兼容测试通过。
- 真实数据联调：澳弘电子加载500根完整前复权日线及500根沪深300日线，8个季度均有营收数据；1440px与390px视口验证无横向溢出。
- 新增Spring依赖使用字段注入；新增/修改分支使用完整大括号；类型按DAO/领域/RPC/服务/Web职责放置；没有新增依赖或修改密钥配置。

## 运行边界

- 估值历史按成功获取的真实快照积累。实测澳弘电子的估值来源暂不可用，页面展示数据缺口，不填充历史或分位；显式刷新可重试。
- 同行样本依赖现有股票行业归属及同日同源估值，不表示完整行业覆盖。
- 财报刷新失败时，本次响应与短期缓存保留刷新前的完整季度快照；现有财报写入流程的跨重启原子恢复不在本次展示增强范围内。
