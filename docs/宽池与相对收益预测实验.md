# 宽池与相对收益预测实验（2026-09-07）

本批在当前分支 `codex/next-session-joint-ranking` 增强现有股票发现、单股预测，不增加 Tab。实现已经完成；两组真实历史实验均未证明整体优势，新模型继续作为对照，不替换原主预测。服务验收结果见文末。

## 已实现的方法

1. 训练池与展示池分离：从真实缓存中按稳定代码哈希补足最多 1,200 只沪深股票，保留展示股票优先覆盖；训练选择不按当前价格、预算或热榜强度排序。行情在 SQL 中按实验截止日截断，至少 365 根有效前复权日线。展示仍沿用现有准入条件。
2. 42 个因子：原 38 因子增加同行 20 日动量、同行 5 日上涨广度、个股相对行业动量、行业覆盖标志。同行排除自身，至少 2 个有效同行。行业成员从实际观测次日起生效，历史未知时保持缺失标志，不把今天的成分倒填到过去。
3. 预测两个不同目标：上涨概率仍是股票实际次日收盘上涨事件；收益回归增加 `(股票收益 − 历史 beta × 市场收益) / 历史波动率` 候选。该候选预测后加回单独 Ridge 市场预测，恢复为实际股票涨跌。市场模型每个日期只计一个样本；beta 限制在 0–2、波动率下限 0.005。
4. LightGBM、逻辑回归、二者固定等权概率融合只按选择段 Brier 选择。绝对收益回归与市场残差回归只按选择段还原后的绝对收益 MSE 选择。不是完整 DoubleEnsemble，也没有根据验收成绩重新调整融合权重。
5. LambdaRank 使用同日波动率标准化市场残差的五档相关性标签，截断参数 8，关注靠前候选；排序分数不冒充上涨概率。训练采用宽池，Top 5 与 Rank IC 只在展示候选池计算。

延续[上一轮方法来源](次日联合模型与排序实验.md)：Qlib 量价特征与时序评测、Learning to Rank 股票排序思路，未复现或移用论文成绩。

## 固定实验协议

版本 `next-session-broad-residual-v2`。模型固定 100 棵树、学习率 0.03、15 叶、深度 5、叶子最少 40 样本、L2=5、随机种子 42；市场模型 Ridge alpha=10。按日期分训练、选择、校准和最后 60 日测试，边界移除未成熟标签；发布时再按最新成熟历史重训。

本批固定 2025-12-31 为较早历史实验，2026-09-04 为近期回归对照。两者都在方法确定后报告一次结果，不据此继续调参。历史选择池仍依赖当前缓存，不是完全重建的历史全市场，因此较早窗口也不宣称为完整无偏样本外证明。

当测试起日不晚于 2026-09-06，证据标记 `RETROSPECTIVE` 并禁止自动替换原模型；只有冻结后完整前瞻窗口才能进入后续优势判断。未来仍需满足原概率、收益、区间和排序优势门槛。

## 数据限制与下一阶段研究

- 宽池来自本地缓存，缺少完整历史退市和上市成员信息，仍有幸存者偏差。近期仅 363 只具备截止日预测条件，历史训练覆盖 1,198 只并不等于每天有 1,198 只新鲜可预测股票。
- 行业历史覆盖为 0%，新增行业列在历史训练中没有提供有效增量。目前仅建立按可用日期积累真实行业记录的能力，尚不能验证行业学习优势。
- 60 个测试交易日具有横截面相关性，数万股票日样本不等于数万个独立样本。冻结后的未来数据才是下一次可信比较的重点。
- 若继续增强准确性，优先补充一致新鲜的宽池行情及真实历史行业成员，再固定消融实验比较宽池、残差、行业因子的独立贡献；不凭这两个已见窗口继续筛选模型后宣布胜出。
