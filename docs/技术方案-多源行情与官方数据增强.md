# 技术方案：多源行情与官方数据增强

## 目标与交付

针对东方财富失败后新浪降级粒度、字段或新鲜度下降的问题，沿用 Java 业务网关与 Python 数据能力服务，增加独立免费来源和官方盘后能力。重点是可实际持续取数、可恢复、可解释、保持有效结果产出。

本轮在 `codex/market-data-source-upgrade` 开发，不创建工作树，不批量下载多年全市场历史。来源适配只处理外部协议，路由处理候选排序、并发合并、时间预算和快照；业务服务继续负责研究与展示。每批通过针对性验证后独立提交并推送。

## 来源分工

| 能力 | 增强方向 |
| --- | --- |
| 实时报价 | 保留腾讯主源与独立备用；新浪股票、指数均读取源时间戳 |
| 日线 | 腾讯原始日线 + 比例复权因子，BaoStock 独立日线补充，保留扶摇；指数优先腾讯，东财与新浪补充 |
| 分钟价格 | 验证腾讯最近分钟线并提供独立能力；真实成交额未知时保持缺失，不混入已有要求真实成交额的研究样本 |
| 全市场盘后 | 通达信官方每日批量包，按交易日下载、解析、校验、限量缓存，服务市场宽度与盘后截面 |
| 财报与官方事实 | 保留已有巨潮披露接入；结构化三表增加独立来源并保留报告期、币种、单位及来源 |
| 资金流与板块 | 保留各家的统计和分类语义；日级结果继续产出，分钟能力缺失明确说明 |

## 日线与复权

腾讯差额前复权与研究使用的比例复权分开。读取原始价格、实际成交量和成交额，以覆盖日期的新浪比例因子做前复权（原始价格除因子）；保留价格和因子各自来源。因子有界缓存与并发合并，不能因因子缺失把原始价格标为前复权。BaoStock SDK 在独立进程执行，超时终止回收，避免进程级 socket 状态影响实时采集。

## 稳定性

一次能力请求有总时间预算，候选来源有独立超时；串行降级不重复耗尽整份预算。同一证券同一能力并发请求合并，来源容量和健康按能力隔离，取消不吞中断。可重试网络错误有限重试；空返回、Schema 漂移与不支持的粒度有明确结果。慢源失败继续尝试独立来源。

网络成功、数据日期新鲜、字段完整分别评估。旧结果继续用于明确日期的展示和研究；成功返回日级资金流不代表分钟能力已恢复。快照只有有效在线结果可覆盖；财报快照必须区分报告期、报告类型和合并口径。

## 通达信盘后包

完整 `hsjday.zip` 与每日 `.cod/.md1` 包是两种协议，本轮接入每日包。校验 ZIP 大小、解压体积、市场成员、记录映射、数值与证券身份；将 A 股从指数、基金、债券中分离。每日包只代表所请求日期，404 同时可能代表尚未发布、缺档或非交易日，不能据此判定休市。失败不覆盖成功缓存，缓存有数量与总空间限制，临时文件原子替换，只清理自身管理的包。

## 验证

离线测试用真实协议形态的固定响应覆盖字段单位、复权跨事件、重复分页、日期错配、超时回收、并发合并、来源降级和缓存范围。真实接口冒烟限少量证券/单日包，记录日期、覆盖与耗时，不把单次成功当作长期稳定保证。运行 Python、Java 相关回归及接口契约测试。

参考：通达信个人行情数据 https://www.tdx.com.cn/article/vipdata.html；AKShare 腾讯新日线实现 https://github.com/akfamily/akshare/blob/main/akshare/stock_feature/stock_hist_tx.py；免费源参考 https://github.com/simonlin1212/a-stock-data 。仅参考协议与实测线索，不继承其业务规则或不安全 TLS 示例。

## 实施与实测记录（2026-10-12）

已落地：腾讯原始日线与比例复权、BaoStock 可终止日线进程、通达信官方每日包、腾讯盘中有界批量行情与最近分钟价格、独立结构化财报来源、按报告期隔离的快照、请求合并及能力容量隔离。Java 保留真实来源与质量，新浪报价不再以请求时间代替行情时间；指数缺成交额时保留价格，并明确以成交量代理流动性相对指标。

股票日线默认只读已收盘历史。指数可提供盘中截面，标记 `is_complete=false`、使用当前截面时间、最多复用一分钟，并在收盘后重新取数。显式请求当日股票截面可用于展示；量化股票研究拒绝将其当作完整收盘样本。

整体回归：Python 全量 619 项通过；后端 `mvn test` 通过（含已有故障组合回归）；前端生产构建及相关页面 36 项通过。盘中完整性、快照失效与报表形态恢复的最后改动另行通过 Python 103 项专项与 Java 9 项量化日线契约测试。真实接口验证仅说明此次响应与映射正确，稳定性后续可由已有运行审计与质量信息观察。

代码按独立批次提交推送。既有数据与配置保持兼容；本轮没有全市场多年历史导入、付费供应商切换或现有数据清理。运行实例需要加载更新后的 Java 与 Python 代码。
