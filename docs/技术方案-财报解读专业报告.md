# 财报解读专业报告：结构化数据阶段

日期：2026-10-05。提示词/报告版本：financial-interpret-v5；分析版本：financial-analysis-v5；公式版本：financial-metrics-v3。

## 输入与材料边界

沿用 `/api/financials/reports/{id}/interpretations` 异步接口、快照、输入指纹复用、一次修复和确定性降级。无需新增数据库表，报告新字段保存在原有 result JSON 中；历史六维报告继续可读。

服务端先组织十章提纲，再单次生成完整报告，最后执行校验。提纲包含章节材料引用、教学解释、常见误读和已知缺口，不增加十次模型调用。

输入只使用本地结构化三表、指标、规则和历史。历史限定当前报告期之前、同公司代码/市场、同币种、同合并口径；加入上一年同类报告的原始科目。最多读取二十份历史报告，模型证据预算从七十二条扩至一百一十二条，按三表分配原始科目容量、优先本期，并为核心趋势最多保留十六条位置。完整快照同时留存提纲、实际模型证据标识和输入字节数。

不使用后续报告解释历史报告；不因公司名称推断主营业务。业务拆分、管理层讨论、审计意见、附注、同行和研报观点没有接入本次证据。范围栏明确显示这些缺口。模型仅负责叙事，不自行换算单位或计算指标。一季报优先取累计披露数，因为第一季度累计等于单季，避免受历史派生零值干扰；旧公式年度指标不参与新公式趋势，范围栏会说明。

## 输出

保留经营状态、总置信度、执行摘要、核心变化、三表联动、限制及声明。新版使用 sections 代替六维 dimensions，旧字段保留默认空数组以兼容历史。

十章：公司与商业模式、本期业绩与历史趋势、增长来源与持续性、盈利能力与费用、利润质量、现金流与营运资金、资产质量、偿债与融资、资本效率与资本配置、披露风险与后续验证。

每章包含综合判断、章节置信度、关键事实 FACT、分析 INFERENCE、替代解释/反证 INFERENCE、后续验证 WATCHPOINT、引用和材料缺口。每条判断包含独立置信度。教学说明和常见误读由服务端固定规则补齐，作为一般知识显示，不能当成公司证据。

有材料的章节必须包含事实、分析、反证和验证；无材料的章节只能低置信度/证据不足，不补造公司判断。详细段落按材料展开，没有最小字数要求。模型不可用时，按章整理可核查数据和教学说明，经营状态标记证据不足，不能把降级伪装成完整研究。

## 校验与口径

沿用结构、引用存在、置信度上限和投资建议门禁；新版以逐条引用校验代替全包数字白名单，并增加：

- 全部十章覆盖；判断类型与章节数组匹配；推断置信度最高中等。
- 每条判断中的数字必须来自本条引用，允许原样数值及零至两位小数的展示舍入；禁止只引用无关材料而复述其他证据中的数字。
- 原因/未来影响的常见词不能标为 FACT；已确立的连续趋势须有至少三个相邻季度或年度时点；否定趋势和未来核查语句不被误当作既成趋势。无引用的限制段落不得补写数字。
- 三表联动必须引用至少两个报表域的原始科目。
- 缺少业务/披露原文的章节不可生成公司事实；章节总引用必须有与主题相关的证据。

这些是可机械验证的必要条件，不是完整语义蕴含证明。页面提示原因解释仍待核查，不把“引用校验通过”解释为所有论证已证实。

补充确定性指标：存货/总资产、应收/总资产、资本开支/收入、货币资金/已覆盖有息负债。仅对正分母计算。流动/速动比率使用倍数，营业总成本不再替代营业成本计算毛利率。亏损/零利润基期明确提示增长率解释限制。有息负债以“已覆盖科目”标识；不把缺失项目视为完整负债口径。

## 阅读与兼容

新版显示范围与材料覆盖、执行摘要、章节目录、连贯正文、关键数值和报告期、可展开教学说明/常见误读、反证与下一步验证、学习阅读路径。证据引用继续通过当前解读所属快照打开抽屉。

旧版使用原卡片布局；新版本失败时保留旧成功结果，历史记录不覆盖。新报告需要点击生成/重新生成，浏览旧结果不会自动产生模型调用。

## 验证

后端测试覆盖非法引用、引用外数字、过度置信、原因冒充事实、缺章/反证、无原文补造、趋势/三表约束、空字段、降级、比较历史过滤与新增指标。前端验证新版阅读、教学展开、数值引用、版本切换与旧版兼容，并执行 TypeScript/生产构建。

生成耗时需以真实模型样本测量，不能沿用原短报告的延迟目标。PDF 与附注证据属于下一阶段。
