# 次日联合模型与排序实验（2026-09-06）

本轮增强现有股票发现与单股预测，不增加 Tab。新增 38 因子的联合 LightGBM 概率/收益模型及独立 LambdaRank 股票排序。**本次真实测试未支持整体替换旧模型，因此作为对照上线，不能宣称预测准确率已经提高。**

## 方法来源

- [Qlib LightGBM / Alpha158](https://github.com/microsoft/qlib/tree/main/examples/benchmarks/LightGBM)：借鉴量价特征和时序评测思路。本实现复用原 20 个特征，增加 10 个 K 线、RSV、量价相关特征及 8 个截面特征，并非完整复现 Alpha158。Qlib 默认标签与本项目不同，此处固定预测下一交易日收盘相对当前收盘。
- [Building Cross-Sectional Systematic Strategies By Learning to Rank](https://arxiv.org/abs/2012.07149)：借鉴独立排序目标；[LightGBM LGBMRanker](https://lightgbm.readthedocs.io/en/stable/pythonapi/lightgbm.LGBMRanker.html) 按交易日分组，以同日未来收益五档作为 relevance，排名得分不解释为上涨概率。
- [MASTER](https://github.com/SJTU-DMTai/MASTER) 作为后续研究参考，本轮没有引入其 Transformer 或移用论文成绩。

## 实验协议

使用截止 2026-09-04 的本地真实前复权行情，从现有发现股票池按原准入条件得到 183 只股票、182,452 个股票日期样本。开发段、60 日选择段、60 日校准段、最后 60 日测试段按时间划分，各边界清除未成熟标签；选择和校准段实际可验证信号各 59 日。最后测试为 2026-06-11 至 2026-09-04 的 10,976 个样本，指标按交易日等权。

训练固定 100 棵树、学习率 0.03、15 叶、深度 5、叶子至少 40 样本、L2=5、随机种子 42，没有根据最终测试成绩重新调参。分类模型仅按选择段 Brier 选出，校准段用于 Platt 概率校准及 80% 绝对残差区间。发布预测时按最新成熟数据重训，历史测试指标仍保留原时点结果。

截面特征先按当天可见股票计算，再排除次日停牌等不可验证标签，避免使用“明天是否交易”反向改变今天的因子。行情指纹覆盖有效的最后 1,061 根日线；单股入口仅复用同日、相同有效行情的联合快照。

## 解释边界与复现

该实验的历史股票集合来自今天可用的股票池，未重建历史上市/退市及行业成分，存在幸存者和选池偏差；截面样本彼此相关，10,976 行不等于 10,976 个独立观测。只有 60 个测试交易日，不代表长期或不同市场环境。Top 5 结果是收盘到收盘收益，未包含费用、可成交价格或组合回测。模型测试未通过后没有重调参数并重复使用同一测试集证明提升。

在 `market-data-service` 目录执行：

```sh
uv sync --extra dev
# macOS 首次使用 LightGBM：brew install libomp
.venv/bin/python scripts/evaluate_next_session_joint.py --as-of 2026-09-04
```

原始实验输出位于本地 `market-data-service/data/quant/joint-experiment-2026-09-04.json`（不提交市场数据）。该命令只读现有行情和股票池缓存；缓存变化时结果也可能变化。日常发现流程按新行情重训并发布 `next-session-joint.json`；单股预测读取共享快照。
