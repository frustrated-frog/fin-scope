# 真实持仓策略实验室使用说明

## 1. 它解决什么问题

真实持仓策略实验室只管理手工录入的 A 股股票账户。它把三个容易混淆的问题严格分开：

1. **真实账户核算**：我实际有多少股、现金多少、成本多少、盈亏多少；
2. **股票量化预测**：在不读取个人成本和盈亏的前提下，这只股票未来 1/5/20 日的概率与收益分布如何；
3. **仓位策略**：在已经持有、资金有限且 A 股按一手交易的情况下，当前证据是否允许改变仓位。

页面位于“策略 → 长期投资 → 真实持仓”，包含实盘总览、交易流水、持仓诊断、影子策略和验证账本五个视图。它不会连接券商、不会自动下单，也不会承诺收益。

## 2. 第一次使用

如果电脑迁移前已经有持仓，按当前真实状态初始化，不必补录全部历史：

1. 用“资金转入”记录当前可用现金；
2. 每只已持有股票录入一条“期初持仓”，数量填写当前股数，成交价填写当前可核对的单位成本；
3. 如果券商成本已经包含历史费用，不要再重复填写费用；
4. 对这只股票运行一次单股完整研究，留下可复用、带模型版本和数据指纹的预测记录；
5. 回到真实持仓页。页面会自动读取最新记录并生成当天影子策略，无需点击刷新。

期初持仓不扣减现金，它表示“系统接管时已经存在的证券资产”；资金转入表示接管时账户中实际可用的现金。二者相加形成初始账户权益。

## 3. 日常如何记账

### 3.1 事件含义

| 事件 | 必填内容 | 对账户的影响 |
|---|---|---|
| 期初持仓 | 股票、数量、单位成本 | 建立一次初始仓位，不重复扣现金 |
| 买入 | 股票、数量、成交价 | 扣现金；数量必须是 100 股整数倍 |
| 卖出 | 股票、数量、成交价 | 加现金并确认已实现盈亏；允许卖出零股余量 |
| 现金分红 | 股票、现金金额 | 增加现金与分红收益 |
| 送转股 | 股票、增加数量 | 总成本不变，单位成本下降 |
| 资金转入/转出 | 现金金额 | 只改变现金，不伪装成投资收益 |
| 冲正 | 原事件 | 原事件与冲正事件在重放时同时排除 |

佣金、印花税、过户费和其他费用只在用户明确填写时入账。系统不会悄悄编造一笔默认费用。记录写入后不直接编辑；录错时在“交易流水”中冲正，再写入正确事件，这样每次变化都有审计轨迹。

### 3.2 成本口径

账户采用移动加权平均成本：新买入金额与费用加入剩余总成本；部分卖出确认已实现盈亏，但不改变剩余股票的单位成本；送转增加数量而不增加总成本。

真实市值使用原始、不复权行情。单股预测与回测继续使用前复权日线，二者不能混用。行情不可用时会保留数量和成本，但不会用前复权价格冒充真实市值。

## 4. 如何阅读影子策略

| 动作 | 含义 | 不是在说什么 |
|---|---|---|
| 保持持有 | 现有证据不足以支持改变仓位 | 不等于保证上涨 |
| 允许加仓 | 概率、费用后中位优势、左尾风险、现金和集中度同时通过，且至少买得起一手 | 不是自动买入指令 |
| 降低集中度 | 单股风险暴露超过上限，风险预算优先于方向观点 | 不一定代表模型看跌 |
| 退出条件触发 | 上涨概率、收益中位数和左尾风险联合恶化 | 不因浮亏或跌破成本价单独触发 |
| 证据不足 | 行情过期、模型健康暂停、预测样本不足或数据链不完整 | 不把失败包装成“持有建议” |

每条成功建议冻结：预测运行 ID、模型版本、数据指纹、概率与 P10/P50/P90、原始行情日、持仓数量、风险金额、动作、建议数量、证据、阻断项、策略版本和到期日。同一股票、同一天、同一策略版本只保存一次。

真实成本和浮盈亏只用于解释“这个动作对我的账户意味着什么”，不会进入上涨概率、因子值或股票发现排名。股票发现页的“真实持有”徽标同样只在排序完成后附加。

## 5. 验证账本

默认基准是“同一只股票保持当时持仓不动”，不是沪深 300。预测周期到期后，页面读取该预测记录已冻结的真实结果，并在 Python 中按冻结动作计算影子结果：

- `HOLD` / `ABSTAIN`：影子收益等于同股持有，增量为零；
- `ALLOW_ADD`：按冻结建议数量增加的名义敞口计算影子收益；
- `REDUCE_CONCENTRATION`：按冻结减少数量降低收益与风险暴露；
- `EXIT_TRIGGERED`：触发后视为持有现金，后续股票收益为零。

这里比较的是“当时建议如果执行”与“什么都不改”的前瞻差异，不冒充用户真实成交。等待到期时显示 `PENDING`；历史数据无法形成同口径结果时显示 `UNAVAILABLE`；只有完成冻结结算后才显示策略收益、持有收益和增量价值。

少量持仓意味着样本增长会很慢。单个正确结果不能证明策略稳健；必须积累跨时间、跨行情阶段的独立样本，才能讨论胜率、校准或稳定优势。

## 6. 常见降级与恢复

- **只有成本、没有市值**：原始行情暂不可用。账本不受影响，稍后重新进入页面即可重估；
- **显示“等待预测记录”**：先去单股预测页对该股票运行一次完整研究；
- **显示“证据不足”但没有记录 ID**：本次只生成透明的临时拒绝，不写入可验证样本；
- **Python 服务不可用**：账户与交易流水仍可使用，建议按单股隔离失败；恢复 Python 行情侧车后重新进入页面；
- **录错交易**：不要直接改数据库，在流水页冲正原事件后重新录入；
- **到期仍未结算**：打开单股预测历史或验证账本会尝试按现有行情能力结算；若缺少可验证日线则保持等待或标记不可用。

## 7. 当前边界

- 只管理股票，不管理基金、债券或衍生品；
- 不同步券商账户，不自动交易；
- 不处理复杂税务、融资融券、质押、跨账户归并和组合优化；
- 交易日推进目前按工作日近似，到期真实收益仍以单股预测账本的可交易日结算结果为准；
- 研究与验证用于提高决策纪律，不构成投资建议。
