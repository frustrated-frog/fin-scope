# 股票归因：业务、同类行情与预期变化

## 本次范围

保留原报告的摘要、故事线、原因拆解、AI 解读、研判补充、后续观察和事件脉络。在事件脉络之后追加三个章节：

- **公司业务关联**：相关业务、产业链位置、带期间口径的经营数据、相关消息、收入/成本/利润传导、关键变量。
- **板块与同类对照**：目标股、沪深300、匹配的行业及最多三家业务可比公司的目标日涨跌、近五日累计、目标股相对表现；每家附业务选择理由。
- **市场预期变化**：此前判断、新信息、预期出发点、定价机制、已兑现内容和下一步催化。

不恢复已删除的原始证据列表。各分析卡只附采用的披露链接，补查状态收在折叠说明中。利好/利空判断独立于是否能证明当日因果，不因引用不足清空合理的机制分析。

## 实现与数据口径

- `AttributionAssessment.researchInsights` 保存独立 JSON 快照，不修改原有字段，不迁移数据库；旧报告该字段为空时不出现空章节。
- 新生成或重新生成的股票报告自动执行补充研究。已有报告不会在打开时自动重跑模型。
- 复用原报告及事件追溯的资料，再进行最多两次定向搜索、两篇正文读取和一次模型分析。补查业务与可比公司信息，历史年报可用于业务背景。
- 来源按报告日截止，补查查询携带截止日期；时间未知不补造，模型须排除页面内晚于目标日的动态内容，历史消息不当作新披露。
- 行情数字不接受模型生成。同行代码和简称由行情网关核对身份，随后读取历史日线；最新报价只用于证券身份核对。
- 个股/宽基必须取得目标日对应日线，不借用上一交易日或当前报价。近五日为含目标日的五个日线涨跌连乘；数据不足显示空值。
- 行业只使用 `MarketPulseRepository.findWorkspace(目标日)` 保存的同日板块快照，并从该快照选择相关行业。无匹配快照时保留宽基和可比公司对照，不触发全行业历史采集。
- 相对表现为目标股当日涨跌减去对照标的当日涨跌，单位为百分点。可比公司样本不等同于完整行业，不计算虚假的事件收益贡献率。
- 数字对照当前支持六位代码 A 股；其他市场保留业务与预期研究，不套用沪深300。
- 资料补查、模型分析、行情获取各自可降级；扩展服务整体失败也不改变原报告状态、摘要或故事线。
- 新增样式统一使用 `attribution-research-insights` / `attribution-insight-*`，避免项目既有 `insight-card` 的网格规则影响本页。窄屏卡片单列，对照表在自身容器横向滚动。

## 使用

在 IDEA 重新启动已更新的 Java 后端后，从自选页重新发起股票归因，生成完成后在原报告底部查看新增章节。Python 日线接口沿用现有服务，无协议修改。打开旧报告仍展示原快照，不会自动补算。
