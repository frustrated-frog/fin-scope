# 自选研究扫描（第一版）

## 边界与契约

输入为普通自选中的 A 股股票、已完成且同口径前复权日线、沪深300日线，以及本地合并报表派生的单季度财务数据。复用 `PythonDailyBarClient`、`ProviderCallDeadline`、`StockFundamentalsService` 和 `StockFinancialQuarterAssembler`，不新增外部数据源、依赖或 LLM 调用。基金不纳入扫描，原有卡片与详情布局保留。

行情扫描最多60只股票，每个相邻收益区间的起止日期必须完全一致；停牌形成的多日收益不与单日基准混比。强弱模型用评价窗口之前最多120个样本拟合 alpha/beta（最少60个），随后评价最近20个完整共同交易区间，记录实际收益、模型基线、偏离和样本期。关系扫描用最近60个共同日收益（至少50个），同时给出原始相关、扣除大盘后的残差相关和下跌日相关；原始相关≥0.75且残差相关≥0.50才标记为紧密联动。无法计算的数值留空并记录原因。

财务质量使用连续8个同币种、同来源季度，对比最近/此前四季度的收入、归母利润、经营现金流及收入加权毛利率。正利润但经营现金流为负、利润增长≥10%而现金转化低于0.5、收入增长≥10%而毛利率下降≥2个百分点分别形成可追溯观察项。负基期利润不计算增长百分比，缺失金额不补零。只使用实际已取得的数据，不回填到过去的扫描。

## 状态与持久化

独立有界单线程池运行扫描，最多一个活动任务。SQLite保存任务和不可变结果JSON；唯一活动槽位防止重复执行，终态只允许从RUNNING条件更新为READY/PARTIAL/FAILED。启动时把上次进程未完成的任务标记FAILED，保留历史已完成快照。每次扫描有固定的成员指纹、方法版本、观测时间与证据日期；远程请求不在数据库事务内。

GET `/api/watchlist/research-scan` 返回最近结果、活动进度、最近7次历史摘要；首次访问或到达新交易日收盘后自动启动。POST同路径显式重扫。后台在工作日16:30触发同一用例；周末复用周五扫描日。总远程预算180秒，行情阶段90秒，财报阶段使用剩余预算；单只失败保留其他结果。手动重扫也保留此前快照。

页面增加紧凑的研究扫描区，按强弱偏离、隐藏联动、增长质量展示计算结果和依据，支持历史切换及点击进入现有股票详情。结论是统计观察，不输出买卖评分。历史只展示当时冻结的结果，不把现在取得的数据伪装为过去已知。

## 验证

覆盖模型不使用评价期拟合、同区间对齐、停牌/缺口、复权/完成状态、零方差、市场共同波动产生的伪相关、连续季度与币种/来源/缺失约束、SQL活动槽位与终态防覆盖、重复请求、部分失败、历史切换和轮询取消；执行相关后端测试、前端测试、生产构建及本地页面检查。
