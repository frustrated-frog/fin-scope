# 自选经营资料整理的标的校验

## 澳弘电子的实际问题

2026-11-15，澳弘电子最新学习卡运行的六个维度均返回 `READY`，但经营页接口返回 `PARTIAL`，`findings` 为 0。盈利维度引用的是盐湖股份、深南电路、乐鑫科技及公告汇总页，模型因此将收入、利润和现金栏目标为 `UNVERIFIED`。只检查模型是否返回完整 JSON，不能证明经营整理已经产出可用内容。

## 获取链路

`StockLearningBaselineService` 先建立本公司资料，再由 `StockLearningEvidenceCollector` 补充搜索，最后交给既有生成与经营投影流程。

- 公司简介与经营范围复用东方财富适配器，适配器核对证券代码；优先使用七天内的本地公司资料，缺失或过期时在显式整理任务中获取。
- 财务资料按 instrument ID 读取本地公开合并财报，包含最近报告及同币种、同类型、同主来源的去年同期报告；排除未来报告、冲突与未核实报告。
- 公开结构化财务来源目前使用同花顺及新浪适配器已保存的记录。每个供应商单独形成一条证据，保留来源、质量、报告期、累计/期末口径、币种和原始指标，不将各来源的同名指标合并为一条记录。
- 不使用用户的手工笔记或私有导入文档充当公开证据。公司资料与财报基线在本次运行中只装配一次，各维度使用独立副本，避免维度和证据编号互相覆盖。

## 搜索过滤

搜索明确引用证券简称与代码。获取正文前检查标题、URL 和摘要是否与目标公司相关；正文中的普通六位金额不作为证券身份。拒绝相近但不同的公司名、嵌在更长数字中的代码，以及不可追溯的非 HTTP 链接。

正文获取失败时可保留已经匹配目标公司的摘要；正文被重定向到其他公司或不再包含目标身份时，不覆盖原摘要。单条资料失败不丢弃其他材料。搜索整体不可用时仍可使用已校验基线，缺少目标资料时不使用其他公司的结果凑数量。

每维最多八条材料，最多尝试读取两条搜索正文；基线和补充材料统一重新分配维度内的 E 编号。

## 生成状态与验收

未知证据编号、无有效引用的支持判断等校验继续保留。所有栏目均为 `UNVERIFIED` 的维度改为 `INSUFFICIENT_EVIDENCE`，评级为 `UNKNOWN`、置信度为 `LOW`，不再把完整返回一组“未知”记为研究已就绪。

验收同时检查经营投影的可用条目和来源，而非仅检查学习卡状态。使用澳弘电子原失败运行的搜索材料，加入实时核验的公司资料与本地同标的财报后，真实模型重放得到四项可引用经营认识：收入来源、回款与现金、利润与成本、竞争优势依据。对内容进一步复核时，材料已区分累计与期末数据、报告期及原始来源；未披露的产品拆分、定价和竞争细节继续保留为未知。

重放仅只读用户数据库，公司资料缓存写入使用隔离替身，没有改写历史运行、手工笔记或观察清单。正式使用需重启后端并重新发起整理。

本批学习卡、基本面及公司资料适配器相关 109 项测试通过，包括错公司与近似名称拒绝、普通金额不匹配证券代码、无关正文不覆盖摘要、搜索失败保留基线、跨维度副本隔离、财报来源及累计口径隔离、未来及冲突报告拒绝、全未知结果降为资料不足等。
