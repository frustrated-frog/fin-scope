# 资讯河流与历史回放

入口：资讯 → 新闻河流 · 回放。使用现有资讯源及雷达聚合结果。

## 浏览方式

- 查看一天内每半小时新收录事件的曲线，按财经、科技、国际时事及其他主题切换。
- 点击有事件的时段，展开该半小时内新收录的事件；拖动时间轴或使用方向按钮回看某次实际发布的榜单。
- 历史榜单保存实际发布的前二十项，展示首次上榜、排名上升、排名下降、再度上榜及持续在榜。
- 点击标题展开当时摘要；“查看实时详情”明确跳转当前雷达，历史摘要不会静默替换为最新内容。
- 新发布版本只显示更新提示，点击“查看更新”或“回到实时”后才切换，保留阅读位置。

## 时间与存储

- SQLite 保存实际发布批次、不可变标题摘要版本、事件首次收录记录、各批次排名。内容版本使用 SHA-256 复用，同一事件再次出现不重复计算为新收录。
- 统计时间为该功能实际观察到成功发布事件的时间，不使用原文落款或发布时间回填过去。首次启用会收录当前已有事件；此前没有保存的榜单不会倒推生成。
- 在 Redis 页面版本激活成功后才保存历史，SQL 提交完成后通知 `news-river` 页面范围。发布失败不归档；历史存储失败记录错误并保留当前实时浏览能力。
- 每次物化发布（含增强后重新发布）保存独立版本，重试同一版本幂等；后来的标题或分类变化不改写既有记录。
- 默认浏览今天，允许查看最近七个自然日，使用北京时间。榜单引用的旧内容仍可保留，其他无引用旧版本随历史清理。
- 半小时事件明细按首次收录时间和稳定事件键排序，每页五十项；截至所选批次时刻，迟到报道只能出现在之后的时段。

## 接口

- `GET /api/news/river?date=yyyy-MM-dd`：日期范围、已保存批次和半小时分组计数。
- `GET /api/news/river/frame?batchId=<id>&category=ALL`：当时实际发布的榜单。
- 同一明细接口带 `bucket=yyyy-MM-ddTHH:mm:00&page=0` 查询该时段的新收录事件。时段须与批次同日且不晚于该批次；结束时间以所选发布时刻截断。

事件 ID、批次 ID 以字符串返回，避免 JavaScript 丢失长整型精度。请求读取本地历史，不触发抓取、聚类或模型调用。

## 验证

覆盖内容不可变、排名升降与再度上榜、迟到事件、版本复用、批次幂等、事务失败回滚、七天清理、稳定分页、日期/时段校验、发布失败不归档及历史保存后的通知顺序。前端覆盖曲线与列表联动、历史摘要、手动接受更新、空历史和过期异步响应隔离。
